```

                          experiments/error_budget/wallet_audit.md

```

## 3. 회계 고침 — 켜는 것을 권한다. 다만 근거의 범위를 적는다

```
현행   총액 = max(앵커, 계획)          계획의 정책 반응 3/4 를 버린다
고침   총액 = 앵커 × clamp(계획/평소계획, 0.5, 2.0) × SCALE
```

```
확인된 곳    P012   총액 +2.37% → +5.41%   (계획 반응 +9.76%, p=0.0015)
             **위약이 지킨다** — 같은 달력일을 정책 없이 돌면 계획액 −2.18%(p=0.1036)
확인 안 된 곳 P013   **취소했다.** 그 런은 지원금이 한 푼도 안 나갔고(모든 날 0원),
             "정책 반응 +6.36%" 중 +3.70%p 가 정책 전에도 있던 상승이다
             experiments/plan_channel/P013_evidence_is_weaker.md
```

**한 정책에서만 확인됐다.** 다른 정책에 쓸 때는 반드시 **위약이나 정책 전 가짜 ON
창**을 함께 낸다(`recompute_plan_channel.py --placebo-on`).
