# 실험 v7 — 정책별 결과 비교

> 주 지표는 **사건 단위 구매 비율**이다. 후보당 ~1,760 사건(4 seed)이라 SE 가 0.006 이다.
> 값은 기록된 계획 파일에서 계산했다.

## 주 지표 — 구매 사건 비율 (on 팔)

```
v25  구매 지목      ██████████████████              0.0584
v30  겨냥 교정      ███████████████████████         0.0771
v29  빗장 없음      ███████████████████████████     0.0904
```

| 비교 | 차이 | SE | 크기 | |
|---|---:|---:|---:|---|
| v25 → v30 | +0.0187 | 0.0085 | **2.21 SE** | **2 SE 이상** |
| v25 → v29 | +0.0320 | 0.0088 | **3.63 SE** | **2 SE 이상** |
| v30 → v29 | +0.0133 | 0.0093 | **1.43 SE** | 2 SE 미만 |

### 사전등록 판정

| 조건 | 기준 | 관측 | |
|---|---|---:|---|
| v30 > v25 | ≥ 2 SE | 2.21 SE | **충족** |
| v30 ≈ v29 | < 2 SE | 1.43 SE | **구별 안 됨** |
| 칸 채우기 아님 | 계획당 사건 증가 없음 | -0.07 | **안 걸림** |
| 외출 폭증 아님 | zone 비율 ±0.03 | +0.0019 | **안 걸림** |

> **판정: 겨냥이 문제였다.** 빗장에서 "구매"라는 낱말을 빼는 것만으로
> 구매 비율이 2.21 SE 올랐고, 칸 채우기도 외출 폭증도 일어나지 않았다.

## 같이 봐야 할 것 — 무엇이 안 변했나

```
                   zone 비율      계획당 사건
v25  구매 지목          0.1054        9.19
v30  겨냥 교정          0.1073        9.12
v29  빗장 없음          0.1147        9.22
```

**세 후보의 zone 비율이 0.105~0.115 로 여전히 붙어 있다.** v6 이 그은 경계 그대로다.
하루는 여전히 집에 있고, 바뀐 것은 **그 하루 안에서 사느냐**뿐이다.

## 정책 격차 — 좋아 보이지만 아직 말할 수 없다

```
on − off 구매 비율
v25  구매 지목      +0.0071
v30  겨냥 교정      +0.0191
v29  빗장 없음      +0.0176
```

v25 +0.0071 → v30 +0.0191 로 2.7배지만, 이중차분으로 재면 **+0.0120 · SE 0.0115 · 1.05 SE** 다.
**정책 반응이 좋아졌다고 말할 수 없다.** 점추정이 그렇게 보일 뿐이다.
