## 좋은 것 — EM-4 가 처음으로 값을 냈다

`EM-4` 는 "못 잰 지표" 였다. 이제 값이 나오고 **순위를 맞혔다** —
준내구재(가구·문구·안경·의류)가 오르고 대면서비스(미용·욕탕·레저)가 내렸다.
정답지의 방향과 같다.

**다만 간격이 9배 넘게 크다**(68.3%p 대 7.20%p). 부호는 맞고 크기가 과하다.

## 나쁜 것 — EM-2·EM-3 가 0 을 지난다

둘 다 기대는 `+` 인데 **구간이 0 을 포함**해 "구별 안 됨" 으로 떨어졌다.
지급 정책인데 **총 카드매출이 안 늘었다**(-0.46%).

이것은 P012 에서 본 것과 **다른 종류의 벽**이다. P012 는 문턱이 창 밖이라
유인이 없었는데, 여기는 지갑에 돈이 들어왔는데도 총액이 안 는다 —
**지원금이 어차피 할 지출을 대체하고 끝났다**는 뜻이다(대체율 ~1, MPC ~0).

## 이전 읽기보다 나빠졌다 — 숨기지 않는다

```
오차 예산의 기존 EM-3    시뮬 +12.60 · 오차 5.30%p
arm A 의 EM-3           시뮬 -0.46 · 오차 **7.76%p**
```

**자를 고친 결과가 더 나쁘다.** 그래도 이쪽이 맞는 자다 — EM-2 의 적격 판정이
상생 기준이었던 것을 고치려고 돌린 런이고, 표본도 n=700 으로 더 크다
(읽을 런을 고르는 규칙은 **가장 큰 표본**).

**좋아지는 쪽만 반영하면 그건 측정이 아니라 선별이다.** 옮겨 적는다.

## 옮겨 적기 전에 확인할 것

```
· EM-3 는 적격 판정과 무관한 지표(전체 카드매출)인데 왜 이렇게 다른가
  -> 창이 다르다. 기존 읽기의 창을 확인하고, 창 차이로 설명되는지 본다
· 창 차이로 설명 안 되면 두 런 사이에 다른 것이 바뀌었다는 뜻이다
```

이 확인 없이 옮겨 적지 않는다. **왜 달라졌는지 모르는 채로 숫자만 바꾸면
나중에 어느 쪽이 맞는지 아무도 모른다.**

## 남는 물음 — 지갑형의 벽

EM-2·EM-3 가 0 인 것은 **대체 문제**다. 지원금이 새 소비를 만들지 못하고
기존 소비의 결제수단만 바꾼다. 이것은 프롬프트가 아니라 **소비 모델의 문제**이고,
P012 의 문턱 벽과 나란히 **두 번째 구조적 벽**으로 기록한다.

```
P012  문턱이 창 밖이라 유인이 없다        (창으로 고침 · 확인 중)
P013  지갑이 대체로 끝나 총액이 안 는다   (미해결)
```
