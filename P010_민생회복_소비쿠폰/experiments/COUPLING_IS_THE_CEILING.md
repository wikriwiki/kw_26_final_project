# 자원에 거는 것이 천장을 만든 장본인이다

**2026-09-22 05:20** · v27 계획 480칸 · 볼일 업종별 분해

---

## 어젯밤 보고서에 적은 다음 단계를, 돌리기 전에 기각한다

보고서 `REPORT_20260921_실험현황.md` 에 이렇게 적었다.

> 1. 빈자리를 채운다 — "하기로 했지만 안 갈 수 있는 일"을 만든다. **볼일을 자원에 걸면 된다.**
>    세탁·세제가 이미 그 모양이고, 자원 게이트가 안 한 계획을 잡아낸다

**그 설계는 이미 돌아가 있었다.** v27 의 볼일 여섯 업종 중 둘은 자원에 걸려 있고
넷은 안 걸려 있다. 같은 라운드, 같은 프롬프트, 같은 480칸 안에 대조가 들어 있었다.

```
볼일 업종            자원 연결                          수행률
  groceries        quote:groceries → meal_stock       26/216  (12%)
  meal_dine_in     meals 필요(=meal_stock 소비)        18/168  (11%)
  ─────────────────────────────────────────────────────────────
  health_goods     없음                                 1/ 56  ( 2%)
  other_service    없음                                 1/ 24  ( 4%)
  convenience      없음                                 0/  8  ( 0%)
  education_service 없음                                0/  8  ( 0%)

  걸림   44/384 (11.5%)
  없음    2/ 96 ( 2.1%)        5.5배 · Fisher 양측 p = 0.0031
```

## 두 줄로 읽힌다

**자원에 거는 것은 통한다.** 2.1% 를 11.5% 로 올린다. 다섯 배 반이고 우연이 아니다.

**그리고 11.5% 가 바로 그 천장이다.** [THE_TEN_PERCENT_CEILING.md](THE_TEN_PERCENT_CEILING.md)
가 "열에 한 번"이라고 적은 10% 는, 다시 세어 보니 **자원에 걸린 볼일의 수행률**이었다.
안 걸린 것은 10% 가 아니라 2% 다.

```
내가 천장이라고 부른 것        실은 결합이 이미 올려놓은 값이었다
결합으로 더 올릴 여지          없다 — 이미 결합된 쪽을 재고 있었다
```

그러므로 **볼일을 자원에 더 거는 라운드는 돌릴 필요가 없다.** 결과를 안다: 11.5%.

## 남은 것은 비율이 아니라 분모다

같은 표를 시나리오·팔로 쪼개면 DS-1 이 왜 4건·2건 위에 서 있었는지가 한 줄로 나온다.

```
매장식사 볼일을 받은 칸 — 60명 코호트

   cashback       off  3/21   on  1/21
   distancing     off  2/21   on  1/21     ← DS-1 이 여기서 나온다
   grant          off  4/21   on  1/21
   local_voucher  off  3/21   on  3/21
```

**팔당 21칸이다.** 볼일 업종을 "그 시민이 가장 많이 쓰는 업종"으로 고르는 규칙이
60명 중 21명에게만 식사를 준다. 11% 를 곱하면 2건과 1건이 나온다. 정확히 그 수가 나왔다.

```
DS-1 의 분모가 작은 이유    수행률이 낮아서가 아니라  ← 11%는 결합된 것치고 정상값
                           식사 볼일을 받은 사람이 21명이어서다
```

## 그래서 다음 라운드가 고칠 것은 이것 하나다

| 바꾸는 것 | 안 바꾸는 것 |
|---|---|
| 식사 볼일을 받는 인원 (21명 → 전원) | 프롬프트 (v25 그대로) |
| 시민 수 (60 → 240) | 볼일을 선택으로 두는 것 (v28 의 문법 강제는 안 쓴다) |
| 시나리오를 거리두기 하나로 (칸 수 유지) | 양 팔에 똑같이 주는 것 |

11% 를 240명에 곱하면 팔당 **스물 몇 건**이다. 지금의 2건·1건과 달리 분모가 된다.

> **이것이 유도인가.** 업종을 고르는 규칙이 "관측된 최대 업종"에서 "전원 동일 지정"으로
> 바뀐다. 이것은 숨길 것이 아니라 적을 것이다. 다만 **양 팔에 똑같이 주므로 방향을
> 만들 수 없다.** 거리두기가 켜졌을 때 그 볼일을 포기하는지 아닌지는 여전히 모델이 정하고,
> DS-1 이 재는 것이 바로 그것이다.

## 이 문서가 고쳐 놓는 앞선 기록

`THE_TEN_PERCENT_CEILING.md` 는 "천장은 볼일의 유무가 아니라 선택적 필요에 대한
10% 수행률"이라고 적었다. **절반만 맞다.** 선택적 필요의 수행률은 하나가 아니라 둘이다.

```
자원에 걸린 선택적 필요     11.5%
안 걸린 선택적 필요          2.1%
```

그 문서가 낸 처방(`mandatory: true` 로 준다)은 v28 에서 돌렸고, 문법이 강제해 버려서
물음 자체가 사라졌다. 이 문서가 내는 처방은 비율을 건드리지 않고 **분모만 키운다.**
