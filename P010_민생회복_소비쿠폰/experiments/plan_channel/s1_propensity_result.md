
클램프 비율(2차)도 정답지 오차(3차)도 보지 않았다.

## 무엇이 확인됐나 — 결함은 진짜고, 프롬프트로는 안 고쳐진다

겨냥한 결함이 **n=120 에서 제대로 된 중심값으로 재확인됐다.**

```
v5 의 r = −0.088 / −0.099 / −0.078      (본런 n=200 에서 −0.155 였다)
120명에게 고유값 6~7개 · 0.68 이 64~71%
```

**모델은 누구에게나 0.68 을 적는다.** 그리고 "본인의 소비수준과 소득이 기준이다"
라고 한 문장을 더해도 **그대로 0.68 을 적는다**(고유값 +1~2, r 0 근처, 부호검정
p=1.000/0.177/0.892).

필드 일반**으로 볼 근거가 생겼다.
