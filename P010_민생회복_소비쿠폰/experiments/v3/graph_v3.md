## 기전별 후보 비교 — 잡음 폭과 함께 읽는다

> 잣대는 v3 결과를 보기 전에 고정했다 (평균 2,938원 · 최대 4,000원). `data/experiments/seed_variation_band_v25.json`
> **후보 간 폭이 잡음 폭 이하이면 후보의 차이로 읽지 않는다.**

**거리두기**

```
     -3,583원                 0 +3,583원                
v25                          │████████████████████████  +3,583원
v26                          │██                        +250원
v27                          │███████████████████████   +3,500원
```

후보 간 폭 **3,333원** > 잡음 폭 2,917원 → 폭을 넘었다. 다만 후보당 seed 하나이므로 **후보 탓이라고 단정하지 않는다** (v4로 넘긴다).

**지역화폐**

```
     -1,500원                 0 +1,500원                
v25  ████████████████████████│                          -1,500원
v26                          │████████████████████      +1,250원
v27                          │█████████████             +833원
```

후보 간 폭 **2,750원** ≤ 잡음 폭 4,000원 → **구별 불가.** 후보의 차이라고 말하지 않는다.

**지원금**

```
     -3,583원                 0 +3,583원                
v25                          │████████████████████████  +3,583원
v26                          │█████████████████         +2,583원
```

후보 간 폭 **1,500원** ≤ 잡음 폭 2,167원 → **구별 불가.** 후보의 차이라고 말하지 않는다.

**캐시백**


## 반응성 — 정책을 켜면 계획이 움직이는가

> 영점은 **같은 팔을 seed만 바꿔 다시 뽑은 거리**다(96쌍). 그냥 다시 뽑아도 이만큼은 달라진다.
> 기준은 결과를 보기 전에 정했다 — [PREREG_RESPONSIVENESS.md](PREREG_RESPONSIVENESS.md).

**무엇을·어디서 (주 지표)**

```
영점    ██████████████████████      0.197
v25   █████████████████████████   0.218   영점 대비 +0.021
v26   ████████████████████████    0.216   영점 대비 +0.018
```
