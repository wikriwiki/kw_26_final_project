# Visualization override

- 전체 애플리케이션 헤더와 객체 요약을 숨긴다.
- viewport 높이를 고정하고 문서 스크롤 대신 지도 캔버스와 도킹 패널을 사용한다.
- 1440×900 기준 지도 가시 면적은 최소 70%다.
- 지도 위에는 상태 문장이나 개발 안내문을 쌓지 않는다.
- 실제 HTML 시각화 산출물이 확인되면 iframe을 캔버스 전체에 맞춘다.
- 산출물이 없으면 중앙 한 줄 상태와 `실행 개요로 돌아가기`만 제공한다.
- 조작 순서: 시간 재생 → 레이어 → 객체 선택 → 선택 객체 근거.
