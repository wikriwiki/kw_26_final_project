# 금연 실험: 프롬프트 검증, 근거 기록, 인터뷰와 찬반 분석

대상은 고정 7,500명, OFF/ON 각각 2017-11-19~12-16이다. 이 문서는 실제 GPU 실행 결과가 아니라 **실행·기록·분석 절차**다. 실제 시민 인터뷰 자료와 합성 시민의 응답을 구분한다.

현재 인터뷰는 **개인 상황과 공개 근거를 연결하는 v2 계약**을 사용한다. 입력 선택, 응답 구조, 품질 검토와 작은 비교 진단은 [reasoning_quality_v2.md](reasoning_quality_v2.md)를 따른다. 이전 v1 응답은 같은 분석에 섞지 않는다.

## 실행 프롬프트

실험 runner가 `SIM_PROMPT_VARIANT=no_smoking_v1`을 고정한다. 낮 의도, 장소 선택, 밤 상호작용은 각각 금연 실험용 프롬프트를 사용한다. 소비쿠폰 잔액·가을 만료일·강제 외출·정해진 찬반 방향을 금연 규칙에 적용하지 않는다. 과거 정책 재현용 프롬프트는 별도 등록·보관된다. 전체 인벤토리와 검증 범위는 [prompt_audit.md](prompt_audit.md)에 있다.

모든 실제 실험 호출에서 고정 LG tokenizer와 chat template로 입력 토큰을 센다. 입력 + 요청 출력 + 여유 128토큰이 8,192를 넘으면 호출 전에 실패시키며 기록을 임의로 잘라 조용히 계속하지 않는다. tokenizer 3개 파일은 `tokenizer_manifest.json`의 revision·해시로 확인한다. 합성 fixture의 통과만으로 7,500명의 모든 실제 입력이나 LG 응답 품질이 검증된 것은 아니다.

Stage1/Stage2/밤 응답은 공개 설명과 **실제 사용자 입력에 존재하는 `evidence_quote`**를 남긴다. 의도·장소 선택에서는 구체적인 개인 상황이나 제약이 선택과 어떻게 연결되는지 설명한다. 단순 일상에는 짧은 설명도 가능하며 없는 대안·상충 요인을 만들지 않는다. 일치 검사는 인용 위치를 확인하며 설명의 의미적 타당성까지 보증하지 않는다. 상세 내부 사고과정을 저장·수집하는 기능은 아니다.

Stage2는 기존 엔진의 유료 외출·양의 제안 지출 모델을 사용한다. 제안액, 최종 결제 영수증, 자동 금액 보정·장소 대체를 구분한다. 만족도는 모형 값이고 실제 설문이나 정책 찬반이 아니다. 시점이 확인되지 않은 실시간 후기는 이 실험에서 조회하지 않는다.

## 기록과 완전성

`evidence/v1/<day>/*.jsonl`에는 요청 이전에 저장한 system/user 원문, 모델·sampling 설정, 응답 공개 본문, 오류 종류, 일자·팔·참여자·코호트·소스 해시가 남는다. 비밀키와 숨겨진 reasoning 필드는 저장하지 않는다. 실제 저장 실패가 있으면 성공한 에이전트 일자로 처리하지 않는다.

에이전트 일자별 기록은 DB에 원자적으로 커밋된 metrics의 `interview_evidence` 참조로 연결한다. 제안된 결정, 공개 이유, 실행 이벤트, 영수증, fallback을 별도 항목으로 보존한다. 실패한 트랜잭션의 고아 로그는 인터뷰 근거에 포함하지 않는다. 밤 대화는 **모형이 추정한 상호작용**으로 표시하며 실제 녹취·시민 발언으로 취급하지 않는다. 대화가 없는 날도 빈 완료 기록을 남긴다.

`interview_evidence.py`의 전체 감사와 packet exporter는 일자 누락, 미완료 밤, 섞인 실행/참여자/소스, 변조된 참조를 검사한다. 7,500명 수집에는 임시 SQLite 색인을 만들어 metrics를 한 번 읽는다. 특정 시점 이후의 사건·기억·정책 판단은 제외한다. 원문 기록 용량과 처리 시간은 GPU 파일럿에서 측정해야 하며 기존 100GB 디스크로 충분하다고 가정하지 않는다.

```bash
# 완료된 OFF와 ON에 각각 실행한다. 아직 존재하지 않는 실행 결과를 가정하지 않는다.
python scripts/sim/interview_evidence.py --run-dir /workspace/no-smoking-results/off --audit-all --through-day 2017-12-16 --out /workspace/no-smoking-results/audits/off_evidence.json
# 특정 시민의 당시 인터뷰 근거를 읽기만 하는 예시. 실제 cohort ID로 바꾼다.
python scripts/sim/interview_evidence.py --run-dir /workspace/no-smoking-results/off --aid COHORT_AGENT_ID --through-day 2017-12-02 --out /workspace/no-smoking-results/audits/agent_pre_packet.json
```

감사 결과의 누락·근거 연결·대체 처리 수치를 먼저 확인한 후 인터뷰를 실행한다. 현재 실제 GPU 실행 기록이 없으므로 7,500명 전체 기록의 완전성을 이미 확인했다고 해석하지 않는다.

## 같은 질문으로 정책 전후 응답 수집

권장 응답 시점은 **12월 2일과 12월 16일**, 두 팔에 같은 고정 질문을 사용한다. 정책이 시행되지 않은 OFF 및 ON/pre는 질문에서 제시한 규칙에 대한 `hypothetical`, ON/post는 `experienced`로 구분한다. 후자는 개인이 시설을 실제 이용했다는 뜻은 아니다. 이 구분을 유지하며 서로 다른 질문·대상·측정 맥락을 같은 정답과 비교하지 않는다.

`collect_policy_stances.py`는 **완료된 실행 기록을 읽기만 한다**. 응답을 시뮬레이션 상태에 다시 넣지 않으므로 인터뷰가 본 실험을 변화시키지 않는다. 기본 명령은 계획만 출력하며 `--execute`에서만 LG 서버를 호출한다. `--limit`은 진단용 일부 인터뷰이며 본 실험 인원을 바꾸지 않는다.

```bash
python scripts/experiments/collect_policy_stances.py --run-dir /workspace/no-smoking-results/off --as-of 2017-12-02 --out /workspace/no-smoking-results/interviews/off_pre
# 모델 준비·전체 기록 검사 후 같은 명령에 --execute 추가
```

나머지 세 조합은 OFF/12-16, ON/12-02, ON/12-16이다. 문항 ID·해시·답변 원문·인용·자기 확신·모델과 원본 호출 해시가 보존된다. 입력창에 맞춘 근거 선택은 전체 packet을 별도로 보관하고 선택/누락을 표시한다. 선택된 근거에 없는 경험을 인용하거나 응답이 잘리면 오류 응답으로 남기며 찬반을 만들어 보충하지 않는다.

## 집단과 성능평가

[stance_analysis.md](stance_analysis.md)에 실제 CLI와 정답 schema가 있다. 명시적 입장을 찬성/반대/양면적/중립/판단 유보/잘 모름으로 구분하며 저확신·무응답·실패를 별도로 집계한다. 흡연 여부·매출·만족도만으로 입장을 정하지 않는다.

응답과 인용 텍스트의 TF-IDF·구면 k-means로 주제 군집을 만들고 **OFF/pre로만 적합한 모델을 고정**하여 다른 구간에 적용한다. 정해진 개수의 군집이 반드시 생긴다고 가정하지 않으며 데이터 부족·어휘 부재도 표시한다. 군집별 근거·대표 응답과 고정 인구속성별 찬반 분포를 출력한다. 원시 나이·흡연 라벨은 군집 feature에 직접 넣지 않지만 응답자가 자발적으로 언급한 내용은 텍스트에 남는다.

현재 연구 보고서의 매출 회귀값은 찬반 정답 라벨이 아니다. 찬반 평가는 기본 보류하며, 같은 응답에 대한 독립 주석 또는 같은 문항·집단·시점·분모의 조사 통계가 있을 때만 실행한다. 분류는 confusion matrix, macro-F1, balanced accuracy, coverage를 보고하며 미해결 응답도 숨기지 않는다. 집단 비율 비교는 동일한 측정 대상을 확인한 후 수행한다. 합성 fixture 성능은 실제 정책 재현 성능으로 해석하지 않는다.

## v7 준비 단계의 오프라인 검증 기록

`validation_prompt_evidence_stance.json`에 실행한 검사와 원본 로그 해시를 기록했다. Python 244개·프롬프트 모듈 52개·생성 호출 15곳을 정적으로 조사했고, 활성 단계와 인터뷰 사례 38개가 고정 LG 토크나이저 예산 검사를 통과했다. 모든 과거 프롬프트의 의미적 품질이나 모델 출력 품질을 인증한 것은 아니다.

위 수치와 다음 테스트 수치는 이전 v7 스냅샷의 기록이다. 현재 v2 개인 상황·근거 개선 결과는 `validation_reasoning_quality_v2.json`과 `reasoning_quality_v2.md`를 확인한다.

시뮬레이션 단위 테스트는 862개 통과·7개 건너뜀·3개 실패, persona/배포 검사는 36개와 하위 검사 7개가 통과했다. 실패 3개는 이번 변경과 무관하게 메인에도 있는 `test_outside_need.py`의 기존 기대값 불일치다. 실제 GPU 출력, 전체 코호트 입력 길이, 실행 속도·기록 용량, 실제 찬반 집단과 실증 성능은 파일럿 및 본 실행에서 확인한다.
