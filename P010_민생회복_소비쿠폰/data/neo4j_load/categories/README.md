## 검토 가이드

자동 매핑이라 완벽하지 않을 수 있음. 다음만 확인하면 보통 OK:

1. **L1 명칭이 자연스러운가** — "주점"을 "술집"으로 바꾸고 싶으면 직접 편집
2. **누락된 sub가 있는가** — 예: 디저트에 "케이크"가 없는 이유 = 데이터에 별도 L3 없음. 필요 시 베이커리에 흡수
3. **"기타" L1**: 시뮬에서 거의 안 쓰임. 제거하거나 그대로 둬도 무관

직접 편집 가능. yaml 형식만 유지하면 됨.

## 운영시간 (선택)

POC 후 §11-A 데이터 확보 시 카테고리별 운영시간 추가:

```yaml
- name: 식사
  open: "06:00"
  close: "23:00"
  sub: [한식, 중식, ...]
```

현재는 운영시간 없이 시작. Stage 2 검증 시 24h 가정.
