## 함정 — 세 번 당했다

```
· 라운드 러너의 관문이 파일럿 경로를 읽는다. 복제로 판정했다면 경로를 바꿔 건다
· 서버 저장소가 둘이고 **세대가 다르다**. 덮지 말고 tools/patch_split_anchor.py 로 심는다
· 탐침을 둘 동시에 돌리면 둘 다 느려진다. 본런과는 워커 4로 나눠 쓴다
· **띄우기 전에 같은 이름의 프로세스가 도는지 먼저 본다.** `rm -rf` 로 출력
  폴더를 지우는 것은 앞 프로세스를 멈추지 않는다. 오늘 두 번 당했다 —
  탐침 둘이 같은 .part 에 함께 썼고, 본런 둘이 같은 폴더·같은 그래프에 함께 썼다
· 건너뛰기 표식을 --fetch 가 받아 온다 → "SKIPPED" 가드를 넣었다 (실제로 한 번 받았다)
· **scp 한 셸 스크립트는 반드시 `sed -i "s/
$//"` 한다.** CRLF 면
  `export FOO BAR` 가 "BAR
" 이라는 못 쓰는 이름을 export 하려다 조용히 실패하고,
  스크립트는 **에러 없이 계속 돈다.** 환경변수가 안 닿아 기본값으로 도는데
  로그만 봐서는 모른다 — 시드 3개를 넘겼는데 1개로 돌아 호출이 360 대신 120 이었다.
  **돌린 직후 "인자가 닿았다" 를 로그 한 줄로 확인하고 자리를 뜬다.**
· 탐침을 relaunch 할 때 **이전 프로세스가 죽었는지 확인**한다. 두 개가 같은
  responses.jsonl.part 에 함께 쓰면 자료가 섞인다 (실제로 2개가 동시에 돌았다).
```
