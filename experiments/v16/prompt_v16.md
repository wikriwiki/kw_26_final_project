## 왜 지금 다시 겨루나

**지금까지의 프롬프트 비교는 전부 퇴화된 기준선에서 했다.**

```
옛 기준선 (v3 ~ v12)
  구매 30건 / 96칸 · 그중 home_online_goods 23건 (77%)
  11개 업종 중 7개가 한 번도 안 팔림
  부여된 구성과의 거리 (사람별) 0.80
```

구매의 4분의 3이 **자원 시나리오가 강제한 세제 하나**였다.
그런 곳에서 프롬프트를 견주면 **무엇을 바꿔도 세제는 그대로**이므로 차이가 안 난다.

```
새 기준선 (끼니 필요 + 되먹임 수정)
  구매 58건 / 77칸 · groceries 26 (45%) · 세제 13 (22%)
  부여된 구성과의 거리 (사람별) 0.53
```

**행동 공간이 열렸다.** 이제 프롬프트가 움직일 여지가 있는지가 처음으로 물어진다.

## 후보 v34 — 근거가 남은 수정 둘을 합친다


(`test_no_third_change_sneaked_in`).

정책 이름·업종·방향·수치가 하나도 없다.
