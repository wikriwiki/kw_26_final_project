## 소득을 잘못 승격하지 않는 기준

`frozen_income.json`의 daily_income_by_aid는 평일·주말 소비 앵커를 가중평균한 일별 지갑 보충 예산입니다. 파일명에 income이 들어가더라도 실제 소득이 아닙니다. 페르소나 personal.income_level / 그래프 p_income_level도 생성된 계층이며 실측 소득분포가 아닙니다. 이 두 값을 단순히 소득 5분위로 바꿔 표본 정합을 주장하지 않습니다. 공식 소득분포를 사용해 합성시민에게 소득을 부여하는 방법은 허용하지만, donor·imputation·할당 방법·소스 해시·분포 검증을 별도로 보존하고 합성 할당이라고 밝힙니다.

서울서베이의 가구소득과 주민등록의 개인 성별·나이·행정동은 모집단 단위가 다릅니다. 가구소득을 각 주민에 연결하려면 가구원 확대 가중치 및 개인/가구 소득 정의를 명시해야 합니다. 단위·연도 변환 근거가 없으면 도구가 중단됩니다. 네 주변분포를 맞추더라도 네 변수의 결합분포가 실제와 같다고 판단하지 않습니다.

## CPU 도구와 차단 관문

`tools/freeze_population_matched_cohort.py`는 공식 frame과 후보 projection 파일만 읽어 결정론적 seed로 raking 및 중복 없는 표본을 만듭니다. Neo4j나 모델을 호출하지 않습니다. 대상 필드는 sex, age_band, admin_dong, income_band 네 개입니다. 각 목표의 원본 경로·SHA256·모집단 단위·기준연도·필드 정의를 요구합니다. 공식 원자료로 검증된 소득 할당 또는 공개된 calibrated synthetic assignment만 허용합니다.

양수인 모든 목표 범주가 후보와 추출 표본에 존재해야 합니다. 수렴 실패, 실측 목표 누락, 소스 해시 불일치, 소득/소비 혼용, 단위·연도 변환 감사 부재는 차단합니다. 비가중 실제 모델 표본의 범주별 최대 차이는 기본 2%p 이내, 가중 유효 표본은 원표본의 50% 이상, 정규화 최대 가중치는 10 이하가 기본 관문입니다. 이 값은 실행 전 고정해야 하며 결과에 맞춰 바꿔서는 안 됩니다. 한 범주에 5명 미만인 지원은 별도 경고합니다.

가중 평가 분포가 목표에 맞더라도 비가중 시민 표본이 2%p 관문을 넘으면 모델 호출 허용값은 false입니다. 평가 가중치가 시민 행동을 바꾼다고 주장하지 않습니다. 표본이 작아서 모든 행정동을 담을 수 없다면 표본을 늘리거나 사전에 다른 추정 모집단을 선언해야 하며, 빠진 행정동을 은폐하지 않습니다.

사용 예: py -3 tools/freeze_population_matched_cohort.py --frame verified_frame.json --candidates verified_candidates.json --citizens 1000 --out proposed_roster.json. 실측 원자료가 없으면 fail-closed JSON을 쓰고 exit code 2를 반환합니다. synthetic 예시는 단위 테스트에만 있습니다.

## 원본과 과거 계획의 한계

공식 네 목표 frame을 현재 감사에서 이미 완결/검증했다고 주장하지 않습니다. 루트는 공식 서울서베이 2020·2021·2025 원자료 ZIP을 새로 확보했으나, 이 감사에서 네 축 목표분포와 합성 소득 할당을 이미 만들었다고 볼 수는 없습니다. 원문 PDF의 실측 정책 효과값은 표본을 선택하거나 시민 프롬프트에 입력하지 않습니다. docs/INCOME_ASSIGNMENT_PLAN.md는 계획이며 완료된 소득 할당의 증거가 아닙니다. OA-22166 소득 필드는 공식 페이지 재검증상 2026-05-13 삭제 이력이 있어 과거 계획의 데이터 가용성 가정을 그대로 적용할 수 없습니다.

현재 완료 후 P014 OFF 그래프에서 여섯 표본의 합집합 132명을 읽기 전용으로 추출해 서버/G 해시를 확인했습니다. 성별·연령대는 ID와 일치하지만, 6명은 Agent residence 코드/ID동과 실제 LIVES_AT→POI→Dong 코드가 다릅니다. 따라서 표본 거주지역은 ID 접두어만으로 확정할 수 없습니다. 이 스냅샷은 현재 P014 OFF 그래프 상태이며 과거 모든 팔의 독립 속성 스냅샷은 아닙니다. 동별 상세 두 분포와 차이는 JSON에 따로 보존했습니다.

현재 그래프의 10대 시민은 15·16세입니다. 정책별 실측이 성인 응답자, 신청자 또는 가구를 대상으로 한다면 해당 표본과 그대로 동일한 모집단이 아닙니다. 신청 자격·가구 소득 정의·대리 신청 및 세대원 취급을 따로 선언해야 합니다. 이를 이미 정합된 표본이라고 주장하지 않습니다.

거주동 ID의 8자리 코드와 실제 LIVES_AT 거주 POI가 가리키는 동은 서로 다른 법정/행정 코드계·빈티지일 수 있습니다. 공식 행정동 분포에 맞추기 전에 read-only 그래프 projection과 명시적 crosswalk를 확인해야 합니다. 현재 ID별 코드 수를 공식 행정동 수로 단정하지 않습니다.
