# 정책 시점의 공식 인구·소득 목표분포 확보 기록

2026-09-28에 보존한 원문과 읽기 전용 CPU 집계를 기록한다. 이 문서는 새 대표표본으로 정책 효과를 검증했다는 결과 문서가 아니다. 현재 새 표본 모델 호출은 0회이며, 모든 새 목표 파일의 `model_calls_allowed`는 false다.

## 확보한 자료와 대상

서울 열린데이터광장의 [주민등록인구 성별·연령별·월별·동별 자료](https://data.seoul.go.kr/bsp/wgs/dataView/data300View/1.do)는 통계청 KOSIS `DT_1B04005N`을 제공한다. 공개 원본 JSON 전체를 보존하고 그 원본에서 CSV를 만들었다. 화면에 보이는 1,000행만 사용하지 않았다. 행정동, 자치구, 서울시 합계가 함께 있으므로 동 단위 남성·여성의 20세 이상 5세 구간만 집계했다. 동→구→시, 성별·나이 합계가 원문과 일치한다.

이 목표의 모집단은 **서울에 주민등록된 내국인 중 20세 이상**이다. 외국인과 20세 미만까지 포함한 서울 전체 시민 또는 정책의 전체 수혜자라고 부르지 않는다. 성인 범위를 이렇게 정한 것은 원문이 5세 구간으로 제공되기 때문이다. 15~19세를 임의로 쪼개 18세 이상 인구를 만들지 않았다.

## 소득은 가구원 원가중치로 연결했다

[공식 서울서베이 원자료](https://data.seoul.go.kr/dataList/OA-15564/F/1/datasetView.do)의 가구주·가구원 원문 XLSX를 수정 없이 읽었다. 가구 ID로 월평균 총 가구소득 구간을 가구원에 연결하고, 가구원 원가중치 `wtb1`로 20세 이상 시민이 어느 소득 구간의 가구에 사는지 계산했다. 가구주 원가중치 `wta1`로 가구 분포를 구해 개인 분포라고 부르는 방법을 쓰지 않았다. 원문 집계에서 소득 ID 연결 실패는 없다.

|조사연도|소득을 연결한 성인 가구원 레코드 수|소득 구간 수|이번에 사용하는 역할|
|---|---:|---:|---|
|2019|41,204|19|2020년 정책의 시행 이전 공변량|
|2020|38,383|19|동시기 자료 검토·민감도 분석용; 초기 주분포에는 사용하지 않음|
|2021|38,871|21|2021년 10월 정책 시행 이전 공변량|
|2024|35,192|21|2025년 정책의 시행 이전 공변량|
|2025|33,472|21|동시기 자료 검토·민감도 분석용; 초기 주분포에는 사용하지 않음|

소득은 **가구의 세전 월평균 총소득 구간**이다. 개인 월급, 개인 지갑 잔액, 하루 소비 예산 또는 소비 10분위와는 다른 변수다. 구간 안의 정확한 금액과 최상위 열린 구간의 상한을 임의로 만들지 않았다. 2019년 조사표 AQ1의 소득 기간은 2018-09-01~2019-08-31이다. 2021년은 2020-09-01~2021-08-31이다. 2024년 조사표 AQ1은 ‘지난 1년’의 세전 총 가구소득을 묻는다. 공개 소득 자료의 세부 지역은 자치구까지다.

따라서 2019·2024년의 관측 분포를 다음 해의 초기 시민 합성에 적용하는 것은 **명시적인 시점 이월 가정**이다. 2020·2025년 시행 전 달의 소득 분포를 직접 측정했다거나, 성별×연령×동×소득의 네 변수 결합분포가 실측과 완전히 같다고 주장하지 않는다. 동별 소득 합성은 자치구·성별·연령 안의 조건부 분포 가정과 민감도 검증이 필요하다.

2021년 원문 코드북에는 20개 소득 구간이 적혀 있지만 원시 데이터에는 21개 코드가 있다. 같은 ZIP의 공식 조사표를 확인하여 19번 900~950만원 미만, 20번 950~1,000만원 미만, 21번 1,000만원 이상을 사용했다. 코드 21을 무응답으로 제거하지 않았다. 코드북·조사표의 불일치와 원문 SHA는 `income_distribution_2021.json`에 보존했다.

## 목표 파일과 실제 표본은 다르다

[6개 정책 목표 매니페스트](<G:/내 드라이브/Kw/final_project/output/population_matching_20260928/policy_population_targets_manifest.json>)는 공식 분포를 계산한 단계의 증거다. 여기에는 새 시민 표본이 아직 없다. 새 모델 실행까지 남은 작업은 다음과 같다.

1. 현재 그래프의 실제 거주 POI와 정책 시점의 공식 행정동 경계를 연결한다. 현재 코드의 접두어를 잘라 원문 코드라고 부르지 않는다.
2. 정확한 나이·성별·실제 거주 anchor를 확인한 후보 시민에게 공식 소득 구간을 합성 배정한다. 소득 구간은 관측 분포로 검증하지만 각 시민의 소득은 합성값임을 밝힌다.
3. 성별·연령·행정동·소득 주변분포, 가능한 성별×연령×동 결합분포, 가중 유효 표본 수와 희소 셀을 감사한다. 빈 동을 감추거나 작은 표본을 전체 서울시와 동일하다고 말하지 않는다.
4. 새 소득이 시민 프롬프트와 정책 판정에 실제 전달되는지 전수 확인한다. 기존 정책이 소비 분위로 수혜자격을 정의했다면 소득 배선만으로 실제 자격 기준까지 바로잡았다고 주장하지 않는다.
5. 모집단·집계 기간·실측 지표 정의·평가 방법을 사전등록한 별도 출력 디렉터리에서 새 실험을 실행한다.

현재 그래프를 읽기 전용으로 전수 확인한 결과, Agent 14,881명 중 정확한 성인 나이·성별·고유한 실제 거주 anchor로 쓸 수 있는 후보는 13,771명이고 거주동은 393개다. 거주 anchor가 없는 321명, 정확한 나이가 없는 8명은 별도 입력 보완이 필요하다. ID/Agent 속성의 동과 실제 거주동이 다른 444명은 같은 구 안의 차이이며, 정확한 나이·성별·고유한 실제 anchor를 충족한 409명은 실제 거주동을 동결하여 사용할 수 있다. 이 불일치만으로 자동 탈락시킬 필요는 없다.

그러나 현재 시민 후보가 없는 동의 실측 인구는 가중치만으로 되살릴 수 없다. 누락 동 시민의 거주 anchor와 생활 환경을 새로 구축해야 한다. 또한 같은 행정동 코드가 계속 사용되었다고 경계까지 불변인 것은 아니다. 2021년 상일2동 분동은 옛 상일동을 두 개로 나눈 사건으로 단순 처리할 수 없으며 강일동의 경계도 바뀌었다. 정책 시점 경계와 현 모델 거주 위치의 정합을 별도로 확인한다. [코드·후보 지원 감사](<G:/내 드라이브/Kw/final_project/output/population_frame_sources_20260928/admin_code_population_support.json>)의 code-identity 범위를 역사적 경계 검증 완료로 읽지 않는다.

모델 입력에는 시민 자신의 환경과 소득 구간만 들어간다. 공식 목표 구성비, 정책 결과 PDF의 효과값, 목표 오차, 특정 정책에서 기대하는 방향이나 지출 증가량은 입력하지 않는다.

## 보존과 재현

원문 ZIP은 바이트 그대로 보존했다. 초기 공변량에 사용하는 2019·2021·2024년 ZIP과 목표·소득 집계 JSON은 C:와 G: 복사본의 SHA256이 일치한다. [보존 매니페스트](<G:/내 드라이브/Kw/final_project/output/population_matching_20260928/source_targets_preservation_manifest.json>)에 파일별 지문이 있다. 전체 원문은 공개 자료이며 Git에는 큰 원자료나 개인별 원시 조사 행을 올리지 않는다.

집계 도구는 `tools/build_seoul_population_frames_20260928.py`, `tools/build_policy_population_targets_20260928.py`이다. 후자는 출처 지문·기준월·허용 성별과 나이 코드·동별 남녀×17개 성인 나이 구간의 완전성을 확인하고 동·구·시 합계가 중복되지 않도록 집계한다. 기존 정책 실험 숫자와 동결 입력은 변경하지 않았다.
