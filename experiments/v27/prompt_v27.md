# 실험 v27 — DS-1 에게 분모를 준다, 그리고 그 사실을 먼저 적는다

**2026-09-22 사전등록** · **상태** 대기 · **프롬프트 v25 고정 · 볼일 규칙 제한 해제**

## 무엇을 바꾸나

볼일을 고르는 규칙에서 **임의의 제한 하나를 뺀다.**

```
전:  그 사람의 가장 큰 '서비스' 업종 (미용·건강·여가·교육 넷 중)
후:  그 사람의 가장 큰 '집 밖' 업종  (식사·마트·편의점·디저트·기타·주점 포함)
```

넷으로 좁힌 것은 **내가 쓴 제한이고 자료가 요구한 것이 아니다.** 그 탓에
서비스 지출이 0인 8명은 볼일을 아예 못 받았다.

```
전:  건강 34 · 교육 15 · 여가 3 · (없음) 8
후:  마트 27 · 식사 21 · 건강 7 · 기타 3 · 편의점 1 · 교육 1 · (없음) 0
```

## 순서를 먼저 고백한다

**이 변경은 DS-1 에 분모가 없다는 것을 안 뒤에 했다.** 그리고 실제로 분모를 준다 —
21명이 매장 식사 볼일을 받는다.

그러므로 다음을 구분해 적는다.

| 시나리오가 정하는 것 | 모델이 정하는 것 |
|---|---|
| 매장 식사 볼일이 **있다** | 그것을 **오늘 하는가** (볼일은 선택이다) |
| 몇 명에게 있는가 | 정책이 켜졌을 때 **얼마나 줄어드는가** |

**DS-1 이 재는 것은 오른쪽 열이다.** 분모를 만든 것은 나지만, 붕괴율은 모델의 답이다.

> 그래도 이 라운드의 DS-1 숫자는 **"분모를 만들어 준 뒤의 값"**으로만 읽는다.
> v18·v20·v23 의 DS-1 과 같은 줄에 놓고 비교하지 않는다.

### 주 지표 — 거리두기 칸의 매장 취식 건수

**정답지 값이 아니라 분모를 본다.**

```
기준선   v23  거리두기 무정책 팔 매장·포장 4건
성공선   무정책 팔 매장·포장 ≥ 20건
```

스무 건은 비율을 말할 수 있는 최소선으로 미리 정한다. v18 의 DS-4 가 한 건으로
[−100, −100] 을 냈고 v23 의 −75% 가 네 건 위에 섰다. **열 건 아래는 적지 않는다.**

### 부 지표 — 그때의 DS-1

주 지표를 넘었을 때만 적는다.

```
매장만으로 잰 DS-1   (실측 -14.1%)
식사 전체로 잰 DS-1  (배달 포함 — 정렬이 어느 쪽인지 아직 모른다)
```

**부호와 크기를 둘 다 적되, 어느 쪽 정렬이 맞는지는 단정하지 않는다.**
[DS1_SIGN_MATCHES_WHEN_ALIGNED.md](../DS1_SIGN_MATCHES_WHEN_ALIGNED.md) 에
적은 대로, 실측의 `음식점` 이 배달을 포함하는지 확인 전이다.

- **최적 프롬프트** — 프롬프트를 고정한다. 후보를 가르지 않는다
- **DS-1 의 판정** — 정렬이 확인되기 전에는 "맞혔다"고 적지 않는다
- **다른 여덟 지표** — 필요 표본이 지금의 40배이거나 구조적으로 못 낸다

### 왜 못 넘었나 — 볼일을 줘도 10%만 한다

볼일은 **그 활동 하나로만** 채울 수 있다. 배달로도 온라인으로도 안 된다.
그런데 계획에 들어가는 비율이 이렇다.

```
볼일로 받은 활동      계획에 들어간 칸 / 전체 칸
  groceries            26 / 216   (12%)
  meal_dine_in         18 / 168   (11%)
  health_goods          1 /  56   ( 2%)
  other_service         1 /  24   ( 4%)
  convenience           0 /   8   ( 0%)
  education_service     0 /   8   ( 0%)
  전체                 46 / 480   (10%)
```

**열 번에 한 번이다.** 볼일은 `mandatory: false` 이고, 프롬프트 9행이
미루거나 생략하는 것을 허락한다. 모델은 열에 아홉을 그렇게 한다.

같은 모델이 **근무는 92% 한다**(직업 있는 296칸 중 누락 24칸).
`mandatory: true` 와 `false` 를 분명히 다르게 다룬다.

자세한 것은 [THE_TEN_PERCENT_CEILING.md](../THE_TEN_PERCENT_CEILING.md).

### 판정

**사전등록 판정: 기각.** 무정책 팔 매장·포장 3건으로 성공선 20건에 못 미친다.
**부 지표(DS-1)는 적지 않는다** — 사전등록에 "주 지표를 넘었을 때만 적는다"고
써 두었고, 3건 위에서 비율을 말하지 않기로 한 것이 그 규칙의 이유다.

하류(게이트·수정·결제)는 계속 돌려 기록은 남기되, DS-1 판정에는 쓰지 않는다.

### 이 라운드가 가르쳐 준 것

분모가 없는 이유가 **볼일이 없어서가 아니라 볼일을 안 해서**였다.
볼일 규칙의 제한을 푼 것은 옳았지만(8명이 볼일을 못 받던 것이 0명이 됐다),
그것으로 분모가 생기지는 않는다.

**다음은 `mandatory: true` 다.** 그것이 유도가 아닌 이유는 위 문서에 적었다 —
근무·통근·재고를 지정하는 것과 같은 층위이고, **얼마나 줄어드는가는 여전히
모델이 정한다.**
