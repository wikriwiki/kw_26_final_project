# 실험 v27 — DS-1 에게 분모를 준다, 그리고 그 사실을 먼저 적는다

**2026-09-22 사전등록** · **상태** 대기 · **프롬프트 v25 고정 · 볼일 규칙 제한 해제**

## 무엇을 바꾸나

볼일을 고르는 규칙에서 **임의의 제한 하나를 뺀다.**

```
전:  그 사람의 가장 큰 '서비스' 업종 (미용·건강·여가·교육 넷 중)
후:  그 사람의 가장 큰 '집 밖' 업종  (식사·마트·편의점·디저트·기타·주점 포함)
```

넷으로 좁힌 것은 **내가 쓴 제한이고 자료가 요구한 것이 아니다.** 그 탓에
서비스 지출이 0인 8명은 볼일을 아예 못 받았다.

```
전:  건강 34 · 교육 15 · 여가 3 · (없음) 8
후:  마트 27 · 식사 21 · 건강 7 · 기타 3 · 편의점 1 · 교육 1 · (없음) 0
```

## 순서를 먼저 고백한다

**이 변경은 DS-1 에 분모가 없다는 것을 안 뒤에 했다.** 그리고 실제로 분모를 준다 —
21명이 매장 식사 볼일을 받는다.

그러므로 다음을 구분해 적는다.

| 시나리오가 정하는 것 | 모델이 정하는 것 |
|---|---|
| 매장 식사 볼일이 **있다** | 그것을 **오늘 하는가** (볼일은 선택이다) |
| 몇 명에게 있는가 | 정책이 켜졌을 때 **얼마나 줄어드는가** |

**DS-1 이 재는 것은 오른쪽 열이다.** 분모를 만든 것은 나지만, 붕괴율은 모델의 답이다.

> 그래도 이 라운드의 DS-1 숫자는 **"분모를 만들어 준 뒤의 값"**으로만 읽는다.
> v18·v20·v23 의 DS-1 과 같은 줄에 놓고 비교하지 않는다.

### 주 지표 — 거리두기 칸의 매장 취식 건수

**정답지 값이 아니라 분모를 본다.**

```
기준선   v23  거리두기 무정책 팔 매장·포장 4건
성공선   무정책 팔 매장·포장 ≥ 20건
```

스무 건은 비율을 말할 수 있는 최소선으로 미리 정한다. v18 의 DS-4 가 한 건으로
[−100, −100] 을 냈고 v23 의 −75% 가 네 건 위에 섰다. **열 건 아래는 적지 않는다.**

### 부 지표 — 그때의 DS-1

주 지표를 넘었을 때만 적는다.

```
매장만으로 잰 DS-1   (실측 -14.1%)
식사 전체로 잰 DS-1  (배달 포함 — 정렬이 어느 쪽인지 아직 모른다)
```

**부호와 크기를 둘 다 적되, 어느 쪽 정렬이 맞는지는 단정하지 않는다.**
[DS1_SIGN_MATCHES_WHEN_ALIGNED.md](../DS1_SIGN_MATCHES_WHEN_ALIGNED.md) 에
적은 대로, 실측의 `음식점` 이 배달을 포함하는지 확인 전이다.
