# 실험 기록

실험 한 회 = 폴더 하나. 각 폴더에 두 파일이 들어간다.

| 파일 | 내용 |
|---|---|
| `prompt_vN.md` | **맨 위에 이번에 바뀐 점과 눈여겨 볼 점.** 그 아래 사전등록(설계·지표·판정 기준)과 쓴 프롬프트 전문 |
| `graph_vN.md` | 정책별 결과 비교 그래프와 수치표. 결과가 나오기 전에는 "대기"로 둔다 |

## 읽는 법

- `prompt_vN.md` 의 **바뀐 점**만 훑으면 실험이 어디로 가고 있는지 보인다
- `graph_vN.md` 의 막대는 **0을 가운데 둔 발산형**이다. 왼쪽이 감소, 오른쪽이 증가
- 수치는 전부 `data/experiments/scoring_table.json` 과 각 런의 원문에서 온다. 손으로 적지 않는다

## 폴더 번호와 프롬프트 번호는 다르다

헷갈리기 쉬워서 못 박는다. **폴더 `v1`은 첫 번째 실험**이지 프롬프트 v1이 아니다.
각 폴더의 `prompt_vN.md` 머리에 이번에 쓴 프롬프트 이름을 따로 적는다.

| 실험 폴더 | 쓴 프롬프트 |
|---|---|
| `v1` | 계획 `v25` · 결제 `asset_transaction_v7` (프롬프트 변경 없음, 배관만 바뀜) |
