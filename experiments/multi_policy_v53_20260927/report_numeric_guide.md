# v53 정책별 숫자 비교 보고서

`scripts/report/build_experiment_comparison.py`의 `--multi-policy-pairs`는 정책별
`multi_policy_numeric_v1` 산출물을 여러 번 받을 수 있습니다. 각 산출물의 실험명,
프롬프트 버전, 채점표 지문, 원장 파일 SHA256을 확인한 뒤
`empirical_registry.json`의 실측 수치와 합칩니다. 서로 다른 날짜의 원실험을
한 대시보드에 모을 때는 `--experiment`로 대시보드 이름을 명시하고, 원실험명은
정책별 행과 JSON `source_experiments`에 남깁니다.

HTML 제목은 `v53 기준선`입니다. 범용 프롬프트 최적화의 출발점이며
최적화 완료나 정책 효과 크기 검증 성공을 뜻하지 않습니다. 정책별 시뮬 시민
수와 지표별 분모를 함께 표시합니다. 캐시백 지급액·상한 도달률의 지표 `n`은
전체 시민 수가 아니라 양의 캐시백 수령자 수입니다. 12명 이하 월간 실험은
방향과 크기가 매우 불확실하다고 표시합니다. 표시된 95% 구간은 합성 시민
재표집만 반영하며 모델 반복 생성이나 외부 표본 불확실성은 포함하지 않습니다.
정책별 범용 프롬프트 지문이 모두 존재하고 같을 때에만 동일 바이트 v53
프롬프트라고 표시합니다. 정책 입력 파일·환경 ID·시행 기간은 scorer
산출물에 근거가 있을 때만 표시합니다. 모델 요청의 ID가 alias인 경우
실제 서빙 가중치로 취급하지 않습니다.
실제 서빙 모델은 ON/OFF 서버 스냅샷이 각각 SHA256으로 확인되고 스냅샷의
모델 ID와 서버 실행 명령이 일치하는 신규 팔에서만 정책 카드에 표시합니다.
신규 정책 카드에는 각 팔의 Stage1 첫 기록 내부검증, 외부 재시도 회복,
최종 원장 완결, Stage2 fallback·선택 보정을 분리합니다. 첫 기록 이력이
빠진 시민×일은 성공으로 간주하지 않고 가능한 통과율 범위를 표시합니다.
원시 첫응답의 엄격 형식률은 별도 검사 없이는 알 수 없습니다. 시행 전
ON/OFF 균형 관문이 실패하거나 사전등록되지 않았으면 인과효과 해석을
보류합니다. P013 과거 팔의 생성 품질은 신규 감사가 없어 숫자를 추측하지 않습니다.

```powershell
py -3 scripts/report/build_experiment_comparison.py `
  --multi-policy-pairs output/p013_v53_pilot_20260927/multi_policy_numeric_v1.json `
  --multi-policy-pairs output/<p010-run>/multi_policy_numeric_v1.json `
  --multi-policy-pairs output/<distancing-run>/multi_policy_numeric_v1.json `
  --p010-funding-audit output/multi_policy_v53_20260928/p010/funded_by_sub_audit.json `
  --p010-channel-audit output/recovery_20260928/multipolicy_v53/p010/p010_channel_gap_audit.json `
  --p010-concentration-audit output/recovery_20260928/multipolicy_v53/p010/p010_citizen_gap_concentration_audit.json `
  --p012-sector-audit output/multi_policy_v53_20260928/p012/sector_denominator_display_audit.json `
  --distancing-input-audit experiments/multi_policy_v53_20260927/distancing_render_audit_20260928.json `
  --in-progress-policy P012 `
  --experiment multi_policy_v53_20260928 `
  --out output/report/experiments/multi_policy_v53_20260928.html
```

정책이 끝날 때마다 **완료된 정책 파일만** 추가해 새 이름으로 출력합니다.
`--out`의 `.html`과 같은 경로에 `.json`도 생성됩니다. P012, P016 등의
산출물을 같은 방식으로 추가할 수 있습니다. 과거 r2/v5 채점 파일은 v53
숫자 보고서에 넣지 않습니다.
`--in-progress-policy`는 실제 실행 중인 정책만 명시합니다. 해당 정책은
숫자 없는 지표 행이나 빈 값 대신 확보 현황에 `진행 중`으로 표시합니다.
완료된 정책 scorer를 추가할 때 이 옵션을 제거합니다. 완료 뒤에도 시뮬
수치가 구조상 미산출된 지표는 실측 숫자와 분자·분모를 만들 수 없는
구체적인 사유를 접힌 현황에 표시합니다.

P012-6의 이번 v53 월말 **발생추정**은 상한 도달 0/11 수령자입니다.
시민 재표집 구간 [0, 0]은 성공 관측이 0명이라 퇴화한 값으로, 상한
도달률이 실제로 0이라는 증거가 아닙니다. 독립 이항 표본이라는 단순
가정 아래 Clopper–Pearson 양측 95% 상한은
`100×[1−0.025^(1/11)] = 28.49%`입니다. 보고서는 원자료 월말 JSON
SHA256·수령자 분모·0명 관측을 확인했을 때만 이 **참고 불확실성**을
표시하며 10월 실측 약 20.87%와의 산술 차이를 생략합니다.
모델 반복 변동과 실제 인구 표본오차, 익월 지급 관측은 반영하지 않습니다.

같은 단위이거나 로그계수를 `100×(exp(계수)−1)%`로 변환할 수 있는 경우
`탐색적 숫자상 차이`와 대략적인 규모를 표시합니다. 이는 서로 다른 모집단,
관측기간, 분모, 대조군에서 나온 숫자의 산술 차이이며 정책 효과의 오차,
적중률, 최적 프롬프트 판정이 아닙니다. `%`와 `%p`처럼 차원이 다른
두 값은 차감하지 않습니다. 직접 효과 차이는 독립적인 원문·실험 창·추정량
감사가 통과한 경우에만 별도 필드로 출력됩니다. 현 v53 보고서에서는
직접 차감 가능한 지표가 없습니다.

실측 registry와 이 보고서는 실험 **평가 단계에서만** 읽습니다. 시민 프롬프트나
모델 요청에는 주입하지 않습니다. 원시 원장과 정책별 scorer 산출물은 수정하지
않고 정책별 파일 SHA256을 보고서 JSON에 보존합니다.
