# v50 결과 — 관문을 20.6%p 올린 프롬프트가 정답지에서는 v5 를 이기지 못했다

**2026-09-23 00:34 종료** · 거리두기 12일 창 · 200명 · v5 대 v45 · 판정기는 **결과 전에 고정**했다

## 등록된 판정

```
지표      실측        v5        v45      더 가까운 쪽    |시뮬−실측|
DS-1    -14.1%     -7.2%     -8.1%        v45        6.9 → 6.0
DS-2     +4.2%     +0.4%     -7.1%        v5         3.8 → 11.3
DS-3     순위       적중       적중         동률          —
DS-4       —       -8.7%    -15.8%         —      (실측값 없음)
```

**사전등록한 합격선은 "DS-1·DS-2 가 둘 다 실측에 가까워질 것"이었다. 갈렸다.**

> v45 가 더 가깝다 → 거시 현행을 v45 로 올린다
> v5 가 더 가깝다 → v5 유지
> **비슷하다·갈렸다 → v5 유지. 바꿀 근거가 없다**

**→ v5 유지.**

## 무엇을 읽을 수 있고 무엇을 읽을 수 없는가

이것도 **결과 전에** 적어 두었다([v5_replication.md](v5_replication.md)).

```
DS-1   두 팔의 이동 0.9%p · 런 간 이동 0.2%p   → **읽는다**
DS-2   두 팔의 이동 7.4%p · 런 간 이동 13.1%p  → **런으로도 설명된다. 근거로 쓰지 않는다**
```

검정력 역산도 같은 답을 냈다 — DS-2 를 0 과 가르려면 약 10,000명이 필요한데
이 라운드는 200명이다([SAMPLE_IS_THE_BINDING_CONSTRAINT.md](../SAMPLE_IS_THE_BINDING_CONSTRAINT.md)).
**서로 다른 두 방법이 같은 자리를 못 읽는다고 말한다.**

그래서 **이 판정이 실제로 기대는 증거는 DS-1 하나**다. 거기서 v45 가 0.9%p 가깝다.
그리고 등록된 규칙은 한 지표로 채택하지 않는다.

## 사전등록한 예측과 대조

> v45 가 **조금 가깝거나 비슷할 것이다.** 두 가능성이 모두 그럴듯하므로
> 구간을 좁게 적지 않는다.

**DS-1 에서는 맞았고(조금 가까워졌다) DS-2 에서는 틀렸다.** 예측을 넓게 적어 둔
것이 유리하게 작용하지 않도록 적어 둔다 — **넓은 예측은 맞히기 쉽다.**
이 라운드에서 실제로 확인된 것은 "둘 다 가까워지지는 않았다" 하나다.

## 적어 둘 관측 하나 — DS-3 이 같은 '적중'이 아니다

```
v5   쇼핑+마트 +0.4%  vs  식사 -7.2%    부호가 갈린다
v45  쇼핑+마트 -7.1%  vs  식사 -8.1%    둘 다 내려가고 소매가 덜 내려갔다
```

DS-3 은 "**제약이면 다 줄어든다**로 수렴한 프롬프트를 잡는" 지표로 등록됐다.
채점상 둘 다 적중이지만, **v5 는 부호가 갈려서 통과했고 v45 는 덜 줄어서
통과했다.** 실측의 구조는 음식점 −14.1% 대 소매 **+4.2%** 로 부호가 갈린다.

**다만 이 관측은 DS-2 값에 기대어 있고, 그 값은 위에서 읽지 않기로 한 것이다.**
그러므로 이것을 v45 의 성질로 적지 않는다. 다음 라운드에서 표본을 키워 다시 본다.

## 이 라운드가 답한 것과 답하지 못한 것

**답한 것.** 관문(형식 계약)을 68.0% → 88.6% 로 올린 것이 **정답지 수렴으로
이어지지 않았다.** v45 를 정답지에 대고 잰 것은 이번이 처음이고, 등록된 규칙에서
v5 를 이기지 못했다.

**답하지 못한 것.**
- **크기 검증이 아니다.** 원문 창은 40주이고 우리 창은 이틀이다(`audit_2026_09_20`)
- **한 런이다.** DS-1 의 0.9%p 는 런 간 이동(0.2%p)보다 크지만 한 번의 관측이다
- **DS-2 는 이 표본으로 못 잰다.** 프롬프트 탓인지 잡음인지 가를 수 없다

## 규칙대로 한 것
