## 같은 칸끼리 맞대면 — 논리적으로 불가능한 답이 나온다

같은 시민·같은 날·같은 시드, **SYSTEM 만 다른** 48칸을 짝지었다.

```
좁은 질문 (배송만)          평균 0.1448 · 중앙 0.1500
넓은 질문 (동네 밖 전부)     평균 0.1427 · 중앙 0.1500
차이                        -0.0021 · 양측 부호검정 p=0.711  구별 안 됨

쌍별   넓을 때 더 큼 16 · 더 작음 13 · 같음 19
```

**넓은 질문의 집합이 좁은 질문의 집합을 포함한다.** 배송은 "동네 밖" 의
부분집합이므로, 앞뒤가 맞는 응답자라면 **넓은 답 >= 좁은 답**이어야 한다.

```
더 작음 13/48 (27%)   논리적으로 불가능하다
같음    19/48 (40%)   집합이 더 큰데 같은 수를 적었다
```

즉 모델은 **집합을 따져서 답하는 것이 아니다.** ~0.15 를 적고 있을 뿐이다.

## 그러므로 사전등록한 중단 조건이 걸린다

> `amend_01_scope.md` — 넓힌 판의 천장이 여전히 18.92%p 보다 작으면 본런을
> 돌리지 않고 **구조적 한계로 보고한다**

```
천장 +17.0%   <   메워야 할 간격 18.92%p        → 중단
```

**본런을 돌리지 않는다.** 7.5시간 × 500명을 아낀다.

## 중단 사유를 정직하게 적는다 — 등록한 것보다 강한 근거가 나왔다

등록한 조건은 "천장 < 간격" 이라는 **산술** 조건이었다. 그런데 실제로 나온
것은 그보다 강하다 — **필드가 질문의 내용을 안 듣는다.** 범위를 3배 넓혀도
답이 안 바뀌고, 27%는 집합 논리에 어긋난다.

질문의 뜻에 반응하지 않는 필드가 **정책에는 반응하리라고 볼 근거가 없다.**
이것은 이미 겪은 것과 같은 모양이다 — P010 역진의 벽에서 "서술 프롬프트는
무효, 계산된 사실에만 반응" 을 확인했다. `daily_propensity` 가 예시 숫자
0.72 근처(0.68)에 54% 몰리는 것도 같은 결의 현상이다.

**다만 한 가지는 분명히 해 둔다.** 이 판정은 *질문 범위에 대한 무반응*과
등록된 산술 조건에서 나온 것이지, **정책 유무를 직접 맞대어 본 것이 아니다.**
직접 보려면 정책이 켜진 맥락이 필요한데 그것은 그래프에서만 만들어지므로
탐침으로 못 만든다. 그 한계를 그대로 적는다.
