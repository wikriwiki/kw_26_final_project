## 무엇을 바꾸나 — 셋뿐이다

```
1 회계   offline = (anchor / 2.40) x share     한 상수가 하던 두 일을 가른다
         (max 뒤에서 나눈다 — 어느 항이 이기는지는 안 변한다)
2 프롬프트 v5online = v5 + "오늘 산 것을 어디서 샀나" 한 항목 (+410자)
3 눈금   P012-2(제외업종)를 st.online_spent 로 잰다
```

**3 을 왜 바꾸나.** 정답지의 제외업종은 백화점·대형마트·온라인이다. 우리
그래프에는 그 POI 가 337개(0.06%)뿐이고 온라인은 아예 없다. 지금 P012-2 가 재는
것은 새어 나온 1.35%(84행) 잔여물이다. 그 뭉치는 `st.online_spent` 에 **이미
매일 적히고 있다** — 눈금을 거기로 옮긴다. 자를 바꾸는 것이지 답을 바꾸는 게 아니다.

## 순서와 중단 조건

```
가  교정 탐침   정책 없는 동결맥락 96 호출 · v5online
                 (a) online_share 응답률 >= 90% 여야 한다. **미만이면 중단한다.**
                 (b) mean(1 - online_share) 를 재서 KEEP_MEAN 으로 **얼린다**
나  항등 관문   1일 x 200명 · v5(= online_share 없음) + SPLIT=1
                 personal_total 중앙이 현행과 ±1% 안. 벗어나면 배선이 틀린 것이다
다  본런        P012 · v5online + SPLIT=1 + 얼린 KEEP_MEAN
라  위약        정책 창 밖 같은 길이 창에서 share 분포가 안 움직여야 한다
```

## 미리 적는 예측 — 셋 다 틀릴 수 있다

```

  예측  **커진다.** 다만 P012-1 의 런 간 이동이 8.2%p 이므로
        그보다 적게 움직이면 **읽을 수 없다**고 적고 판정을 보류한다

P012-2 제외업종   현행 시뮬 -13.90% 실측  +2.85%  오차 16.75%p
  예측  **부호는 안 고쳐진다.** 1층(총액)이 여전히 상수이므로 적립이 오르면
        제외는 내린다. 실측은 둘 다 올랐다 — 그 모양은 총액이 커져야 나온다.
        눈금을 옮겨 크기가 제대로 잡히므로 **오차의 크기는 줄 수 있다**

  판정  **총 오차가 줄어야 성공이다.** P012-1 만 좋아지고 P012-2 가 그만큼

```

## 무엇이 이 가설을 죽이나

```
· 교정 탐침에서 online_share 가 정책 유무와 무관하게 같은 값이면
  → 2층도 죽은 레버다. 수리를 접고 **"이 모델로는 상생 기전을 표현할 수
    없다"** 를 결론으로 보고한다. 그것도 답이다
· 항등 관문이 ±1% 를 벗어나면 → 수준을 건드린 것이므로 본런을 돌리지 않는다
· 위약 창에서 share 가 움직이면 → 정책이 아니라 시간이 움직인 것이다
· 총 오차가 안 줄면 → 기각. v5 + 현행 회계로 되돌린다
```

## 순환이 아님을 미리 못 박는다

바꾸는 것은 "오늘 산 것을 어디서 샀나" 라는 **행동 질문**이고, 재는 것은 원장과
State 의 금액이다. 측정 공식(순효과·MPC·소진율)도, 목표 수치도, 방향을 지시하는
문장도 프롬프트에 없다 — 시험 6개가 막는다(`test_v5online_variant.py`).
KEEP_MEAN 은 **무정책 맥락에서 한 번 재고 얼린다**. 팔마다 다시 재면 정책이 만든
이동이 정규화로 지워진다.

## 이번에 안 여는 것 — 미리 밝힌다

1층(총액)은 그대로 둔다. 앵커를 `max` **앞**에서 나누면 계획이 이기는 비율이
0.7% → **63.9%** 로 뒤집혀 1층이 열리지만, 수준이 **+40.7%** 올라 참 앵커
(서울 개인카드 실적으로 잡은 52,462원/일)를 41% 넘어선다. 계획 단가 자체를
다시 보지 않고는 채택할 수 없다. 그래서 `EXP_ANCHOR_BEFORE_MAX` 로 **재려고만**
열어 두고 이번 판정에는 쓰지 않는다.

또한 온라인 뭉치는 **크기만** 있고 업종 구성이 없다. "제외업종 안에서 어느
업종이" 는 이번에도 못 잰다. 보고서에 한계로 적는다.
