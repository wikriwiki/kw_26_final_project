# 실험 v5 — 프롬프트는 그대로 두고, 사실을 어디에 쓰는지만 바꾼다

**날짜** 2026-09-20 · **상태** 완료 — **실패. 그런데 위약군이 더 큰 것을 알려줬다**

---

## 이번에 바뀐 점

**프롬프트를 바꾸지 않는다.** v3·v4 에서 프롬프트 문장을 세 번 바꿨고 세 번 다
아무 일도 일어나지 않았다.

| 라운드 | 바꾼 것 | 결과 |
|---|---|---|
| v3 · v26 | 제도를 2단으로 읽으라는 설명 추가 | 실패 |
| v3 · v27 | 제도 문장 제거 (하한) | 영점 |
| v4 · v28 | 필요를 어디서 채울지 고르라고 함 | 실패 |

그래서 이번에는 **같은 사실을 어디에 쓰느냐**만 바꾼다.

## 왜 이 축인가

지갑의 사용 규칙은 지금 두 군데에 서로 다르게 들어 있다.

```
조건 블록      "· [쿠폰] 표시 POI에서만 사용"   ← 그 표시는 입력 어디에도 없다
구매 후보 JSON  wallet_acceptance: 9개 zone × 13개 활동   ← 결제가 실제로 쓰는 규칙
```

한쪽은 **존재하지 않는 표시를 찾으라 하고**, 다른 쪽은 **JSON 안에 파묻혀 있다.**

한편 **캐시백만은 조건 블록에 숫자로 들어 있고**(`threshold_won`), v4 에서
on−off 도달 격차가 가장 컸다(+0.125 / +0.104). 지원금은 자격이 파묻혀 있고
격차가 가장 작았다(+0.021 / −0.021).

**이것은 기전 넷을 늘어놓고 본 관찰이지 검정이 아니다.** 자리 탓인지 정책 내용
탓인지 그 자료로는 못 가른다. **v5 가 그것을 가른다.**

## 무엇을 바꾸나 — 정확히 이것만

`surface_wallet_acceptance` 플래그 하나다. 켜면 조건 블록이 이렇게 된다.

```
- P013 [정책지갑 지급] | ... | 세부 업종 조건은 정책 본문 참조
  배경: (그대로)
  P013 사용처: zone:11290685, zone:11290660, ... 에서의 meal_dine_in, groceries, ...
  에서만 받는다. 다른 장소·활동에서는 이 자금으로 결제할 수 없다.
```

그리고 가리킬 곳 없는 `· [쿠폰] 표시 POI에서만 사용` 을 지운다. 규칙이 둘이면
안 되기 때문이다.

**입력에 없던 것을 만들지 않는다.** 저 zone 과 활동 목록은 이미 같은 입력의
`wallet_acceptance` 에 있던 값 그대로다. 방향도, 수치 목표도, 정책 성과도 더하지 않는다.
검사가 강제한다(`test_nothing_is_invented_beyond_the_preview`).

## 눈여겨 볼 점

**① 내장 위약군이 있다.** 96칸 중 **24칸만 바뀐다** — 지원금 on 12칸, 지역화폐 on 12칸.
나머지 **72칸은 글자 하나 다르지 않다.** 캐시백·거리두기는 지갑이 없고, off 팔은
정책이 없기 때문이다.

```
캐시백 off/on   그대로 12/12      지원금 off 그대로 12 · on 바뀜 12
거리두기 off/on  그대로 12/12      지역화폐 off 그대로 12 · on 바뀜 12
```

**바뀐 칸만 움직이고 안 바뀐 칸은 가만히 있어야 한다.** 둘 다 움직이면 그건
이 축의 효과가 아니라 잡음이다. v3·v4 에는 없던 대조다.

**② 프롬프트가 같으므로 프롬프트 탓이 아니다.** 양쪽 다 v25 다. 차이가 나오면
문장이 아니라 **사실이 놓인 자리**가 원인이다.

## 사전등록 — 돌리기 전에 정한다

| | 내용 |
|---|---|
| 설계 | 같은 12명 × 4기전 × on/off = 96칸, **seed 4개**(61001~61004), 두 팔 = 계획 768칸 |
| 팔 | **대조**(`surface_wallet_acceptance: false`) · **처치**(`true`). 프롬프트는 양쪽 v25 |
| 계획 | thinking 512 / answer 2048, 온도 0.2, 게이트 활성 |

### 출발점 (v4 에서 잰 값, 같은 규칙)

```
                on 도달 (4 seed, 48칸씩)
지원금            3/48  0.062      ← 바뀌는 칸
지역화폐          6/48  0.125      ← 바뀌는 칸
캐시백            8/48  0.167      ← 안 바뀌는 칸 (위약)
거리두기          4/48  0.083      ← 안 바뀌는 칸 (위약)

전체 on 0.109 (SD 0.046) · off 0.047 (SD 0.039)
```

### 판정

**주 지표 — 바뀌는 칸(지원금 on + 지역화폐 on, 96칸)의 도달 비율**

| | 기준 |
|---|---|
| **성공** | 처치 팔이 대조보다 높고, 그 폭이 **seed 변동 폭을 넘는다** |
| **실패** | 폭 안이다 — 자리를 바꿔도 안 문다 |
| **무효** | **안 바뀌는 칸(위약)도 같이 움직이면** 이 축의 효과가 아니다. 성공으로 세지 않는다 |

마지막 줄이 v4 의 "off 도 같이 올랐다"에 해당하는 안전장치다. 이번에는 위약군이
**구조적으로** 보장되므로 더 강하다.

**부 지표** — 정책 자금으로 실제 쓴 돈(`concession_funded_consumption`).
v4 까지 지갑의 0.3% 였다. 도달이 올라가면 여기가 따라 올라와야 앞뒤가 맞는다.
**따라 오지 않으면 도달만 늘고 결제는 그대로라는 뜻이고, 그것도 결과다.**

### 하면 안 되는 것

- 실측 부호·크기와 맞는 쪽 고르기 — 순환 검증이다
- 도달이 올랐다고 "정답에 가까워졌다"고 말하기 — **도달은 필요조건일 뿐이다**
- 위약군이 같이 움직였는데 주 지표만 보고 성공이라 하기

### 이 실험이 답하지 않는 것

- 최적 프롬프트가 무엇인지 — 이번엔 프롬프트를 아예 안 건드린다
- 모집단 일반화 — 12명이다
- 실제 정책 효과의 크기 — 추정량 정렬이 끝나지 않았다

## 결과 — 실패. 그리고 위약군이 이 실험 전체를 다시 읽게 한다

수치는 [graph_v5.md](graph_v5.md). 두 팔 모두 계획 **384/384 유효**, 게이트 제외 0.

```
                          대조      처치     차이    변동폭
바뀐 칸 (지원금·지역화폐 on)   0.167    0.177   +0.010   0.092
위약 (캐시백·거리두기 on)     0.083    0.177   +0.094   0.142
off 팔 전체                0.073    0.073   +0.000   0.050
```

**주 지표는 실패다.** 자리를 바꿔도 도달이 안 는다(+0.010, 변동폭 안).
부 지표도 같다 — 정책 자금 사용이 2,083원 → 1,583원으로 **오히려 조금 낮다**.
지갑 280,000원의 0.6~0.7%인 것은 그대로다.

### 위약군이 말한 것

```
바뀐 칸   +0.010   ← 실제로 입력이 달라진 24칸
위약 칸   +0.094   ← 두 팔 사이에 글자 하나 다르지 않은 칸
```

**글자 하나 다르지 않은 칸이 바뀐 칸보다 9배 크게 움직였다.**

이것은 가정 없이 직접 잰 잡음 바닥이다. 같은 입력을 다시 넣어도 도달 비율이
이만큼 흔들린다. **지금까지 재려던 모든 효과가 이 바닥 아래에 있다.**

off 팔이 +0.000 으로 완벽히 붙은 것은 파이프라인이 샌 것이 아님을 보여 준다.
정책이 없는 칸은 두 팔에서 똑같이 나왔다. **설계는 옳았고, 잴 힘이 없었다.**

### 얼마나 키워야 하나

도달 비율이 0.17 근처이므로 한 seed·24칸의 표준편차가 √(p(1−p)/n) ≈ 0.077 이고,
관측된 흔들림과 맞는다.

| 보려는 도달 차이 | 필요한 칸 수(한 팔) | 지금 대비 |
|---:|---:|---:|
| +0.20 | 56 | 2배 |
| +0.10 | 224 | 9배 |
| +0.05 | 894 | 37배 |

칸 = 사람 × 날 × 기전. 사람을 늘리든 날을 늘리든 같다.

### 이번 라운드가 답한 것과 답하지 못한 것

**답한 것** — "사실을 조건 블록에 올리면 무는가"는 **이 표본에서는 모른다.**
+0.010 은 잡음 바닥 0.094 안이라 있음도 없음도 말할 수 없다.

**답하지 못한 것** — 캐시백이 도달 격차가 컸던 이유. 자리 탓인지 내용 탓인지
가르려 했는데, **잣대가 너무 무뎌서 가르지 못했다.** 가설은 살아 있지만 미검정이다.
