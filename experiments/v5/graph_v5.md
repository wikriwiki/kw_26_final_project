# 실험 v5 — 정책별 결과 비교

> 두 팔의 **프롬프트가 같다**(v25). 다른 것은 지갑 규칙이 조건 블록에 있느냐뿐이다.
> 값은 기록된 근거 파일에서 계산했다.

## 도달성 — 바뀐 칸과 안 바뀐 칸을 함께 본다

```
                           대조          처치     
바뀐 칸 (지원금·지역화폐 on)       0.167       0.177       차이 +0.010
위약 (캐시백·거리두기 on)         0.083       0.177       차이 +0.094
off 팔 전체                 0.073       0.073       차이 +0.000
```

> 실패 — 차이가 seed 변동 안이다. 자리를 바꿔도 안 문다

### 위약군이 말해 주는 것 — 이번 라운드의 진짜 결과

```
바뀐 칸   차이 +0.010   ← 실제로 입력이 달라진 24칸
위약 칸   차이 +0.094   ← 두 팔 사이에 글자 하나 다르지 않은 칸
```

**글자 하나 다르지 않은 칸이 +0.094 움직였다. 바뀐 칸(+0.010)의 9배다.**

이것은 가정 없이 직접 잰 잡음 바닥이다. 같은 입력을 다시 넣으면 도달 비율이
이만큼 흔들린다는 뜻이고, **지금까지 재려던 모든 효과가 이 바닥 아래에 있다.**

off 팔이 +0.000 으로 완벽히 붙어 있는 것은 파이프라인이 샌 것이 아님을 보여 준다 —
정책이 없는 칸은 두 팔에서 똑같이 나왔다.

### 그래서 얼마나 키워야 하나

도달 비율이 0.17 근처이므로 한 seed 의 표준편차는 대략 √(p(1−p)/n) = 0.077 (n=24칸) 이다. 관측된 흔들림과 맞는다.

| 보려는 도달 차이 | 필요한 칸 수(한 팔) | 지금(24칸) 대비 |
|---:|---:|---:|
| +0.20 | 56 | 2배 |
| +0.10 | 224 | 9배 |
| +0.05 | 894 | 37배 |

양측 5% · 검정력 80% · 두 팔 비교 기준. **칸 = 사람 × 날 × 기전**이므로
사람을 늘리든 날을 늘리든 같은 값이다.

## 부 지표 — 정책 자금 사용

```
            대조      처치
지원금     2,083원   1,583원      지갑 280,000원의 0.6~0.7%
지역화폐       0원       0원
```

**자리를 바꿔도 지갑은 그대로 안 쓰인다.** 처치 쪽이 오히려 조금 낮지만 잡음 안이다.
