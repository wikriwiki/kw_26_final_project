# v51 생산 온도 형식 전이 사전등록 (2026-09-26)

이 등록은 결과 호출 전에 고정했다. 선행 v51·v52 실험에서 v51은 temperature 0의 Stage1 원시 형식 관문을 통과했지만, 실제 Stage1 첫 호출은 temperature 0.7이다. [원시 응답 감사](../../docs/V51_V52_FORMAT_SCREEN_20260926.md)의 v45 360/384, v51 375/384와 짝지은 p=0.0059246은 0.7이나 정책 효과 크기로 전이된 증거가 아니다.

## 입력과 호출

- 모델 `LGAI-EXAONE/EXAONE-4.5-33B-AWQ`, `enable_thinking=False`, `max_tokens=2200`, temperature **0.7**, 작업자 24. Stage1의 첫 응답만 원문 그대로 채점하고 생산 재시도·후처리로 고친 결과를 통과로 세지 않는다.
- [설정](../../data/experiments/validation_v51_prodtemp_20260926.json)의 후보는 v45와 v51뿐이다. 앞 실험에서 보존한 **동일 12명 × 네 기전 × ON/OFF × 네 seed = 후보당 384칸**, 총 768호출이다. `prepare_reused_prompt_pilot.py`가 기존 동결 입력 96개와 프롬프트 본문을 그대로 가져오고, 컨텍스트·모델·날짜·팔·seed·토큰 상한이 달라지면 실패한다. 정책·배경은 기존 별도 입력 채널을 사용한다.
- 원시 `responses.jsonl`, 동결 입력, 설정·코드·프롬프트 지문, 요청 실패와 토큰 사용량을 보존한다. 등록한 모든 칸을 한 번씩 끝내며 유의성에 따른 조기 중단·조용한 재시도·불리한 시민 제외는 하지 않는다.
- 현재 A100의 P012 28일 런과 동시 추론하지 않는다. 그 런의 마지막 날짜 및 그래프·실행 코드 백업을 확인한 뒤 별도 깨끗한 체크아웃에서 호출한다. 출력은 별도 경로에 쓰고 두 곳에 복사·SHA256을 확인한다.

## 판정

v51을 **다음 기술 점검 후보**로 올리는 필요조건은 양쪽 384칸 완전성, v51 원시 엄격 통과율 95% 이상, v45보다 zone 위반 감소, v45보다 높은 엄격 통과 수와 짝지은 정확 양측 McNemar p<0.05, 요청 실패 0건, 재정 ON/OFF 중 OFF에서 허위 정책 귀속 0건이다. 하나라도 미달하면 실패 원문을 보존하고 별도 후보를 등록한다. 통계적으로 유의하지 않다는 사실을 동등성 증거로 해석하지 않는다.

통과해도 이는 **12명의 알려진 개발 사례에 대한 Stage1 형식**만 뜻한다. Stage2의 무보정 장소 선택·실현 거래·정책 원장과 ON/OFF 효과의 방향·대략적 크기는 후속 독립 관문이다. P015는 이미 사용되어 재실험하지 않는다. 이 파일과 공통 프롬프트에는 정책별 실측 효과의 부호·수치를 넣지 않는다.

준비 후 `PYTHONHASHSEED=0 python scripts/sim/validate_prompt_v3.py --config data/experiments/validation_v51_prodtemp_20260926.json --out <동결 출력 폴더>`로 실행한다. 준비된 로컬 폴더 `output/validation_v51_prodtemp_frozen_v3_20260926`의 설정 digest는 `9f102eb05e39869938719e977b342c386fe6ab62f3c072a1dff762f14cbed5fb`, 동결 입력 digest는 `12bf485e9028de59fa41c65d552f9cb3851fb1cecc900c919c77d328d0ee6469`다. 실행 전에 이 둘과 실제 서빙 모델, 코드 지문을 다시 확인한다.

## 2026-09-26 실행 전 소스 지문 보정

모델 호출 전에 v3 동결본을 검사하니 설정·96개 컨텍스트·v45/v51 프롬프트 본문·실행 스크립트 지문은 그대로였지만, 동결 뒤 `scripts/sim/income.py` 한 파일의 지문이 바뀌었다. 원래 v3 동결본을 보존하고 중간 v4 동결본을 만들었다. 이어 실행기가 매니페스트의 **전체 소스·프롬프트 지문을 실제 호출 전에 강제 확인**하도록 보강했으므로, 보강된 실행기로 최종 **v5 동결본** `output/validation_v51_prodtemp_frozen_v5_20260926`을 만들었다. 설정 digest `9f102eb05e39869938719e977b342c386fe6ab62f3c072a1dff762f14cbed5fb`와 입력 digest `12bf485e9028de59fa41c65d552f9cb3851fb1cecc900c919c77d328d0ee6469`는 v3~v5 모두 동일하다. 실제 실행은 **v5 폴더**를 쓰며, 코드가 다시 바뀌면 호출을 거부한다. 세 동결본 모두 아직 `responses.jsonl`이 없어 결과를 본 뒤 입력이나 기준을 바꾼 일이 아니다.
