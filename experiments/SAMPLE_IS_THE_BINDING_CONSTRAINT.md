# 지금 표본으로는 정답지 값을 검출할 수 없다 — 지표 10개 중 8개가

**2026-09-22 22:05** · `scripts/report/power_to_detect_truth.py` · 채점표의 구간에서 역산

---

## 왜 이걸 쟀는가

거리두기는 **프롬프트를 한 글자도 고치지 않고** n 을 200 → 500 으로 올린 것만으로
부호 적중이 1/4 에서 3/4 이 됐다. 표본이 모자라면 어떤 프롬프트를 써도 수렴을
보여줄 수 없다는 뜻이다. 그래서 후보를 더 만들기 전에 **검출력부터** 쟀다.

## 숫자

각 정책의 가장 큰 n 을 쓴 라운드에서, 95% 구간을 표준편차로 되돌려
"정답지 효과를 0 과 가르려면 몇 명이 필요한가"를 계산했다.

```
정책            지표      실측%     n      필요 n    지금의 몇 배
거리두기         DS-1     -14.1    493       155    충분 ✔
상생소비 P012    P012-4       —    200       144    충분 ✔
상생소비 P012    P012-1   +20.8    200       231    1.2배
거리두기         DS-4         —    311       378    1.2배
긴급재난 P013    EM-2     +11.1    200       278    1.4배
지역상품권 P014   LV-1         —    495       790    1.6배
긴급재난 P013    EM-3      +7.3    200       615    3.1배
지역상품권 P014   LV-3         —    495     2,980    6.0배
거리두기         DS-2      +4.2    481    10,013   **20.8배**
지역상품권 P014   LV-2         —    495    75,134   **151.8배**
```

**10개 중 8개가 모자라다.** 그리고 모자란 정도가 자릿수로 갈린다.

## 두 지표는 표본으로 해결할 수 없다

```
DS-2  소매 지출 +4.2%   필요 n 약 10,000   지금 481
LV-2  거주 동 소비 비중   필요 n 약 75,000   지금 495
```

**DS-2 는 정답지 효과 자체가 작다.** +4.2% 는 우리 소매 지출 기준 468원이고,
관측된 표준편차는 16,723원이다. 효과가 잡음의 **2.8%** 다. 프롬프트를 아무리
고쳐도 이 비율은 거의 그대로다 — 프롬프트는 잡음을 줄이지 않는다.

**LV-2 는 더 심하다.** 관측 효과가 몫 0.0021 인데 표준편차가 0.2055 다.
사람마다 거주 동에서 쓰는 비중이 워낙 다르고(0~1 전체에 퍼져 있다) 정책이
움직이는 폭은 그 안에서 미미하다.

## 그래서 프롬프트 작업에 무엇을 뜻하는가

**① v50 의 DS-2 비교는 설계상 읽을 수 없다.** v50 은 n=200 이고 DS-2 는
약 10,000 이 필요하다. 이것은 결과를 보기 전에 `v5_replication.md` 가
"DS-2 는 런 간 이동이 13.1%p 라 근거로 쓰지 않는다"고 적은 것과 같은 결론이며,
이번에는 **독립적인 방법(검정력 역산)으로 같은 답이 나왔다.**

**② 프롬프트로 이길 수 있는 지표는 몇 개 안 된다.**

```
지금 표본으로 읽히는 것    DS-1 · P012-4       ← 여기서 프롬프트 차이가 보인다
표본을 2배쯤 늘리면        P012-1 · DS-4 · EM-2 · LV-1
표본으로도 안 되는 것      DS-2 · LV-2         ← 지표나 설계를 바꿔야 한다
```

**③ 표본을 늘리는 것이 후보를 더 만드는 것보다 값이 크다.** 거리두기에서
n 2.5배가 부호 적중을 1/4 → 3/4 으로 올렸다. 관문 라운드 다섯 번이 올린 것은
형식 준수 +20.6%p 였고, 그것은 본런 실패율을 2.33% → 2.50% 로밖에 못 움직였다
([gate_does_not_move_production.md](v50/gate_does_not_move_production.md)).

## 이 계산이 말하지 않는 것

- 정답지 값을 **그대로 맞히는** 힘이 아니라 **0 과 구별하는** 힘이다
- 구간은 붓스트랩인데 정규 근사로 표준편차를 되돌렸다 — 어림이다
- 원문 창(한 달~40주)과 우리 창(이틀)이 달라 실측 %를 우리 base 에 곱한 것도 어림이다
- **그래도 몇 배가 모자란지는 자릿수로 읽을 수 있다.** 1.2배와 152배는 다른 이야기다

> 이 문서가 적는 것은 여기까지다. 지표 10개 중 8개가 지금 표본으로 정답지 효과를
> 검출하지 못하고, 그중 둘(DS-2·LV-2)은 표본을 늘려도 현실적으로 닿지 않으며,
> **프롬프트가 차이를 보여줄 수 있는 자리는 DS-1 과 P012-4 뿐**이라는 것.
