# 한 상수가 두 일을 하고 있다 — 그것을 가르는 수리안

**2026-09-24 04:40** · 근거 diagnosis_03 + 라이브 계획 2,977건

---

## 코드가 스스로 적어 둔 문장

```
consumption.py:816   이 값은 '앵커 과대'와 '비사용처 미분리'를 함께 보정한다.
consumption.py:825   LLM 판단(online_share): ... 필드는 진단용으로 남기고
                     비중 산정에는 쓰지 않는다.
```

`ELIGIBLE_SHARE_SEOUL = 0.2535` **하나가 서로 다른 두 가지를 고치고 있다.**

```
일 1  수준 교정     앵커가 실제보다 크다 — 곱해서 줄인다
일 2  채널 분리     동네 가게 몫과 온라인·대형소매 몫을 가른다
```

일 1 은 정책과 무관한 **보정**이고, 일 2 는 정책이 움직여야 할 **행동**이다.
한 수에 묶여 있으므로 **일 2 를 행동으로 풀면 일 1 의 교정이 깨진다.**
그래서 상수일 수밖에 없었고, 그래서 정책이 닿지 못한다.

## 앵커 과대는 추정이 아니라 측정된 값이다

라이브 2,977건으로 코드의 교차검증을 그대로 재현했다.

```
총액(온라인 포함) 평균        125,915원/일
서울 전체 환산 (940만 x 365)   연 432조원
서울 개인카드 실적             약 180조원
                               → 2.40 배 과대   (코드 주석의 2.4 와 일치)
참 앵커 평균                   52,462원/일
```

## 가르면 이렇게 된다

```
현재    offline = anchor x 0.2535                한 상수, 두 일
제안    offline = (anchor / 2.40) x share        둘로 가른다
                              ^^^^^ 정책이 움직일 수 있는 행동
기준값  share0 = 0.2535 x 2.40 = 0.608
```

**기준값에서 두 식은 항등이다** — `anchor/2.40 x 0.608 = anchor x 0.2535`.
수준을 하나도 안 건드리고 **레버만 생긴다.**

```
현재    share 가 0.2535 에 고정 · 여유 없음
제안    share 가 0.608 에서 출발 · 위로 0.39 · 아래로 0.46 의 여유
```

## share 를 무엇으로 움직이나 — 이미 있는 필드

`stage1_intent.py:227` 의 `online_share` 가 그대로 있고 배선도 살아 있다.
다만 v5 프롬프트가 묻지 않아 2,977건 전부 `None` 이다(diagnosis_03).

**단, 원값을 그대로 쓰면 안 된다.** R82·R83 이 "0.2 근처로 균일" 을 쟀으므로
`1 - 0.2 = 0.8` 이 되어 기준값 0.608 을 32% 밀어 올린다. 수준이 깨진다.
그래서 **수준이 아니라 편차만 받는다.**

```
share_i = share0 x (1 - online_share_i) / M          M = 기준 런에서 잰 평균
```

**`M` 은 무정책 기준 런에서 한 번 재고 얼린다.** 팔마다 다시 계산하면 정책이
만든 이동이 정규화로 지워진다 — 그러면 아무것도 안 한 것과 같아진다.

## 순환이 아닌 이유, 그리고 그것을 어떻게 못 박나

바꾸는 것은 "오늘 지출 중 배송으로 받는 몫" 이라는 **행동 질문**이고, 재는 것은
원장의 업종별 금액이다. 측정 공식(순효과·MPC·소진율)도, 목표 수치도, 방향을
지시하는 문장도 프롬프트에 넣지 않는다. POI 를 고르게 하는 것과 같은 종류다.

못 박는 방법:

```
관문 1  기준 런에서 총액·오프라인 분포가 현행과 구분되지 않아야 한다
        (항등식이므로 구조적으로 그래야 하고, 아니면 배선이 틀린 것이다)
관문 2  정책 줄을 빼면 share 분포가 기준 런과 같아야 한다 (위약)
관문 3  지표의 정의를 바꿔도 share 가 안 변해야 한다 (순환 검사)
```

## 남는 한계 — 미리 적어 둔다

까지다. 보고서에 이 한계를 명시한다.
