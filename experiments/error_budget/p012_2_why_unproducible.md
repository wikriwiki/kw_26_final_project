# P012-2 가 왜 값을 못 내는가 — 분류가 아니라 **판 자체**다

**2026-09-24 22:10** · 사용자 지시("실측은 있는데 시뮬이 못 내면 우리 문제다")를
P012-2 에 적용해 원인을 끝까지 따라갔다.

---

## 먼저, 내가 틀린 것

`CONTAINS '이마트'` 로 세어 보고 **"대형마트가 적립으로 잘못 분류돼 있다"** 고 적었다.

```
이마트   1,018건 중 eligible 919   <- 이것을 오분류로 읽었다
백화점     337건 중 eligible 266
```

**틀렸다.** 분류기는 맞다. 이유가 코드 주석에 이미 적혀 있었다(§ `_BRANDS_LARGE`):

```
부분일치는 190건 매칭인데 대부분 오탐이었다 — "국대떡볶이이마트목동점",
"깐부치킨 압구정현대백화점", "던킨 목동홈플러스점" 처럼 대형점에 입점했거나
인근임을 지점명으로 표시한 소상공인이다.  → 상호 '맨 앞'에서만 매칭. 190 → 19건.
```

맨 앞으로 다시 세면 이렇다.

```
이마트 로 시작하며 적립인 689건  →  **689건 전부 이마트24(편의점)**  (100.0%)
                                    정규식 `이마트(?!\s*24)` 가 일부러 뺀 것이다
이마트 로 시작하며 제외인  96건  →  진짜 대형마트
```

편의점은 실제 제도에서도 적립 대상이었다. **분류기가 맞고 내 질의가 틀렸다.**

## 그래서 진짜 원인은 무엇인가

분류는 멀쩡한데 **제외업종이 판에서 차지하는 자리가 없다.**

```
POI 판 (543,924)          실제 지출 (그래프의 모든 Plan)
  eligible        490,568   eligible          6,518건   38,880,673원  (98.5%)
  비소비            40,614   excluded_other       41건      427,273원  ( 1.1%)
  유흥               3,597   excluded_vice        37건      164,929원  ( 0.4%)
  명품               2,404   excluded_luxury       1건        6,095원  ( 0.0%)
  기타(대형마트·백화점) 306
```

**대형마트·백화점이 판에 306개뿐이고, 지출의 1.1% 밖에 안 받는다.**
실제 카드 소비에서 백화점·대형마트는 이보다 한참 큰 몫이다.

그리고 진짜 '제외업종' 자리는 POI 가 아니라 **상수**가 맡고 있다.

```
_off = 1.0 - ELIGIBLE_SHARE_SEOUL      # = 0.7465, 모든 사람 모든 날 같은 수
```

측정으로도 확인된다 — `적립누적/월지출` 이 10% 0.241 · 중앙 0.253 · 90% 0.254.
**사람이 달라도 날이 달라도 같은 수다.**

## 두 층 다 막혀 있다

```
1층  프롬프트로 몫을 물어본다   이미 기각 (split_anchor/calib_02)
     96 호출 · 넓은 질문이 좁은 질문의 상위집합인데 **27%가 더 작은 수**를 적었다
     (논리적으로 불가능) · 40%가 같은 수 · 모델은 그냥 ~0.15 를 적는다

2층  POI 선택에서 몫이 나오게 한다   판에 고를 것이 없다
     가게 지출 중 적립 몫이 **90%의 사람에게 정확히 1.000**
     (방문 건수로는 중앙 0.600 — 돈 안 쓰는 방문이 섞였을 뿐이다)
```

## 그러므로 P012-2 를 내려면

**프롬프트로는 안 된다.** 판을 바꿔야 한다 — 대형마트·백화점·온라인몰을 고를 수
있는 자리로 넣고, 상수 분리를 그 선택의 결과로 대체하는 일이다. 그것은 POI 적재와
Stage2 후보 구성을 함께 건드리는 작업이고, **28일 런이 이 그래프를 쓰는 동안에는
손대지 않는다.**

지금 할 수 있는 것은 **오차 예산에서 P012-2 를 "우리가 못 재는 것" 으로 정확히
분류하고 그 이유를 이 문서로 가리키는 것**이다. 빼 버리면 못 내고 있다는 사실이
사라진다.
