## 왜 다시 겨루나

프롬프트 후보 넷이 모두 기각됐다.

```
v36  +0.0000  [-0.0229, +0.0229]
v37  -0.0083  [-0.0292, +0.0125]
v38  +0.0042  [-0.0187, +0.0271]
v39  +0.0125  [-0.0104, +0.0375]     (비통근 부분군만 갈림)
```

**그런데 그 코호트에서는 480개 계획 중 464개(96.7%)에 집 밖 구매가 하나도 없었다.**
문장이 움직일 것이 없는 자리에서 문장을 겨룬 셈이다.

v23 이 그 자리를 열었다.

```
v25 + 볼일    집 밖 있는 칸 49 / 480   (열기 전 16칸)
              비통근 26명  1 → 26칸
```

**이제 후보가 차이를 보일 공간이 있다.** 같은 물음을 다시 묻는다.

## 설계 — 시나리오를 고정하고 프롬프트만 바꾼다

```
                    볼일 없음          볼일 있음
프롬프트 v25    v18: 16칸          v23: 49칸   ← 대조군
프롬프트 v39    v22: 21칸          이번 라운드 ← 새로 돌린다
```

**새로 돌리는 것은 한 팔뿐이다.** v23 이 같은 코호트·같은 seed 70001 로 이미 돌았으므로
대조군을 다시 돌리지 않는다.

> 왼쪽 두 칸(볼일 없음)은 다른 날 돌았고 그 사이 파이프라인이 바뀌었다
> (서버 다섯 번 사망, `max_threads=1` 패치, 이어달리기 도입).
> **2×2 로 읽되 왼쪽 열은 참고값**이고, 판정은 오른쪽 열의 두 칸으로만 한다.

### 주 지표 — 계획에 들어간 집 밖 구매 활동의 종류

```
대조 v23   칸당 0.115 · 집 밖 있는 칸 49/480
성공선     v23 대비 칸당 종류가 늘고, 칸을 짝지은 95% 구간이 0을 제외한다
```

**잡음 폭은 이번에 다시 잰다.** 기저가 0.033 에서 0.115 로 올랐으므로
±0.023 이라는 옛 폭을 그대로 쓰지 않는다. 구간이 말해 주는 대로 적는다.

### 부 지표 — 비통근자에서 더 벌어지는가

```
대조 v23   비통근 26명(208칸) 26칸 · 통근 34명(272칸) 23칸
```

v39 는 6행(의무의 뼈대)을 지운 판이고, 볼일은 의무가 아니라 **선택**이다.
**둘이 같은 자리를 겨누므로 겹치는지 따로 재는지가 이 라운드의 물음이다.**

- 비통근에서 더 벌어지면 → 두 개입이 **더해진다**
- 안 벌어지면 → 볼일이 이미 천장을 쳤고 문장은 더 줄 것이 없다
