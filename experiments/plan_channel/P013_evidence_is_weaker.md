## ① 지원금이 **한 푼도 안 들어갔다**

`/data/p013_ruler/ruler_a` — P013 은 `type=grant · decile_grants 전 분위 280,000원 ·
effective_from 2020-05-13` 이다. 그런데

```
grant_applied_today     모든 날 모든 사람 **0**
grant_remaining_total   모든 날 **0**
policy_spend_today      모든 날 **0**
cm_policy_eligible_spend_total  모든 날 0
```

`grant_applied_today` 는 `sum(grants_applied_today.values())` 이므로 0 은
**지급이 일어나지 않았다**는 뜻이다. 지갑이 한 번도 안 열렸다.

원인은 찾지 못했다. 확인한 것:

```
_grant_for_single_policy  실제 에이전트 값으로 부르면 **280,000원을 돌려준다**
spend_decile             원장에 '2'·'8'·'10' 등으로 멀쩡히 있다
서버 코드                 로컬과 같다 (게이트 세 줄 동일)
정책 적재                 로그에 "적재 완료: P013 (decile_grants=...280000...)"
```

**재현이 안 된다** — 그래프에 2020-05 State 가 0개다(현재 2021-09-30~10-10 뿐).
그러므로 원인 규명은 다음 지갑형 런에서 관문으로 잡아야 한다.

한편 모델은 지원금을 **받은 줄 알고** 답했다 — `s1_grant_kept_share=0.92`,
`cm_grant_choice_mode=True`. **모델이 본 세상과 엔진의 장부가 달랐다.**

## ② 인용해 온 "+6.36% 정책 반응" 의 58%가 드리프트다

계획액이 정책과 무관하게 계속 오른다.

```
05-04  55,189 (+0.0%)      05-11  73,244 (+32.7%)   <- 정책 전인데 OFF 보다 높다
05-07  71,216 (+29.0%) OFF 05-12  75,965 (+37.6%)   <- 정책 전
05-08  72,673 (+31.7%) OFF 05-13  76,801 (+39.2%)   <- 정책 시작. **도약 없음**
                           05-14  75,516 (+36.8%) ON  <- 오히려 내려간다
                           05-15  77,527 (+40.5%) ON
```

정책 전 날짜로 **가짜 ON 창**을 만들어 같은 검정을 돌렸다.

```
가짜 ON  05-11:12 (정책 전)   71,944 → 74,605   **+3.70%**  385:315  p=0.0091
진짜 ON  05-14:15 (정책)      71,944 → 76,522    +6.36%   410:290  p=0.0000

정책 몫 = 1.0636 / 1.0370 − 1 = **+2.57%**
```

**인용해 온 +6.36% 중 +3.70%p 가 정책 전에도 있던 상승이다.**

## ③ 그러나 P012 는 무사하다 — 위약이 지킨다

같은 의심을 P012 에 걸었더니 **위약 대조가 있다.** `PLACEBO_TIMING` 이 같은 달력일
(OFF 10-21:22 · ON 10-25:26)을 **정책 없이** 돈다.

```
위약(정책 없음)   계획액 71,467 → 69,906   **−2.18%**  112:88   p=0.1036
P012(정책 있음)   계획액 69,839 → 76,652   **+9.76%**  286:214  p=0.0015
```

**같은 날짜에 정책만 빼면 안 오른다.** P012 의 계획 반응은 진짜다.

## 왜 못 봤나 — 앵커가 드리프트를 가렸다

총액은 `max(앵커, 계획)` 이고 앵커가 이긴다. 그래서 **총액 계열은 평평한데 그 밑에서
계획액이 계속 오르고 있었다.** 어제 만든 표류 관문은 총액 계열에 걸었고, 계획 계열에는
아무도 안 걸었다.

어제 그 관문이 P013 에 대해 **"직선이 아니다 — 예열이 섞였다. 덜지 않는다"** 고
말했다. 관문은 제 일을 했다. 나는 그 경고를 "보정을 안 한다" 로만 읽고
**"그러면 비교 자체를 믿을 수 있나" 를 묻지 않았다.**
