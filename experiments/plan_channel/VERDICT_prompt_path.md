# 프롬프트 경로는 닫혀 있다 — 다섯 번 재고 내린 결론

**2026-09-24 19:36** · 탐침 5회 · 호출 합계 1,344 · 쌍 합계 531

---

## 다섯 번의 기록

```
후보 1  문턱 줄 -> Stage2 금액            쌍  24   p=0.678
후보 2  빈자리 줄 -> Stage1 이벤트        쌍  38   p=0.125   (1차)
        같은 후보, 시드 3개로 복제         쌍 143   **p=1.000**
후보 3  trigger 낱말 -> Stage2 금액       쌍  72   p=0.798
후보 4  시점 채널 -> Stage1 이벤트        쌍 142   p=1.000
        같은 후보, **마감 3일 + 문턱 0.93** 쌍  96   **p=0.690**
```

마지막 줄이 중요하다. 그것은 **시점 채널이 물 수 있는 가장 유리한 자리**였다.

```
문턱까지 16,327 ~ 40,815원 남음
이번 달 3일 남음 · 하루 5,442 ~ 13,605원 페이스
문턱 대비 위치 0.90 / 0.93 / 0.96  (실측 분포 그대로)
```

**마감도 있고 손에 닿는 거리도 있는데 안 움직인다.**

## 방향은 일관되게 양수였다 — 그런데 한 번도 안 갈렸다

마지막 탐침에서 셋 다 같은 쪽으로 움직였다.

```
내구재        +21.1%   14:11   p=0.690
policy 트리거  +18.8%   39:27   p=0.175
이벤트 수      +5.9%    42:34   p=0.422
```

**약한 양(+)이 다섯 번 내내 반복되지만 한 번도 0.05 를 못 넘는다.** 효과가
0 이라는 뜻은 아니다 — **재려는 크기가 우리가 가진 표본으로는 안 잡힌다**는 뜻이다.
그리고 그 크기는 정답지와의 간격(18.92%p)을 메우기엔 턱없이 작다.

## 그래서 내리는 결론

**이 기전에 대해 프롬프트로 더 할 것이 없다.** 근거는 셋이다.

```
1  다섯 번 쟀고 한 번도 안 갈렸다 (조건을 유리하게 바꾼 마지막 판 포함)
2  기각 이유가 구조로 설명된다 —
   Stage2 는 업종 단가에 묶인 가격기라 정책 맥락에 반응하지 않고(후보 1·3),
   Stage1 은 이미 반응하고 있다(+9.76%, p=0.0015). 더 밀 여지가 프롬프트에 없다
3  더 세게 미는 문장은 **사용자가 금지한 유도**에 들어간다
   "정책 결과에 대한 노골적인 방향이나 특정 수치를 작성하면서 유도하게해서는 안돼"
```

**조건을 바꿔 가며 유의해질 때까지 돌리지 않는다.** 그렇게 얻은 "최적" 은
정답지에 맞춘 것이지 수렴이 아니다. 후보 4 는 등록한 대로 여기서 끝낸다.

## 남는 지렛대 — 셋 다 프롬프트 밖이고, 셋 다 결함 수정이다

```
창     9일 -> 28일. 문턱 대비 0.64 -> 0.93, 한계 구간 0% -> 98%
       **지금 돌고 있다** (diagnosis_06)
회계   max(앵커,계획) 이 정책 반응의 4분의 3을 버린다. 개인 기준선으로 통과시킨다
       심었고 세 겹으로 확인했다 (diagnosis_05)
채널   정답지의 제외업종(백화점·대형마트·온라인)이 우리 원장에 없다
       ②가 측정 전에 74.65% 를 지운다 (diagnosis_03) — 아직 안 고쳤다
```

**유도가 아니라 새는 곳과 잘린 곳을 막는 일이다.** 프롬프트는 v5 를 그대로 쓴다.

## 다만 v5when 의 지적은 살아 있다

프롬프트가 적립형에 대해 **"목돈이 없으면 미루고 버틴다"** 고 적는 것은
사실이 아니다. 행동을 못 바꾼다고 해서 서술이 맞는 것은 아니다.
**보고서에 이 한계를 적는다** — 고쳐도 측정 가능한 변화가 없었다는 사실과 함께.
