# 회계 고침이 **다른 정책에서도** 듣는다 — 조정하지 않은 채로

**2026-09-24 20:05** · P013(긴급재난형) arm A 자료 재계산 · n=700 · GPU 0

---

## 같은 벽이 P013 에도 있었다

```
Stage2 계획액        71,944 -> 76,522  (**+6.36%**)  410:290  p=0.0000
총액 max(앵커,계획)  131,881 -> 131,825 (-0.04%)
계획 > 앵커          737 / 2,800 (26.3%)
```

**지갑형도 마찬가지다.** 정책이 계획에는 닿는데 앵커가 막는다. P012 에서 본 것과
같은 구조이고, EM-2·EM-3 의 구간이 0 을 지나던 이유가 이것이다.

## 고침을 **그대로** 얹으면

```
현행 max(앵커,계획)   131,881 -> 132,308   +0.32%   EM-3 오차 6.98%p
고침 개인 기준선      131,881 -> 143,790  **+9.03%**  EM-3 오차 **1.73%p**

EM-3 실측 +7.30%
```

**오차가 6.98 -> 1.73%p 로 준다.**

## 이것이 왜 중요한가 — **P013 에 맞춰 고친 것이 아니다**

고침의 모양과 클램프는 **P012 자료로** 정했다.

```
클램프 [0.5, 2.0]   P012 에서 "앵커 순위상관을 현행의 90% 이상 지키는 가장 넓은 구간"
                    -> **P013 에 그대로 가져왔다. 다시 안 골랐다**
SCALE               각 런의 무정책 창에서 수준이 보존되도록 푼 값
                    -> 정답지를 안 보고 정해진다(수준 항등 조건 하나로 결정)
```

**정답지를 보고 맞춘 자유 파라미터가 없다.** 그런데 한 번도 안 맞춰 본 정책에서
실측 +7.30% 에 대해 +9.03% 가 나왔다. **표본 밖 확인이다.**

## 두 정책에 걸친 그림

```
정책   계획 반응        현행 총액      고침 총액      실측        고침 후 오차
P012   +9.76% p=0.0015  +2.37%      +5.41%      +20.82%     15.41%p (쌍 바닥 17.97)
P013   +6.36% p=0.0000  +0.32%      **+9.03%**  **+7.30%**  **1.73%p**
```

P012 가 여전히 먼 것은 **문턱이 창 밖이었기 때문**이고(diagnosis_06), 그쪽은
28일 창이 답한다. P013 은 창 문제가 없어서 고침만으로 정답지에 붙는다.

## 아직 확인 안 한 것 — 미리 적는다

```
· 고침은 총액을 바꾸므로 **EM-2·EM-4 도 함께 움직인다.**
  EM-3 만 좋아지고 나머지가 나빠지면 총 오차는 안 줄 수 있다
· EM-4 는 이미 간격이 9배 과하다(68.3%p 대 7.20%p). 총액이 더 오르면 더 과해질 수 있다
· **총 오차로 판정한다.** 한 지표만 보고 이겼다고 하지 않는다
```

재계산으로 EM-2·EM-4 까지 함께 보는 것이 다음이다. 그전에는 "EM-3 가 좋아진다"
까지만 말한다.

## 그리고 이것은 프롬프트가 아니다

프롬프트 후보 다섯은 전부 기각됐다. 그런데 **같은 프롬프트(v5) 그대로**
회계 한 줄을 고치니 한 정책에서 오차가 5.25%p 줄었다.
**오차가 프롬프트 밖에 있었다는 증거가 하나 더 늘었다.**

## 정정할 근사 하나 (20:10) — 총액을 EM-3 의 대리로 썼다

위의 `+9.03%` 는 **총액(personal_total) 변화**이고, EM-3 는 **POI 원장의 카드매출**
변화다. 둘은 비례하지만 같은 수는 아니다.

```
같은 창에서   총액(현행 규칙)  +0.32%
              EM-3 실제 읽기   -0.46%
```

0.78%p 어긋난다. 원장에는 잔액 제약·지원금 정산·온라인 분리가 더 걸리기 때문이다.

**그러므로 "오차 6.98 -> 1.73%p" 는 정확한 값이 아니라 같은 크기의 이동을
가정한 추정이다.** 방향과 크기(약 +8.7%p 이동)는 믿을 만하지만, 소수점은 아니다.

```
말할 수 있는 것   고침이 총액을 약 +8.7%p 더 올리고, EM-3 는 그만큼 따라 오른다
말할 수 없는 것   고침 후 EM-3 가 정확히 +9.03% 다
```

정확한 값은 **고침을 켜고 다시 돌려 원장으로 채점해야** 나온다. 그것이 다음 런이다.

## 거리두기에는 **안 맞았다** (20:45) — 내가 세운 가설을 내가 기각한다

"`max(앵커,계획)` 에서 앵커는 **바닥**이므로, 억제형 정책에서 계획이 줄어도
총액이 못 준다 — 그래서 DS-1 이 덜 반응한다" 고 추측했다. **틀렸다.**

```
거리두기 Stage2 계획액   67,514 -> 76,162  (**+12.81%**)  p=0.0131
총액                    130,472 -> 134,723  (+3.26%)      p=0.659
계획>앵커               196/800 (24.5%)
```

**계획이 줄지 않았다. 늘었다.** 거리두기에서 사람들이 외식을 줄이고 장보기를
늘리면 건당 단가가 커져 계획 총액은 오를 수 있다 — 실제 행동과 어긋나지 않는다.

그리고 **DS-1 은 총액이 아니라 식사 업종만 재는 지표**다. 총액의 벽 이야기가
거기에 직접 닿지 않는다. 내가 세 정책에 같은 그림을 성급하게 붙이려 했다.

```
적용된다   P012(캐시백) · P013(지갑형) — 둘 다 총액을 올려야 하는 정책
적용 안 됨  거리두기 — 업종 간 이동이지 총액 증감이 아니다
```

**같은 고침이 모든 정책에 듣는다고 말하지 않는다.** 둘에서 확인했고, 셋째에서는
확인되지 않았다.
