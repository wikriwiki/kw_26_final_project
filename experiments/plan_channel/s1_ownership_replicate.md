## 등록했던 판정

> 내구재 이벤트가 v5own 에서 더 많은 쌍이 더 많다 · **새 표본만으로 양측 p < 0.05**

## 결과

```
지표                    v5      v5own    변화     쌍별                    양측 p
내구재(등록된 1차)     0.21 ->  0.22    +3.3%   늘 22 : 줄 22 : 동점 99   **1.000**
이벤트 수              4.46 ->  4.14    -7.2%   늘 46 : 줄 68 : 동점 29     0.0487
policy 트리거          1.05 ->  1.04    -0.7%   늘 54 : 줄 52 : 동점 37     0.923
```

**내구재는 22:22 다.** 1차의 6:1(p=0.125)은 되살아나지 않았다.

## 기각한다

등록한 선을 크게 벗어난다(p=1.000). **후보 2 를 본런에 올리지 않는다.**

## 1차가 왜 그렇게 보였나 — 표본이 7 이었다

1차는 쌍 38 에 동점 31, 즉 부호검정에 들어간 실질 표본이 **7** 이었다.
7개에서 6:1 이 나올 확률은 동전 던지기로도 낮지 않다(양측 0.125 — 그래서
그때도 통과라고 적지 않았다). 복제에서 실질 표본이 **44** 로 늘자 22:22 가 됐다.

```
1차   실질 표본  7 → 6:1   p=0.125
복제  실질 표본 44 → 22:22 p=1.000
```

**p=0.125 를 통과시키지 않은 것이 옳았다.** 그때 통과시켰다면 8시간짜리 본런을
잡음 위에 세웠을 것이다.

## 덤으로 나온 것 — 이벤트가 오히려 **줄었다**

이벤트 수가 4.46 → 4.14 (-7.2%), 68:46 으로 줄어든 쌍이 많다. p=0.0487.

**그러나 이것을 "확인된 효과" 로 적지 않는다.** 지표를 셋 재고 그중 하나가
0.05 를 겨우 밑돈 것이다. 셋을 본다는 것을 감안하면(본페로니 0.0167) 넘지
못한다. 게다가 이것은 **등록하지 않은 방향**이다 — 사후에 집어 올리면
그게 바로 낚시다.

적을 수 있는 것은 여기까지다: **이 줄이 이벤트를 늘리지 않는다는 것은 1차와
복제에서 일관되고, 오히려 줄이는 쪽으로 기운다.** 계획액을 키우려는 후보인데
이벤트를 줄이는 쪽이라면 방향이 어긋난다.

## 배운 것

```
· 동점률이 높으면 쌍 수가 아니라 **불일치 쌍 수**가 표본이다. 그것을 먼저 센다
· 복제는 값을 했다 — 1차를 믿었으면 잡음 위에 8시간을 세웠다
· 지표를 여럿 재면 그중 하나는 0.05 근처에 온다. **등록한 것만 읽는다**
```
