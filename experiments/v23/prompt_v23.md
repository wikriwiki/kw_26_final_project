# 실험 v23 — 프롬프트가 아니라 하루에 볼일을 넣는다

**2026-09-21 사전등록** · **상태** 조건부 대기 · **프롬프트 v25 고정 · 시나리오 변경**

> **조건을 결과보다 먼저 적는다.** 이 라운드는 **v22 의 v39 가 기각될 때만** 돈다.
> v39 는 이 문서를 쓰는 지금 돌고 있다.

---

## 왜 프롬프트를 멈추는가

네 프롬프트가 같은 수를 냈다.

```
v25  16칸   v36  16칸   v37  12칸   v38  17칸      (480칸 중, 잡음 폭 ±11칸)
```

3행·9행·18행을 하나씩도 합쳐서도 지웠는데 움직이지 않았다.
그리고 누가 나가는지는 **통근 하나가 가른다.**

```
v25  재직자 나간 적 있음 11/34(32%) · 통근 56.6 대 30.4분 · p=0.0001
     비재직자 나간 적 있음 1/26(4%)
v36  재직자 10/34(29%) · 통근 54.7 대 32.3분 · p=0.0002
     비재직자 0/26(0%)
```

**모델은 구매를 위해 나가지 않는다. 이미 하던 이동에 붙일 뿐이다.**
통근이 없는 사람에게는 붙을 다리가 없다.

v39(6행)가 그 순서를 건드린다. **그마저 안 되면 남는 설명은 하나다 —
하루에 나갈 이유가 없다.** 이 라운드는 그것을 준다.

## 무엇을 바꾸는가

`add_outside_need.py` 로 **집에서 끝낼 수 없는 볼일 하나**를 넣는다.

```
칸 480 → 480 (그대로)
볼일이 붙은 칸 416 / 480
볼일 받은 시민 52 / 60명
  건강 34 · 교육 15 · 여가 3 · (서비스 지출 0인 8명은 안 받음)
통근 없는 26명 중 21명이 받는다     ← 한 번도 안 나가던 집단
sha256 1b2faff6588ddb37e4d07a9c6f6f3edc54b416854f3753e1a06cbf6e459866c1
```

**어느 업종을 줄지는 그 사람 자신의 카드 실측 구성에서 가장 큰 서비스 업종**이다.
정답지의 어떤 값도 보지 않는다 — `errand_provenance.blind_to` 에 그렇게 적혀 있다.

> **이것은 유도인가?** 볼일을 주면 나가는 것이 당연하지 않은가.
> 그래서 **선택(mandatory=false)** 으로 넣는다. 미루거나 생략할 수 있고,
> 프롬프트 9행이 그것을 명시한다. 그리고 끼니를 넣었을 때도 같은 물음이 있었는데
> 답은 "넣어도 모델이 안 할 수 있다"였다 — 실제로 끼니의 상당수가 배달로 갔다.

### 주 지표 (v21·v22 와 같음)

```
기준선 v25   칸당 0.033 · 집 밖 칸 16/480
잡음 폭      ±0.023  →  칸 수로 ±11칸
성공선       칸당 종류 증가 + 짝지은 95% 구간이 0 제외 (27칸 초과)
```

### 부 지표 — 이 라운드의 진짜 물음

**통근 없는 시민이 나가는가.**

```
기준선   비재직자 26명 중 나간 적 있는 사람   v25 1명 · v36 0명 · v37 1명
```

볼일을 받은 21명 중 몇 명이 실제로 나가는지를 따로 적는다.
전체 비율이 올라도 **그것이 통근자에게서 온 것이면 다른 사실이다.**

### 취소 조건

| 조건 | 선 | 무엇을 막나 |
|---|---|---|
| 계약 깨짐 | 유효·적격 < 95% | 필요를 하나 더 넣어 형식이 무너짐 |
| 채우기 | 계획당 사건 수 ≥ v25 + 1.5 (v25 = 9.01) | 볼일이 아니라 항목 수만 늘어남 |
| 볼일만 하고 안 삼 | 집 밖 활동은 늘었는데 결제 후보 업종 수가 그대로 | 나가기만 하고 사지 않음 |

### 이 실험이 답하지 않는 것

- **최적 프롬프트** — 프롬프트를 고정하므로 이 라운드는 후보를 가르지 않는다
- **정답지 지표** — 60명으로는 아홉 지표 전부 0을 지난다
- **현실성** — 볼일은 합성 가정이다. "이런 하루를 주면 모델이 나가는가"를 묻는 것이지
  "실제 시민이 이런 볼일을 가진다"를 주장하는 것이 아니다

## 결과

**계획 480/480 · 유효 480 · 적격 480.**

### 주 지표 — 통과

```
              종류   칸당      집 밖 있는 칸
v25 (대조)    3/14   0.033       16 / 480
v23           3/14   0.115       49 / 480
차이                 +0.0813  [+0.0458, +0.1167]   칸 480 짝지음 · 갈림
```

**사전등록 판정: 통과.** 스물넷째 라운드 만에 처음으로 성공선을 넘었다.
16칸이 49칸이 됐다 — 잡음 폭(±11칸)의 세 배다.

### 부 지표 — 이 라운드의 진짜 물음도 갈렸다

```
                칸       집 밖 칸         차이
비통근 26명     208       1 → 26     +0.1490  [+0.0913, +0.2163]   갈림
통근  34명     272      15 → 23     +0.0294  [-0.0074, +0.0699]   0을 지남
```

**볼일은 비통근자를 26배 움직이고 통근자는 거의 안 건드린다.**

기전이 예측한 그대로다. 통근자는 이미 이동이 있어서 구매를 붙일 다리가 있었고,
비통근자는 그 다리가 없었다. 볼일이 그들에게만 다리를 만들어 준다.

> v39(프롬프트로 6행을 지운 판)도 같은 방향이었다 — 비통근 1 → 7칸.
> **v23(시나리오)은 1 → 26칸이다.** 같은 자리를 겨눴고 시나리오 쪽이 훨씬 세다.

### 취소 조건 — 하나도 안 걸렸다

```
계약      480/480 유효·적격
채우기    계획당 사건 수 9.01 → 9.07   (선 +1.5)
```

세 번째 취소선("볼일만 하고 안 삼")은 결제 단계가 필요하다. 하류가 돌고 있다.

### 한 번도 안 쓰이던 업종이 들어왔다

```
v23 이 쓴 집 밖 활동   groceries 37 · health_goods 11 · meal_dine_in 7
```

**`health_goods` 는 480칸짜리 런 네 번(v25·v36·v37·v38)에서 0건이던 활동이다.**
그리고 `meal_dine_in` 이 1건에서 7건이 됐다 — DS-1 이 재려는 매장 취식이다.

## 이 라운드가 남긴 것

1. **상류가 열린다.** 카탈로그·문법·자원이 아니라 **하루에 나갈 이유**가 없던 것이
   맞았다. 이유를 주자 나간다
2. **프롬프트보다 시나리오가 세다.** 같은 자리를 겨눈 v39 는 1→7칸,
   v23 은 1→26칸이다. 다만 **v23 은 프롬프트 후보가 아니다** — v25 고정이다.
   "더 나은 프롬프트"를 만든 것이 아니라 "프롬프트가 일할 수 있는 하루"를 만든 것이다
3. **다음은 결제다.** 매장 취식 7건이 실제 구매로 이어지면 DS-1 이 처음으로
   붕괴할 대상을 갖는다. 그때 비로소 정답지와 견줄 수 있다
