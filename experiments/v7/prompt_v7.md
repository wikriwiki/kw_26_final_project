# 실험 v7 — 빗장은 무엇을 막아야 하나

**날짜 2026-09-20** · **상태** 완료 · **2026-09-21 정정** — v30 미채택(근거는 바뀌었다)

---

## v6 이 남긴 것

빗장을 통째로 뺐더니 이렇게 됐다.

```
                v25 on    v29 on
zone 사건 비율   0.1057    0.1143    판정선 ±0.03 → 안 나간다
계획당 사건 수     9.11      9.16    칸 채우기 아님
구매 사건 비율   0.0571    0.0750    +0.0179 (2.1 SE) ← 여기만 움직였다
```

**빗장은 외출이 아니라 구매를 막고 있었다.** 그런데 빗장의 목적은 **칸 채우기를
막는 것**이지 구매를 막는 것이 아니다. 문장을 보면 이유가 보인다.

```
v25   활동 수를 채우려고 구매·외출·반복을 추가하지 않는다.
                         ^^^^ 막을 대상으로 '구매'를 이름으로 지목한다
```

## 무엇을 바꾸나 — 명사 하나

```
v30   활동 수를 채우려고 활동을 추가하지 않는다.
```

**빗장은 남는다.** "수를 채우려고 추가하지 말라"는 그대로다. 빠지는 것은
**구매를 지목하는 부분**뿐이다.

- **v29 처럼 빼지 않는다** — 칸 채우기 방지는 필요하다
- **부추기지도 않는다** — "사라·나가라·더 쓰라"가 없다. 검사로 막았다

세 후보의 관계: `v29`(빗장 없음) — `v30`(빗장, 구매 미지목) — `v25`(빗장, 구매 지목).

### 판정 — 돌리기 전에 정한다

**주 지표 — 구매 사건 비율 (on 팔)**

| | 기준 |
|---|---|
| **겨냥이 문제였다** | v30 이 v25 보다 높고(≥ 2 SE ≈ +0.016), **v29 와 구별되지 않는다** |
| **낱말이 아니었다** | v30 이 v25 와 같다 — 명사를 바꿔도 아무 일이 없다 |
| **중간** | v25 < v30 < v29 로 갈라지면 그대로 적는다. 셋 중 하나를 고르지 않는다 |

**취소 조건 (성공을 무효로 만든다)**

| | |
|---|---|
| 칸 채우기 | v30 의 계획당 사건 수가 v25 보다 뚜렷이 많으면 빗장이 깨진 것이다. 승리 아님 |
| 외출 폭증 | zone 비율이 판정선 0.03 을 넘으면 이 축이 아닌 다른 것이 움직인 것이다 |

**정책 선택적 지표 (미리 등록하되, 판정력이 없을 것이다)**

지갑 기전(지원금·지역화폐)의 **적격 구매 사건** on − off. 위약(캐시백·거리두기)은
지갑이 없으므로 **정의상 0**이고, 그것이 구조적 대조군이다.

> **미리 적어 둔다: 이 수는 십 단위일 것이고 판정하지 못할 것이다.**
> v6 에서 v25 가 on 6 / off 8, v29 가 on 12 / off 10 이었다. 경계만 말한다.
> 이렇게 적어 두는 이유는, 나중에 이 수가 좋게 나왔을 때 **사후에 주 지표로
> 승격시키지 않기 위해서다.** v6 에서 한 번 그럴 뻔했다(집계 버그로 철회).

**금액** — 기록만 한다. 12명 평균의 SE 가 2,246원이라 주장할 수 없다.

### 이 실험이 답하지 않는 것

- **어떤 구매 비율이 옳은가** — 모른다. 정답지와 대조하지 않았고, 그건 C층의 일이다.
  여기서 말하는 것은 **"칸 채우기 방지 문장이 구매를 지목할 이유가 없다"** 까지다
- 최적 프롬프트 — 한 축을 고칠 뿐이다
- 정책 효과의 크기 — [ESTIMAND_ALIGNMENT.md](../ESTIMAND_ALIGNMENT.md) 참조

## 결과 — 겨냥이 문제였다

수치는 [graph_v7.md](graph_v7.md). 세 후보 모두 계획 **384/384 유효**, 게이트 제외 0.

### 주 지표 — 구매 사건 비율 (on 팔, 4 seed 합산 ~1,760 사건)

```
v25  구매 지목    0.0584
v30  겨냥 교정    0.0771      v25 대비 +0.0187 = 2.21 SE
v29  빗장 없음    0.0904      v30 대비 +0.0133 = 1.43 SE
```

### 사전등록 판정 — 네 조건 모두 통과

| 조건 | 기준 | 관측 | |
|---|---|---:|---|
| v30 > v25 | ≥ 2 SE | 2.21 SE | **충족** |
| v30 ≈ v29 | < 2 SE | 1.43 SE | **구별 안 됨** |
| 칸 채우기 아님 | 계획당 사건 증가 없음 | −0.07 | **안 걸림** |
| 외출 폭증 아님 | zone 비율 ±0.03 | +0.0019 | **안 걸림** |

**빗장에서 "구매"라는 낱말을 빼는 것만으로 구매 비율이 2.21 SE 올랐다.**
빗장은 그대로 있고(칸 채우기 없음), 하루는 여전히 집에 있다(외출 폭증 없음).

v26·v27·v28·surfaced·v29 까지 다섯 번 실패한 뒤 **처음으로 사전등록 기준을
통과한 변경**이다.

### 무엇이 안 변했는지도 같이 본다

```
            zone 비율   계획당 사건
v25          0.1054       9.19
v30          0.1073       9.12
v29          0.1147       9.22
```

세 후보의 zone 비율이 **0.105~0.115 로 여전히 붙어 있다.** v6 이 그은 경계 그대로다.
하루는 여전히 집에 있고, 바뀐 것은 **그 하루 안에서 사느냐**뿐이다.

### 정책 격차는 좋아 보이지만 아직 말할 수 없다

```
on − off 구매 비율     v25 +0.0071 · v30 +0.0191 · v29 +0.0176
```

2.7배로 보이지만 이중차분으로 재면 **+0.0120 · SE 0.0115 · 1.05 SE** 다.
**정책 반응이 좋아졌다고 말할 수 없다.** 점추정이 그렇게 보일 뿐이다.

### 17개 지표 비교는 이번에도 판정력이 없었다 — 사전등록한 그대로

후보마다 결제가 **seed 하나(96칸)** 뿐이라 구간이 이렇게 나온다.

```
v30  DS-1 +169.2 [-100.0, +438.5]   P012-1 -100.0 [-100.0, -100.0]
v29  DS-1  +50.0 [-100.0, +400.0]   P012-1 +222.2 [ -63.0, +488.9]
```

`P012-1 = −100.0` 은 **on 팔의 적립업종 구매가 0건**이라 나온 값이지 −100% 변화가
아니다. 사전등록에 "판정력이 없을 것"이라 적어 둔 그대로이고, **여기서 후보를
고르지 않는다.**

### 분모를 두껍게 하고 다시 봤다 — 그리고 결론이 뒤집혔다

v25·v30 의 나머지 3 seed 결제를 돌려 칸을 96 → **384** 로 늘렸다.
전체 비교는 [indicator_view_v7.md](indicator_view_v7.md).

**v30 이 정답지 지표를 더 나쁘게 만들었다.**

### 정정 (2026-09-21) — "확신을 갖고 틀렸다"는 틀린 말이었다

위에서 v30 의 DS-1·DS-3 을 **"부호 반대 · 구간이 0을 제외"** 로 적었다. **그 구간이
너무 좁았다.** 붓스트랩이 **칸만 재추출하고 seed 블록 변동을 담지 않았다.**

증거는 v25 자신이다. 같은 프롬프트인데 블록이 바뀌자 판정이 뒤집혔다.

```
DS-1   v7 블록(63001~4)  +166.7  [ -16.7, +1000.0]   미결
       v8 블록(64001~4)  +484.6  [ +78.2, +1538.5]   부호 반대 확정
```

블록을 먼저 재추출하고 그 안에서 칸을 재추출하도록 고친 뒤 다시 재면:

```
v25 (v7 블록)  DS-1 +166.7 [ -33.3, +1000.0]   0 포함
v30 (v7 블록)  DS-1 +384.6 [ -23.1, +1500.0]   0 포함
v25 (v7 블록)  DS-3 -185.3 [-1044.5,  +39.4]   0 포함
v30 (v7 블록)  DS-3 -381.4 [-1479.9,  +69.2]   0 포함
```

**둘 다 미결이다.** v30 이 정답지 지표를 확실히 나쁘게 만들었다는 주장은 **철회한다.**

**그래도 v30 을 채택하지 않는다.** 다만 근거가 바뀐다 — "해를 끼쳤다"가 아니라
**"나아졌다는 증거가 없다"** 이다. 점추정은 여전히 v25 보다 나쁜 쪽이고,
구성도 바뀌지 않았다(늘어난 구매가 전부 배달이었다).

### 그래서 무엇을 배웠나 — 사전등록한 기준이 표적을 잘못 겨눴다

v30 은 **구매 비율을 2.21 SE 올렸고**, 칸 채우기도 외출 폭증도 없었다.
사전등록한 네 조건을 모두 만족했다. 그런데 **그렇게 늘어난 구매가 거리두기
on 팔에서 음식점으로 갔다.** 정책이 눌러야 할 바로 그 자리다.

**구매를 더 하게 만드는 것은 정답에 가까워지는 것이 아니다.**
공정 지표(더 산다·더 닿는다)가 정답 지표를 대신할 수 없다는 것을,
이번에는 기준을 통과한 후보가 직접 보여 줬다.

이 판정은 **미결보다 나쁘다.** 모른다가 아니라 확신을 갖고 틀린 것이다.

### 그래서 v25 를 유지한다

- v25: 부호 일치 1 · 부호 반대 0
- v30: 부호 일치 0 · 부호 반대 2

**v30 을 채택하지 않는다.** B층 기준만 보고 골랐다면 잘못 골랐을 것이고,
C층 대조표를 함께 그렸기 때문에 잡혔다.
