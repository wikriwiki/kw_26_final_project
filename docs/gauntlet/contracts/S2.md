# S2 백엔드 계약 — FastAPI

선행 계약: `s1.0.0`
상태: 구현 완료, Critic 통과

## 응답

`web/api/store.py`는 실제 `SIM_DATA_ROOT`를 읽고 S1 참조 집계기를 사용한다.
`SIM_USE_FIXTURES=1`은 테스트에서만 명시적으로 지정할 수 있으며, 실제 모드에
산출물이 없을 때 목업으로 fallback하지 않는다.

구현 엔드포인트:

- `/api/runs`, `/api/runs/{id}`, `/api/runs/{id}/days`
- `/api/runs/{id}/days/{day}` 및 `bottlenecks`, `slow`, `failed`
- `/api/runs/{id}/failures`, `/events/summary`, `/events`(SSE)
- `/api/policies`, 정책 상세·preflight·POST/PUT/DELETE CRUD
- `/api/runner/lock`, `/runner/start`, `/runner/stop`, `/runner/release`
- `/api/artifacts/{path}` 및 run 산출물 서빙

첫 화면 `days`는 `status_scan`을 이벤트 루프 밖에서 실행하고, 상세 집계는
`asyncio.to_thread`와 완료 일자 파일 변경 키 캐시를 사용한다. 원본 JSONL은
API 응답으로 보내지 않는다.

## B8 lock

`RunLock`은 `O_CREAT|O_EXCL`로 lock 파일을 원자 생성한다. 이미 존재하는
lock은 프로세스 생존 여부와 관계없이 409로 거부한다. 시작 명령은 운영자가
`SIM_RUN_COMMAND_JSON`으로 명시한 배열만 사용하며 기본 mock 명령은 없다.
중단은 소유 PID에만 `SIGINT`를 보내고 SIGKILL/이름 기반 kill은 사용하지 않는다.
