# S5 시각화 통합 계약

선행 계약: `s1.0.0`, S2 API
상태: 구현 완료, Critic 통과

- 기존 `output/sim/visualization/index.html`과 `output/sim/report/FINAL_REPORT_5D_FULL.html`을 `/api/artifacts/*`로 서빙한다.
- `GET /api/artifacts`는 파일 경로·크기 목록만 반환하며 원본 HTML은 사용자가 iframe을 열 때만 전송한다.
- `ResultsPage`는 렌더링 파일을 import하거나 수정하지 않고 iframe으로 감싼다.
- `events.jsonl`은 `/api/runs/{id}/events/summary`의 서버 집계를 사용한다. 중단 run의 `available:false`와 reason을 그대로 표시한다.
- 이벤트 집계의 null-only 필드와 policy별 지급액은 원본 응답에서만 표시한다.
