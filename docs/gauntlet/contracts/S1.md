## 범위

S1은 `C:\Users\srdyh\gpu_exp_data\20260802\`의 `out_BASE`, `out_FINAL`,
`rescue\out_BASE7500`와 저장소의 정책 JSON을 읽어 `web/fixtures/`에 API 응답

## 불변 규칙

- 모든 최상위 리소스 응답은 `unknown: string[]`을 가진다.
- `available: false` 응답도 `available: true` 응답과 동일한 키 집합을 가진다. 알 수 없는 값은 `null` 또는 빈 배열과 `unknown`으로 표현한다.
- `sum(by_spend_decile[].agents) == agents_ok`를 항상 만족한다. `spend_decile == null` 행은 null 버킷으로 보존한다.
- 정책 `prompt_preview`는 preflight가 출력한 블록 원문을 줄바꿈·들여쓰기 그대로 보존한다. 줄 접두만 필터링하지 않는다.
- 정책의 `grant_key` 파일값과 검증기 실효값 `grant_key_effective`를 분리한다. 파일 키가 없으면 실제 preflight 기본값 `income`을 사용한다.
- `metrics/day_*.jsonl`과 `events.jsonl`은 서버 집계 응답으로만 노출한다. 픽스처 응답은 200KB 이하이고 중단 run의 19MB metrics 원본은 포함하지 않는다.
- `stage1_failures.jsonl`과 `checkpoints/failed_<day>.json`은 서로 다른 실패 의미이므로 합산하지 않는다.

## 참조 구현과 검증

`web/fixtures/_build_fixtures.py`가 스트리밍 집계·상태 스캔·preflight 파싱의
참조 구현이다. `tests/unit/test_s1_contract.py`가 픽스처 개수, 키 집합,
분위 항등식, 실제 run 파일과의 `status_scan` 일치, 정책 미리보기 및 용량을
검사한다.

재생성 명령:

```text
python web/fixtures/_build_fixtures.py
python -m unittest discover -s tests -p "test_*.py" -v
```

실측 결과: JSON 36개, 총 405,200 bytes, 최대 68,456 bytes.
