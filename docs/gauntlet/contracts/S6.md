# S6 앱 셸·디자인 시스템 계약

선행 없음. 현재 구현은 S1~S5와 함께 통합된다.
상태: 구현 완료, Critic 통과

- 셸은 224px 고정 rail, 48px context bar, 중앙 primary workspace, 우측 inspector를 사용한다.
- rail의 업무 순서는 정책 설정·실행 모니터·결과 시각화·데이터 계약·시스템이다.
- 배경/표면은 불투명 중성 면과 1px hairline으로만 구분한다.
- 상태색은 muted green/cyan/amber/red/blue로 제한하고, 장식용 네온·보라색 AI 강조를 사용하지 않는다.
- 모든 panel/control radius는 4px 이하이고 gradient/backdrop-filter/box-shadow는 없다.
- `KitPage`(시스템)는 토큰·공통 컴포넌트·loading/empty/error/partial 상태의 실물을 제공한다. 예시 수치는 제품 화면의 데이터가 아님을 화면에 명시한다.
- 900px 이하에서 rail은 tab navigation으로 바뀌고 workspace는 1열로 내려간다.
