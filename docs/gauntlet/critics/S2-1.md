## 기준 대조

통과:

- B1: 실제 모드에서 run/policy 산출물을 읽고, fixture 모드는 `SIM_USE_FIXTURES=1`일 때만 활성화된다. 목업 fallback과 임의 KPI가 없다.
- B2: 정책 preflight를 subprocess로 재사용하고 `prompt_preview`, pass/warn, `unknown: ["db_wiring"]`을 그대로 반환한다.
- B3: 읽기 집계와 SSE는 `asyncio.to_thread`로 실행한다. run 제어는 명시적으로 구성된 소유 명령·PID만 대상으로 한다.
- B4: 첫 화면 days 경로는 `status_scan`을 사용한다. 실제 smoke 측정에서 BASE7500 days 약 0.059초였다.
- B5: 상세 JSONL/events는 서버에서 집계하고 원본 파일을 API에 적재하지 않는다. 완료 일자 집계는 파일 mtime/size 키로 캐시한다.
- B8: `O_EXCL` lock과 409 duplicate rejection을 테스트했다. UI 비활성화만으로 의존하지 않는다.
- 경로 보안: artifact route는 허용 root 밖 경로를 거부한다.
- S1 16개 테스트와 S2 8개 테스트가 모두 통과한다.
