# S1 Independent Critic — round 1

역할: 독립 Critic
검토 입력: `docs/GAUNTLET_WEB_CONSOLE.md`, `docs/gauntlet/contracts/S1.md`,
`web/fixtures/`, `web/fixtures/_build_fixtures.py`,
`tests/unit/test_s1_contract.py`

검토 방식: 빌더 대화나 의도를 사용하지 않고 산출물·실제 픽스처·재현 명령만
대조했다. Critic은 코드를 수정하지 않았다.

## 기준 대조

통과:

- B1: 픽스처 값은 실제 run/policy 소스에서 생성되며 36개 JSON이 200KB 이하. 중단 Day 0 원본 19,599,953 bytes가 7,009 bytes 서버 집계 응답으로 축약된다.
- B2: 4개 정책 preflight 결과가 `exit_code: 0`이고 `prompt_preview`에 `배경:` 원문 줄이 포함된다. DB 배선 미확인은 `unknown`으로 공개된다.
- B4/B5 입력 계약: `status_scan`과 실제 36개 metrics 일자의 rows/ok/error가 일치하며, 첫 화면용 days 응답과 전체 day 집계를 분리할 수 있다.
- 불완전 run: BASE7500의 null 계획값, 실패 체크포인트 부재, 이벤트 export 부재가 0으로 치환되지 않는다.
- 키 안정성: bottlenecks/slow/failed/events.summary의 available true/false 픽스처 키 집합이 같다.
- 분위 항등식: BASE, FINAL, BASE7500 대표 day 모두 `sum(by_spend_decile[].agents) == agents_ok`; rescue의 null 5행도 보존된다.
- 계약 회귀: `python -m unittest discover -s tests -p "test_*.py" -v` 결과 8/8 통과.
