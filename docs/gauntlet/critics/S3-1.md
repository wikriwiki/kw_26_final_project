## 기준 대조

통과:

- 실제 정책 목록에서 선택하며 P008 facility처럼 지급 필드가 없는 정책에 임의 지급액을 만들지 않는다.
- P010은 실제 `decile_grants`를 10분위 편집 행으로 보여주고, P009/P011은 실제 소득 tier를 보여준다.
- 편집 후 실제 `/api/policies/{id}/validate`를 호출하고, pass/warn/fail 및 `prompt_preview` 원문을 표시한다.
- JSON 미리보기는 draft 전체를 직렬화하며 별도 샘플 KPI를 주입하지 않는다.
- `grant_key` 원본값과 `grant_key_effective`를 분리하고 기본값 배지를 표시한다.
- DB 배선 미확인 `unknown`을 초록 통과로 뭉개지 않는다.
- 저장 버튼은 dirty 상태·로컬 오류·검증 중 상태에서 차단되며, 서버 preflight 통과 후에만 PUT한다.
- 1280px/768px 레이아웃 규칙은 workspace CSS에서 각각 3열/1열로 축소되고 가로 scroll을 만들지 않는다.
