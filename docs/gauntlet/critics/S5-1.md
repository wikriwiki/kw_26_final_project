## 기준 대조

통과:

- 기존 3D/리포트 렌더링 파일을 수정하지 않고 iframe으로 통합했다.
- 브라우저 첫 응답은 artifact 목록/집계 응답이며 147MB standalone HTML을 목록 API에 포함하지 않는다.
- iframe은 workspace 내부에서 width/height 100%로 제한되고 `embed-stage`가 자체 overflow를 관리한다.
- 완료 run은 실제 events summary, rescue는 `available:false`·reason·unknown을 표시하며 결제액을 0으로 채우지 않는다.
- 실제 output root 밖의 artifact path는 `relative_to` 검사로 거부된다.
- 1280/768 레이아웃은 결과 primary/inspector를 각각 2열/1열로 축소한다.
- 3D·리포트 전환과 산출물 목록은 서버가 반환한 파일 경로를 사용한다.
