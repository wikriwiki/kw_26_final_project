- 정책 6일 총소비/인 합: **681,446원**
- **순증: +47,364원/명 (+7%)**
  - ├ 지원금 직접 소비: **+56,863원/명**
  - └ 개인소비 유발(순증): **−9,498원/명**

**해석**: 시장 총소비는 +7% 증가했으나, 그 증가분은 **지원금 자체 소비**가 전부이고 **개인소비는 오히려 −9,498원 감소**(아래 pull-forward). 즉 순증은 정부 이전지출의 직접 소비이지, 지속적 개인소비 유발이 아니다.

## C. MPC (한계소비성향)

Kan et al.(2017) 정의 = 신규 소비 유발분 / 지원금 사용액.

```
7일 지원금 사용/인 = 187,982원
개인소비 변화/인 (정책일 − 같은요일 baseline) = +1,839원  (거의 0)
신규 소비 = 지원금 + 개인변화 = 189,822원
시뮬 MPC = 189,822 / 187,982 ≈ 1.0
```

**해석**: 2주 관측창에서 개인소비가 순증도 순감도 아닌 ~0이라, 지원금이 개인소비를 밀어내지 않은 것으로 나와 **MPC ≈ 1.0**. 단, 개인소비 페이백(§E)이 관측창을 넘어 계속되면 MPC는 하락한다.
**⚠️ 주의**: 이 값은 **모형 가정(독립 지갑·2주 창·소진 프롬프트)의 영향**을 강하게 받으므로 "소비 진작의 상한"으로 해석. (실측 한국은행 MPC=0.20과의 대조는 `docs/EXP001_VALIDATION_vs_BOK.md` 참조)

## E. 개인소비 pull-forward (시점 간 대체)

지원금을 뺀 순수 개인소비를 같은 요일 baseline과 비교:

| 정책일 | 요일 | 개인소비 vs baseline |
|---|---|---|
| 07-21 | 월 D1 | **+11,335 (+10%)** |
| 07-22 | 화 D2 | **+11,413 (+10%)** |
| 07-23 | 수 D3 | **+5,177 (+4%)** |
| 07-24 | 목 D4 | **−4,494 (−4%)** |
| 07-25 | 금 D5 | **−7,556 (−6%)** |
| 07-26 | 토 D6 | **−6,248 (−8%)** |
| 07-27 | 일 D7 | **−7,785 (−10%)** |

- 개인소비 유발 누적(매칭 6일 화~일): **−9,498원/명** (음(−))
- **해석**: 지급기(D1~D3)의 개인소비 부양(+)이 소진 후(D4~D7) 반락(−)으로 **되돌려짐** → 초기 소비가 미래 소비를 당겨쓴 **시점 재배치(intertemporal substitution)**. 지속적 순증이 아님.
