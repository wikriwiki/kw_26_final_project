# 고정한 범용 후보의 반복 변동 확인

daily_v1의 v25 계획·결제 전96조건이 독립 검사를 통과하면, 같은 문구와 동일한 입력을
유지한 채 seed56001/57001의 계획192조건을 추가한다. 입력 SHA256은
`78961fc28d0f27915a58b2db58c22d3fdc888f3e4be4bbfc6d56dbf054e29000`이다.
`validation_daily_v2_v25_repeats.json`에 실행 전에 등록한다. 기존12명·알려진 정책이며
새 홀드아웃이라고 부르지 않는다. 이전 seed52001은 재실행하지 않는다.

계획별512추론 토큰·온도0.2·같은 시각/장소 문법·상품 목록·의무·선택적 필요를 유지한다.
모든 실패 원문을 보존하고 원문·실행·사실·요청 적격성과 평균 생성량을 확인한다.
각 완전한 적격 반복에서 결제96조건을 따로 생성해 원래 v7/v4/잔액 입력으로 연결한다.
결제 seed53001을 유지해 구매 난수 설정을 고정하되, 실제 경로가 바뀌면 모델 출력이
달라질 수 있음을 명시한다. 조건을 줄이거나 성공한 행만 골라 점수를 만들지 않는다.

확인할 것은 같은 시민·같은 조건의 반복 변동, 동일 seed의 on/off 차이,
각 반복의 좁은 상품 목록 내 소비 차이다. `plan_variation_audit.py`의 행동열 거리와
원문 기반 연결 소비 보고서를 함께 읽는다. 행동열 거리를 소비 효과 크기로 쓰지 않는다.
두 반복에서 정책 부호가 다르더라도 실패를 숨기거나 원하는 부호로 재생성하지 않는다.
관찰 결과에 따라 공통 문구에 특정 정책의 행동·수치·기대 부호를 추가하지 않는다.

이 시험에서 확인 가능한 것은 조건부 반복 안정성이다. 두 추가 반복만으로 통계적 유의성,
인구 대표성 또는 현실 정책 효과의 크기를 입증하지 않는다. 현재 하루·합성 재고·좁은
상품 목록·합성 자격·미완성 환급 및 다일 상태 전이의 한계는 그대로다.
그 한계를 해결할 때까지 반복 횟수나 시민 수 확대만으로 외부 타당성 판정을 대신하지 않는다.
