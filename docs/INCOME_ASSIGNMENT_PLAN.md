# 페르소나 소득 부여 계획 v2 — 소지역 추정 기반 (전면 개정)

> 개정일: 2026-07-09 · v1의 데이터 실효성 문제(반출 의존·구형 데이터)를 부검하고,
> **즉시 접근 가능한 공개 데이터 + 합성인구 문헌의 표준 방법**으로 재설계.
> 문제 정의: **데이터 기반 소득 분위 페르소나 속성 생성** — 학술적으로는
> *소지역 소득 추정(small-area income estimation) + 합성인구(synthetic population) 속성 부여* 문제.

---

## 1. v1 부검 — 무엇이 비현실적이었나

| v1 데이터 | 문제 | 판정 |
|---|---|---|
| 신한은행 생활금융지도 (BDC 반출) | 방문·신청·심사 필요, 반출 제약, **구형 상품(2018~19 계열)** | ❌ 폐기 — 단, 같은 계열 정보의 **공개 가공본이 이미 존재**(아래 D1) |
| 가계금융복지조사 **마이크로데이터**(MDIS) | 신청 절차 + 지역 식별이 시도 수준(서울 내 구분 불가) | ❌ 마이크로데이터 폐기 → **KOSIS 공표 테이블**로 대체 (즉시 접근) |
| K-apt 시세 조인 | 아파트 거주자만 커버, 조인 공수 대비 이득 불확실 | 🔶 옵션 레이어로 강등 |
| 국세청 자치구 통계 | 문제 없음 | ✅ 유지 (검증용) |

**교훈**: "신청·반출이 필요한 데이터"를 주 경로에 두면 계획이 아니라 희망이 된다.
v2는 **모든 주 경로 데이터가 즉시 다운로드 가능**함을 원칙으로 한다.

## 2. 문제의 학술적 정식화와 선행 연구

우리가 풀 문제는 문헌에서 확립된 문제다: *전국 단위로만 정확한 소득 분포를,
소지역(행정동) 집계 제약과 결합해 개인(에이전트)에게 부여*하는 것.

| 선행 연구 | 방법 | 우리에의 시사 |
|---|---|---|
| **SimAthens** — Panori et al., *CEUS* (2017) ([arXiv](https://arxiv.org/abs/1611.07824)) | 그리스 센서스 소지역 표 + EU-SILC 소득 마이크로데이터를 **IPF 재가중** → 소지역 소득분포·빈곤율 | 문제 구조가 우리와 동일 (전국 분포 + 소지역 제약 → 개인 부여) |
| [Spatial microsimulation 방법 리뷰, *Int. J. Microsimulation*](https://microsimulation.pub/articles/00092) | IPF·simulated annealing·combinatorial optimisation 비교, **internal/external validation** 프레임 | 검증 스위트 설계의 표준 (아래 §6) |
| [아일랜드 공개 합성인구 (2024, PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC12145541/) | ABM용 국가 합성인구 공개 데이터셋 | "분포적으로 옳은 배정"이 목표라는 프레임 |
| 한국 활동기반모형 합성인구 ([KITS 학회지](http://journal.kits.or.kr/journal/article.php?code=88220)) | 심층생성모델로 표본에 없는 결합특성 생성 | 국내 합성인구 선례 (교통 분야) |
| Beckman, Baggerly & McKay (1996) | IPF 합성인구의 고전 | 방법 계보 |

**핵심 관점 전환**: 개인의 '진짜 소득'을 맞추는 것은 원리상 불가능하고 문헌도 그걸 목표로
하지 않는다. 목표는 **모든 관측 가능한 집계 수준에서 실측과 일치하는 배정**이며,
그 일치를 자동 검증 수백 건으로 입증한다 (§6).

## 4. 방법 후보 비교 — 문헌 대조 후 채택

| 방법 | 요구 데이터 | 장점 | 단점 | 판정 |
|---|---|---|---|---|
| A. IPF 재가중 (SimAthens) | 소득 **마이크로데이터** 표본 | 결합분포 보존 | 국내 공개 마이크로데이터가 서울 내 지역 식별 불가 (v1 실패 지점) | ❌ 데이터 요건 미충족 |
| **B. 계층 파라메트릭 소지역 보정** | D1+D2+D4 (전부 공개) | 마이크로데이터 불요, 투명·재현 가능, 꼬리는 실측 천분위 사용 | 동 내 분산을 모형 가정에 의존 | ✅ **채택 (주 방법)** |
| **C. 순위 결합 (Iman–Conover)** | D4의 소득-지출 관계 | 소비와의 실측 상관 재현, 기존 `build_rank_coupling.py` 재사용 | 상관 하나로 결합구조 요약 | ✅ **채택 (B에 결합)** |
| D. 심층생성 (VAE/CTGAN, KITS류) | 마이크로데이터 | 고차 결합특성 | 불투명·검증 어려움·데이터 없음 | ❌ |
| E. LLM 추정 (현행) | — | 공짜 | **소비 분위의 재표현 → 순환·왜곡** (문제의 원인) | ❌ 폐기 대상 |
| F. 주거 프록시 회귀 | D5 | 동 내 이질성 | 아파트 편중 | 🔶 2단계 보강 |

### 채택 파이프라인 (B+C) — 수식 수준

```
[Step 1] 전국 분포 모양:  국세청 천분위(D2) → 서울 근로소득 분포 F(x)
         비근로(자영·무직·고령) 보정: 가금복(D4) 가구소득 분포와 혼합
[Step 2] 연령×성 조건부:  D4 연령대별 소득 → 연령·성 배율 m(age,sex)
[Step 3] 행정동 보정:     D1 동별 평균 μ_d → 로그정규 location shift
         F_d,age,sex(x) = F( x · μ̄ / (μ_d · m(age,sex)) )   (전 동 평균은 불변 — 총량 보존)
[Step 4] 에이전트 표집:   u ~ rank-couple(spending decile, ρ*)   ← C
         income_i = F⁻¹_d,age,sex(u),  ρ* = D4 소득-지출 실측 상관 (연령별)
[Step 5] 산출 필드:       p_income_pct (0~100 백분위) + p_income_level_v2 (5단 tier)
         → 2차 쿠폰 "상위 10%"를 tier 근사가 아닌 정확한 컷으로
```

기존 인프라 재사용: `scripts/persona/build_rank_coupling.py` (순위 결합),
`scripts/prep/` 빌더 패턴, 검증은 `validate_*` 순수함수.

---## 5. 기존 필드와의 관계

- `p_income_level`(LLM 추정)은 **보존** (기존 런 재현성) — v2는 `p_income_level_v2`·`p_income_pct` 신규 필드로 병존.
- `consumption.INCOME_PRIOR`(MPC 골격)·`plan_writer.get_grant_amount`·정책 `income_grants` 가 읽는 소득을 v2로 전환하는 스위치: `INCOME_FIELD=v2` env.
- 소비 행동 자체는 불변 — 바뀌는 것은 **정책 타깃팅**(누가 얼마 받나·누가 제외되나)뿐.

## 6. 검증 스위트 — 자동 체크 ~560건 (요청하신 "수십·수백 개 검증")

`scripts/sim/validate_income.py` 가 전 체크를 자동 판정, pass rate 리포트.

| 블록 | 내용 | 기준 | 건수 |
|---|---|---|---|
| V-A 공간 재현 | 동별 배정 평균 vs D1 μ_d | 상대오차 ≤10% | **421** |
| V-B 독립 원천 검증 | 자치구 평균 vs D3 (국세청 — D1과 원천 다름) | Spearman ≥0.85 + 구별 오차 | **26** |
| V-C 분포 모양 | 서울 전체 5% 분위 19개 vs D2 천분위 | 분위별 상대오차 ≤10% | 19 |
| V-D 조건부 분포 | 연령(6)×성(2) 평균·분산 vs D4 | ±15% | 24 |
| V-E 소득-소비 결합 | ρ 전체 + 연령별(6) vs D4 실측 | ±0.05 | 7 |
| V-F 불평등 | 지니·p90/p10·상위10% 점유율·중위/평균비 vs 공표 | ±10% | 5 |
| V-G 정책 타깃 정합 | 상위 10% 컷 인구 비중 = 10±0.5%, tier 구성, 쿠폰 1·2차 대상자 수 | 정확 | 12 |
| V-H 재현성 | 시드 3런 × 주요 지표 동일성 | 완전 일치 | ~30 |
| V-I **음성 대조(placebo)** | 소득을 무작위 셔플한 배정이 V-A~F를 **불합격**하는지 — 스위트가 진짜 판별력이 있음을 자가 증명 | 셔플 pass rate < 5% | ~500 (음성 반복) |
| | | **합계** | **~560 + 음성 500** |

합격 기준: V-A~G 종합 pass rate ≥ 90% & V-I 셔플 pass rate < 5% (판별력 입증).

## 8. 리스크 (정직)

| 리스크 | 대응 |
|---|---|
| D1이 '추정 소득'(카드사 모델) — 과세 실측 아님 | **V-B가 존재 이유**: 독립 원천(국세청)과 자치구 수준 교차 검증. 불일치 구가 있으면 해당 구만 D3 쪽으로 보정 |
| D2가 근로소득자만 (자영업·무직 누락) | Step 1의 가금복 가구소득 혼합으로 보정, TASIS 종합소득 백분위도 병용 |
| 동 내 분산의 모형 의존 (로그정규 가정) | 민감도: 분산 파라미터 ±20% 런, (2단계) D5 주거 프록시로 세분 |
| 소득-소비 ρ의 연령 이질성 | V-E가 연령별로 검증 — coupling도 연령별 수행 |
