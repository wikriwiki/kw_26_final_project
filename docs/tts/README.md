# TTS 준비물 · Tella 촬영 순서

낭독 대본을 **클립 단위**로 잘라 뒀다. 파일 하나가 오디오 하나다.
사람이 읽을 때 쓰는 표시(`/`, 굵게)는 전부 뺐고, 쉬는 자리는 쉼표와 마침표로만 남겼다.
숫자는 전부 한글이라 TTS가 헷갈리지 않는다.

**발화 합계 134초.** 180초 중 46초가 무음이다. 그 46초가 화면을 보는 시간이다 —
줄이지 말 것. 3분 내내 말하면 아무것도 안 보인다.

`_all.txt` 는 전체를 이어 붙인 것. 길이 확인용이고, **실제로는 클립별로 뽑는다.**
한 덩어리로 뽑으면 화면과 어긋났을 때 전부 다시 해야 한다.

## TTS 설정

| 항목 | 값 | 이유 |
|---|---|---|
| 속도 | **0.95배** (기본보다 약간 느리게) | 기본 속도면 숫자가 뭉갠다 |
| 목소리 | 중저음 남성 또는 차분한 여성 | 밝고 높은 톤은 광고처럼 들린다 |
| 감정/표현력 | 낮게 | 설명하는 톤이지 파는 톤이 아니다 |
| 형식 | WAV 또는 48kHz MP3 | Tella에 올릴 때 손실 적게 |

**뽑은 뒤 반드시 들어볼 것 세 군데**

1. `칠천오백` — "칠천 오백"으로 끊기면 어색하다
2. `일 분위 / 이 분위` — "1분위"로 읽히면 안 된다. 이상하면 `일분위`로 붙여 쓴다
3. `이억 원` — "이 억원"으로 끊기는 TTS가 있다

셋 다 어색하면 그 문장만 숫자 표기를 바꿔 다시 뽑는다. 파일이 나뉘어 있어 그 클립만 다시 하면 된다.

## Tella 촬영 순서

Tella는 **장면을 나눠 찍고 나중에 잇는다.** 한 번에 3분을 찍지 않는다.

1. **오디오를 먼저 뽑는다.** 각 클립 길이를 알아야 화면을 얼마나 보여줄지 정해진다
2. **화면만 무음으로 찍는다.** 장면 6개를 따로 찍는다 (목록 / 지도 / 결과 / 보고서 / 문답 / 마무리)
   - 각 장면은 오디오 길이 + 2~3초 여유를 두고 찍는다
   - 보고서 장면만 55초로 길다. 스크롤을 천천히
3. **Tella에서 오디오를 얹는다.** 클립 순서대로 붙이고, 무음 구간에서 화면이 계속 움직이게 맞춘다
4. **자막을 넣는다.** 아래 표 참조

말하면서 조작하지 않는 편이 낫다. 조작에 신경 쓰면 말이 빨라지고, 말에 신경 쓰면 마우스가 헤맨다.

## 촬영 직전 점검

```bash
python -m uvicorn web.api.app:app --host 127.0.0.1 --port 8000
```

- [ ] 3D 지도를 한 번 열어 캐시에 올렸다 (첫 로드 18.8MB)
- [ ] `만들어진 보고서` 에 한 줄 있다 (현장에서 만들면 60초 걸린다)
- [ ] 인터뷰에 쓸 대상자를 정했다 — **쿠폰을 실제로 쓴 사람**
- [ ] 그 대상자에게 미리 한 번 물어봤다 (응답이 빨라진다)
- [ ] 브라우저 1440×900, 배율 100%, 시크릿 창
