## 결론과 이전 보고서 정정

이전 보고서는 3051e95와 미커밋 파일을 기준으로 했다. 이번에는 지정 커밋을 별도 worktree로 고정했다. 기존 작업 디렉터리의 변경은 보존했다.

최신 커밋에는 건별 정책 결제 선택(choice_shares), 온라인/비사용처 지출 분리, 환경·기전 모듈, 상세 방문 이유 저장, 캐시백 실적 및 채점 도구가 이미 추가되어 있었다. 이전 보고서의 “지원금 전액 자동사용”, “방문 기억에는 만족도만 있다”는 설명은 이 커밋에 그대로 적용할 수 없다.

다만 새 모듈의 존재와 실행 타당성은 다르다. 이번에는 결제 선택과 회계의 불일치, 기억 시점, 사회적 후속 연결, 평가 표본 오류를 수정했다. 정책별 입장을 가진 완전한 실행 모형까지 완성했다는 뜻은 아니다.

### 1. 실제 결제 선택에 따른 현금 보존

기존 코드는 정책 결제가 전액 가능하다고 가정해 구매액을 결정하고, 마지막에는 선택 비중만 정책지갑으로 결제했다. 부족한 자기자금이 생겨도 State의 0원 하한이 이를 숨길 수 있었다.

## 테스트와 검증 범위

일부 테스트는 새 choice/온라인 모형에도 자동지갑·고정 금액을 기대했다. 현재 의미에 맞춰 변경하되 자동정산 테스트는 settle_policy_spend_priority 직접 호출로 유지했다. 실패를 숨기기 위한 skip은 넣지 않았다.

- 일일 태세가 미선택 거래를 강제로 사용하지 않음.
- 무활동일 이월 0.
- 업종 진입·이탈·비소비자 유지.
- 역순 날짜 거부, 공통 정책 부재 거부.

## 적용과 후속 순서

이번 수정은 별도 브랜치에 보관하며 기존 진행 중 런에 섞지 않는다. 소비·채점 의미가 달라졌으므로 기존 결과와 새 결과를 같은 실험으로 합치면 안 된다. 과거 파일·운영 DB는 변경하지 않았다.

후속 순서:
1. 이번 패치의 DB 통합 검증.
2. Night2 완료 manifest·원장 복구, 초기 State 사전검사.
3. Decision/Execution/Observation 계약과 시간·정책 제약 엔진.
4. 과거 관측 기반 정책 입장을 다음 기존 호출에 포함.
5. 인간 설문과 시점·집단을 맞춘 반응 평가.

추가 LLM 호출은 도입하지 않았다. 안전 보정이 필요한 경우 CPU 정산 계산은 반복되므로 전체 지연이 0 증가라고 주장하지 않는다. 이번 패치는 실행·채점 결함 수정이며 인간 행동 디지털 트윈의 완성 또는 검증 완료가 아니다.
