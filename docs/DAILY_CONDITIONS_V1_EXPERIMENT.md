# 당일 선행 상태를 고정한 범용 문구 비교

기존12명·알려진4기전·on/off의96조건에 동일한 당일 의무와 생활 자원 상태를 제공한다.
범용 v24와 간결한 v25를 각각seed52001,512추론 토큰,온도0.2에서 비교한다.
정책 이름·효과 방향·실측 수치를 두 공통 프롬프트에 넣지 않는다.
두 후보는 같은 입력·활동 사전·30분 시각 문법·18시 이후 마무리 표현 범위를 사용한다.

등록 설정은 `data/experiments/validation_daily_v1_v24.json`,
`data/experiments/validation_daily_v1_v25.json`이다. 조건 파일 SHA256:
`78961fc28d0f27915a58b2db58c22d3fdc888f3e4be4bbfc6d56dbf054e29000`.

## 제공 조건과 해석 범위

- 원래 시민 서술을 복원한 persona_v1의 정량·정책·상품·자금 입력을 그대로 사용한다.
- 근무자8명에게09~17시, 학생2명에게09~15시의 명시적 일정 가정을 준다.
  나머지2명에게는 추가 확정 의무가 없다. 실제 개인 시간표나 역사적 등교를 관측한 값이 아니다.
- 학교는 선언한 주거 동의 zone anchor다. 이 동을 다른 외출 동과 구별해 시간 구간을
  검사한다. 실제 학교 POI나 교실 체류·연속 수업 참여를 관측/검증한 것은 아니다.
- 집↔학교 동 최소 이동30분은 조건 공급자가 선언한 가정이며,30분 시각 격자의 기존
  최소 간격과 같다. 학생의 실제 통근시간을 학습하거나 맞혔다고 세지 않는다.
- 시민 ID 정렬 순서로 세제 보유량0회분/2회분을 번갈아 부여한다. 정책 조건과 무관하다.
- 모든 시민에게 밀린 빨래1회분을 오늘 하고 싶은 선택적 필요로 제공한다. 다음 날로 미룰 수
  있으며, 세탁·세제 구입을 정답이나 필수 지출로 만들지 않는다.
- 기존12,000원 세제 후보는 합성 가정상10회분이며 주문90분 후 도착한다. 실제 포장 용량,
  당일 배송, 역사적 가격을 주장하지 않는다. 다른 식품·생필품 수요 전체는 아직 모델링하지 않는다.

## 실행과 선택 기준

각 후보의96조건을 모두 한번 실행한다. 입력 사실과 실행 검사, 요청 오류, 시간 보정,
평균 생성량을 확인하고 모든 행동열을 검토한다. 완전한 적격 계획 행렬만 실제 결제 단계로
넘긴다. 실패를 탈락시켜 행렬을 줄이거나0원으로 바꾸지 않는다. 원문과 모든 실패를 보존한다.

두 후보의 후속 결제에는 동일한 v7문구와 v4회계 계약을 적용한다. v7은 일반적인 재고,
수령 지연, 기존 일정의 자원 사용만 안내한다. 정책별 구매 방향은 지시하지 않는다.
회계가 맞아도 도착 전 사용·재고 초과 사용이 있으면 해당 경로는 실패한다.
물품을 사지 않거나 세탁을 미루는 것은 가능하며 미충족 필요 수를 별도로 남긴다.

선별은 선언된 조건 준수·실제 사용 가능성·일상 행동의 일관성·생성량에 근거한다.
지출 증가, 오프라인 활동 수, 지급 재원 사용량, 기대 정책 부호는 정답이 아니다.
두 후보가 모두 적격이면 전체 후속 검증이 유지되는 범위에서 간결한 문구를 선호한다.
단일seed 개발 비교이며 새로운 정책 홀드아웃이나 유의성·외부 효과 크기 검증이 아니다.

## 구현한 검증 장치

`daily_resource_contract.py`는 실제 구매 선택과 시간순 활동에서 자원 증감을 계산한다.
물품을 구입했는지, 언제 도착하는지, 사용 시점에 남아 있는지를 검사한다. 부족한 자원을
보충하거나 이미 정한 활동을 삭제해 성공으로 고치지 않는다. 자정 이후 도착분도 보존한다.

`paired_asset_score.py`는 원문에서 회계와 물리적 자원 검사를 다시 수행한다.
초록색valid표시만 믿거나 재고가 틀린 경로를 소비 효과에 포함하지 않는다.
계획과 결제의 daily_conditions가 바뀌면 연결 보고서도 거부한다.

`asset_day_checkpoint.py`에는 재고·단위·배송 중 물품의 일간 연속성 검사를 추가했다.
다음 날 재고를 처음 값으로 재설정하거나 밤사이 배송을 누락하면 저장을 거부한다.
이는 코드와 합성 단위시험으로 확인한 기능이며 이번 단일 일자 모델 실험이 다일 롤아웃을
검증했다는 뜻이 아니다. 소득 유입·새 필요 발생·기억과 전체 가계 수요의 상태 전이는 남아 있다.

실험 시작 전370개 단위검사가 통과했다. 별도 체크포인트와 독립 재검사를 보강한 뒤
전체373개가 통과했다. 실행 중인 두 계획 후보의 입력·문구·활동 계약은 변경하지 않는다.
