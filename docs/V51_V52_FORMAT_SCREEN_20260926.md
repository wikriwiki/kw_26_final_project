사전등록의 v51 판정에는 **짝지은 McNemar 양측 p<0.05**가 필요하다. 원시 응답을 재계산하면 v45→v51의 개선 21칸·악화 6칸·정확 양측 p=**0.0059246**으로 v51은 등록한 형식 관문을 통과한다. v45→v52는 개선 22칸·악화 12칸·p=**0.1214495**로 등록 관문을 통과하지 않는다. 두 값 모두 실행 로그의 보고와 일치한다.

원시 ID 검증 전에는 같은 384칸의 짝지음이 맞는지 알 수 없었으나, 회수한 동결 입력과 응답을 비교해 각 후보의 **동일한 384칸**이 중복·누락 없이 있음을 확인했다. 요약의 주변합만으로 계산한 v51의 가능한 p 범위 **0.000061~0.01353**, v52의 가능한 p 범위 **0.00195~0.14331** 안에 위 원시 재계산 값이 들어간다.
