# P012 상생소비지원금 — 3주 A/B 실행 (2026-10-05)

엔진·실행기 설명: `docs/KW26_MERGE_20261005.md`. 검수: `data/experiments/AB3W_REVIEW_20261005.md`.

## 창
- 정책 전 주(공통): 2021-09-24 ~ 09-30
- 정책 있음/없음: 2021-10-01 ~ 10-07 (7일 — 문턱·한도를 7/31 로 줄인 압축월 정책 파일 `data/experiments/P012_v53_compressed7_main_20260929.json` 과 짝)
- 9월 지출은 10월 누적에 섞이지 않는다(엔진이 매달 1일에 월 누적을 0 으로 돌린다).

## 실측 지표와 출력
| 지표(평가항목.md) | 무엇과 맞대나 | 출력 |
|---|---|---|
| P012-1 적립업종 지출 + | 적립 대상 가게 지출, 정책 있음 − 없음 | sector 원장 `sangsaeng_eligible_offline_spent` |
| P012-2 제외업종 0 | 제외 업종(온라인·대형점 몫) 지출 차이 | sector 원장 `online_spent`(+ 안분값 `online_by_kdi_attributed`) |
| P012-3 문턱 도달자 비율 > 0 | 압축월 문턱을 넘은 사람 비율 | cashback 원장 |
| P012-4 1인 평균 캐시백 > 0 | 1인 평균 캐시백 | cashback 원장 |
| P012-5 가전·가구 > 이·미용 | 업종별 증가율 순위 | sector 원장 `by_sub` |
| P012-6 한도 도달 비율 > 0 | 한도 10만원(압축월 비율) 도달 | cashback 원장 |

제약: 값은 창 길이에 따라 움직인다(7일 +18.9% / 31일 +11.3%, 이미 측정). 방향과 순위 위주로 읽는다.
