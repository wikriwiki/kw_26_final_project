# 사회적 거리두기 2단계(2020-11-24) — 3주 A/B 준비 상태 (2026-10-05)

엔진·실행기 설명: `docs/KW26_MERGE_20261005.md`. 검수: `data/experiments/AB3W_REVIEW_20261005.md`.

**아직 돌릴 수 없다.** 실행기 설정(`tools/ab3w_cases.sh` 의 distancing)은 아래를 고치기 전까지 멈추도록 돼 있다.

## 설계
- 정책 전 주(공통): 2020-11-17 ~ 11-23 (`covid_2021`: 11-17·18 은 1단계, 11-19~23 은 1.5단계)
- 정책 있음: 11-24 ~ 11-30 `covid_2021`(2단계)
- 정책 없음: 11-23 의 1.5단계를 그대로 이어 간다 — 정답지(서울연구원)는 2단계 이상 vs 그 아래 단계를 비교한다
- 명부: `output/cohort/distancing_ab3w_2000.json`(2020-10 서울 주민등록 분포)

## 먼저 고칠 것
1. 정책 없음 쪽 사회 배경: 지금의 `covid_no_distancing`(거리두기 전혀 없음)은 11-24 에 오히려 완화 충격을 준다. 11-23 규칙을 유지하는 환경이 필요하다.
2. 정책 없음 쪽 머리말의 "비교 조건" 문구 — 모델이 실험 중임을 안다.
3. 규칙 집행: 지금은 Stage1 프롬프트에만 있다. 문 닫은 업종(유흥 5종)·21시 이후 매장 취식을 후보 가게에서 거르고, 걸러진 수를 기록한다.
4. 카페 규칙 한 줄("매장 취식 21:00까지")이 실제(종일 포장·배달만)와 다르다. 100명 이상 행사 금지가 빠졌다.
5. 규칙 자료(단계표 json)를 실행 지문에 넣는다.
6. 짝 채점기(`paired_distancing_effect.py`)는 두 갈래의 실행 ID 가 달라야 한다고 본다 — 이 설계에서는 같다(같은 정책 전 주의 기억을 이어받는다). 환경 ID 가 다르고 출력 폴더가 다르면 허용하도록 바꾼다.
