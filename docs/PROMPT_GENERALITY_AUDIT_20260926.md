# 범용 프롬프트 상태 재감사 (2026-09-26)

사용자 목표는 정책·시대 배경을 별도 입력으로 받고, 한 시민의 미시 선택에서 여러 정책 효과의 **방향과 대략적인 크기**를 설명하는 공통 지시문이다. 평가용 실측 부호·수치는 지시문에 넣지 않는다.

## 코드에서 실제로 렌더되는 문구

`SIM_PROMPT_VARIANT=v5`는 `scripts/sim/prompts/p012.py`의 시스템 본문 중 `daily_propensity` 블록만 바꾼다. 렌더된 나머지 본문에는 캐시백 5회, 문턱 6회, `10%` 1회, `[쿠폰]` 1회, 바우처 3회, `grant_kept_share` 4회가 남는다. 캐시백 지급률 자체는 정책 사실이지만, **별도 정책 입력이 아닌 공통 시스템 지시문에 있다**는 것이 문제다. 현재 A100 프로세스 1474197의 `SIM_PROMPT_VARIANT=v5`를 확인했다. 따라서 이번 P012 28일 런과 기존 v5 비교는 역사적 기준선이며, 정책에 중립적인 프롬프트가 효과를 낸 증거로 쓰지 않는다.

| 렌더된 후보 | SHA256 | 공통 본문에서 위 정책 특화 어휘 | 판정 |
|---|---|---:|---|
| v5 | `250311b63adbc4f6c1b9851e9e320da34b728a8fff0bb6664c470a6d0ea39562` | 남음 | 역사적 기준선, 범용 적격 아님 |
| v45 | `d36a1763095459b228b4f8c226af9f4166ea838fc393ea3764ec4ab5252baec3` | 없음 | 정책 중립 **후보**, 형식 지표 개선 근거 있음 |
| v51 | `10ac99d9efb2a9bab102809b159e76558793fe5cd1008f0799a2dc27a822d143` | 없음 | v45의 장소 형식 수정 후보 |
| v52 | `3f652ab4d4cc11cb9c4b444b2984bbf1ed5eb7fc0815edd11c44891b88bc03b5` | 없음 | v45의 설명 필드 수정 후보 |

이 어휘 검사는 필요한 조건일 뿐이다. 정책 사실 입력의 누락·절단, 암묵적 결과 유도, Stage2 후보·금액 후처리, 소비 엔진 회계도 따로 검증해야 한다. v45/v51의 형식 계약 개선이 실측 효과의 방향·크기 개선으로 이어졌다고 해석하지 않는다.

## 기존 'v5 최적' 판정의 범위

`experiments/SELECTED_PROMPT.md`는 당시의 등록 규칙에서 v5를 유지한 **이력**이다. 그 문서가 같은 눈금처럼 차감한 P012 로그 삼중차분과 짧은 전후 변화, 거리두기 전년비와 같은 해 이틀 변화, P013 전년비와 단기 전후 변화는 이후 원문 감사에서 서로 다른 추정량으로 확인됐다. `docs/VALIDATION_GAPS_20260926.md`에 따르면 현재 38개 중 외부 실측 크기와 동일 추정량으로 확인된 직접 비교는 0개다. 기존 P013 런은 지급이 0원이었던 문제도 있다. 현재 P012 진단 런에는 Stage2 전체 실패 후 자동 POI 대체가 10월 1~16일 정상 metrics의 500건 있었다. 따라서 역사적 순위는 보존하되 범용 최적판의 검증 판정으로 승격하지 않는다.

## 다음 판정 순서

1. 현재 28일 런 완료와 서버 밖 원장·그래프·로그 백업을 먼저 마친다. 실행 중 코드와 DB를 바꾸지 않는다.
2. 같은 시민·환경의 짧은 기술 점검에서 새 Stage2 실행 계약과 생성 품질 관문을 확인한다. 정책 효과 점수에 이 점검을 섞지 않는다.
3. v5는 역사적 기준선으로 분리한다. 정책 중립 후보의 렌더된 공통 지시문과 정책별 사실 블록을 따로 보존하고, 후보 선택 전에 시민·달력·엔진·정책 ON/OFF·시드·추정량·결측·복제 조건을 고정한다. 프롬프트 간 효과를 비교하려면 같은 정책에서 두 프롬프트 모두 ON/OFF 팔이 필요하다.
4. P012의 달력 월 지급 기전과 P013의 지급액 대비 소비 반응을 각 사전등록의 계측기로 채점한다. 정책별 원문과 모형의 추정량이 다른 숫자는 `규모 참고`로 두고 직접 오차로 합산하지 않는다. 개발에 쓴 정책에서 후보를 골랐다면 새 정책/기간을 독립 검증으로 확보한다. P015는 재실행하지 않는다.

이 파일은 이전 프롬프트 선별의 이력을 지우지 않고 **그 주장의 적용 범위를 정정**한다. 정책별 실측값은 평가 문서에만 둔다.
