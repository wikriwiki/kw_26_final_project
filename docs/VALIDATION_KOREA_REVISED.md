# 한국 데이터 기반 재검증 — 외출 횟수(정답 교체) · 소비/공간 지니

**대상 데이터**: `neo4j_backup_20260607_104307` (14일: 2026-05-25 ~ 06-07, agent 7,500명, plan 104,994개, includes 948,423행, P009 지원금 포함)
**변경점(Task A)**: 외출 횟수 정답을 **미국 NHTS → 한국 KOTI/서울연구원(수도권 가구통행실태조사)** 로 전면 교체. 추가로 **소비 지니·공간 지니를 BDC 실측에서 직접 계산**하여 시뮬과 비교.

> 한 줄 요약: 공간 분포는 실제 서울과 잘 맞고(✅), 소비 불평등은 시뮬이 너무 평등하며(✗, `daily_wd` 고정 탓), 외출 횟수는 정답을 한국 기준으로 바꾸니 "이동이 다소 과다"가 드러남(△).

## ⓪ 왜 NHTS를 버렸나 (Task A 배경)

- 기존 검증은 외출 횟수 정답으로 **미국 NHTS형 "2~6번/일"** 이라는 느슨한 범위를 썼다. 서울 시민의 통행을 미국 가구통행조사로 검증하는 것은 부적절(국가·도시구조·통행정의 상이).
- 한국 공식 정답으로 교체:
  - **서울 1인 목적통행 원단위 = 2.59 통행/인·일 (2010년, 5세 이상)** / 1996년 2.34 — 서울연구원 「통계로 본 서울 교통」(수도권 가구통행실태조사).
  - **서울 일평균 통행 ≈ 3.7 통행/인 (2022년)** — 서울연구원 「도시모니터링 2024·교통」(일평균 3,498만 통행 ÷ 서울 인구 약 940만).
- BDC 통신데이터의 `평일총이동횟수(tel_wd_move_cnt)`도 검토했으나, 집계 기간(월/연 단위)이 다른 지표와 혼재해 **절대 일통행수 정답으로는 부적합** → KOTI 공식 원단위를 1차 정답으로 채택.

## ① 외출/통행 횟수 — KOTI 정답으로 재검증

**정의가 두 가지라는 점이 핵심.**
- **통행(이동) 수**: 하루 동안 *머문 장소가 바뀐 횟수*(귀가 포함). KOTI "통행"과 같은 정의.
- **외출 목적지 수**: 집·직장을 뺀 *방문한 장소(POI)의 개수*.

| 측정 | 시뮬 결과 | 한국 실측(정답) | 판정 |
|---|---|---|---|
| 통행(이동) 수 | **평균 6.26회** (평일 6.34 / 주말 6.06, 중앙 6) | 목적통행 2.59 / 전체통행 3.7 | △ 과다 |
| 외출 목적지 수 | **평균 3.65개** (중앙 4) | (목적통행과 같은 자릿수) | △ |
| (참고) 기존 "외출활동수" | 평균 3.71 | NHTS 2~6 → **폐기** | — |

- **분포(통행 수)**: 0회 6명 → 5회 19,231 → **6회 32,869(최빈)** → 7회 22,746 → … 14회 2명. 6회 중심의 깔끔한 **단봉형**(현실적인 종 모양).
- **해석**: 분포 *모양*은 자연스럽지만, **이동 횟수(6.26)가 서울 목적통행(2.59)·전체통행(3.7)보다 많다.** 원인은 에이전트가 활동과 활동 사이에 **집으로 자주 복귀**해 통행을 추가로 만들기 때문. 미국 NHTS의 느슨한 "2~6번" 기준에서는 ✅처럼 보였으나, 한국 공식 원단위로 바꾸자 **과다 이동**이라는 한계가 드러났다.
- **발표용 프레이밍(정직 범위 내)**: "외출 *목적지* 수는 평균 3.65개로 서울 통행 발생량(2.6~3.7)과 같은 수준이며, 분포는 6회 중심 단봉형으로 현실적이다. 단, 매 활동 후 귀가까지 세는 *이동 횟수* 기준으로는 다소 과다하여 향후 보정 대상이다."

## ② 소비 불평등 지니 — 시뮬 vs BDC 실측

| 구분 | 지니계수 | 비고 |
|---|---|---|
| **시뮬** 1인당 소비 | **0.250** | n=7,500, 1인 평균 54,276원/일 |
| **BDC 실측** 평일 1인·1일 소비 | **0.424** | 카드소비 10분위(decile) 기반 |
| **BDC 실측** 주말 1인·1일 소비 | **0.448** | 〃 |

- **정답 데이터**: BDC `weekday_spending_level`의 **1인·1일 평균 소비 10분위 경계값**(682원 ~ 798,508원). 각 분위(인구 10%)의 중간값으로 지니 산출.
- **해석**: **시뮬의 소비 불평등(0.250)이 실제 서울 카드소비(0.424)보다 현저히 낮다 = 에이전트들이 너무 비슷하게 쓴다.**
  - BDC 분위 중간값 방식은 분위 *내부* 분산을 무시하므로 **실제 지니의 하한(下限)** — 즉 진짜 실측 지니는 0.42보다 더 높다. 따라서 시뮬이 너무 평등하다는 결론은 더 강해진다.
  - 원인은 알려진 구조적 결함과 직결: 소비가 페르소나의 **고정 `daily_wd`(일일 예산)** 에 묶여 개인 간 변동이 압축됨.
- **발표용 프레이밍**: "소비의 *공간·시간 패턴*은 잘 맞지만, *개인 간 소비 격차*는 시뮬이 과소(0.25 vs 실측 0.42). 이는 소비액을 고정 예산에 앵커링한 설계 때문이며, 예산 앵커를 풀면 개선되는 식별된 한계다."

## ③ 공간(소비 집중) 지니 — 시뮬 vs BDC 실측

| 단위 | 시뮬 지니 | BDC 실측 지니 | 모양 일치 |
|---|---|---|---|
| **자치구(25개)** | **0.162** | **0.215** | cosine **0.944**, JSD 0.026 |
| **행정동** | 0.312 (372개) | 0.252 (421개) | — |

- **정답 데이터**: BDC `dong_context.b069_sales`(행정동별 매출지수, held-out). 동→자치구 합산.
- **시뮬 공간**: includes의 소비를 viz POI→동 매핑(커버리지 53.5%)으로 자치구에 배정, 거주 인구로 가중.
- **해석**:
  - **자치구 단위: 시뮬 0.162 ≈ 실측 0.215** — 같은 자릿수의 완만한 집중. 형태 일치 **코사인 0.944**(강남 등 상위 상권 순서 재현). ✅
  - 동(洞) 단위: 시뮬 0.312 > 실측 0.252 — 미세 격자에서는 시뮬이 *조금 더* 쏠림. 매핑 커버리지(53.5%) 한계 영향 포함.
- **발표용 프레이밍**: "소비가 서울 *어느 지역*에 몰리는지의 패턴이 실제와 코사인 0.944로 거의 일치하고, 집중도(지니)도 자치구 기준 0.16 대 0.22로 같은 수준이다 → 공간 재현성은 강하다."

## ⑤ 부록: 지니계수 계산식 (노션 붙여넣기용)

지니계수 = 불평등/집중도 (0 = 완전 평등, 1 = 완전 독점)

```
        2 · Σ (i · x₍ᵢ₎)       n + 1
G  =  ────────────────────  −  ──────       (x₍ᵢ₎ = 작은 값부터 정렬한 i번째 값)
         n · Σ x₍ᵢ₎              n
```
- x₍ᵢ₎ = 정렬된 i번째 값(소비 지니=1인 소비액 / 공간 지니=지역별 소비·매출), n = 대상 수.
- 코사인 유사도(공간 형태 일치)·JSD는 본 프로젝트 `VALIDATION_P009_BACKUP.md` 부록의 공식과 동일.
