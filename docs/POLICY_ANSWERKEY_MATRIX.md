# 정책별 정답지 매트릭스 — 소비행동 프롬프트 일반화 실험

작성 2026-09-13. 목적은 **정책과 무관한 소비행동 프롬프트 하나**를 만드는 것이다.
정책마다 프롬프트를 따로 두면 새 정책이 들어왔을 때 어느 프롬프트가 좋은지 알 수 없고,
그러면 "그 정책용으로 맞춘 것"이라는 반론에 답할 수 없다.

설계: **훈련 정책 N개로 소비 프롬프트를 피팅 → 정답지를 열지 않은 홀드아웃 1개로 검증.**
맞추는 것은 수치가 아니라 **방향(부호와 순위)** 이다.

---

## 0. 오염 방지 규칙

> **시행방안·보도자료는 봐도 된다. 효과분석은 보지 않는다.**

정책 JSON·사회배경·적격 POI 룰은 전부 시행방안에서 나온다. 효과분석에는 결과가 들어 있다.
홀드아웃의 효과분석은 봉인하고 **마지막 1회 채점 때만** 연다. 돌려보고 고치면 홀드아웃이 아니다.

**이미 태운 정책** — 아래 5개는 이 문서를 쓰면서 효과분석을 읽었으므로 홀드아웃으로 쓸 수 없다.
P010 · P012 · 긴급재난지원금 1차 · 거리두기 · 지역사랑상품권 · (일부) 2021 국민지원금.

## 1. 훈련 정책 (6)

### ① P010 민생회복 소비쿠폰 (2025) — `wallet` · 증가

한국은행 이슈노트 2026-13. 보유·검증 완료. MPC 실측 0.21 대비 시뮬 0.213.

### ② P012 상생소비지원금 (2021.10) — `cashback` · 증가

기획재정부·KDI 「상생소비지원금 사업의 효과 분석」(2022.9).
지표 32개를 `docs/SANGSAENG_VALIDATION_MATRIX.md` 에 사전등록해 두었다.
핵심: 적립업종 +20.82% vs 제외업종 +2.85%(유의하지 않음), 캐시백 1만원당 소비증가 16,503원,
업종순위 가전·가구 +36.23% > … > 이·미용 +2.87%.

### ③ 긴급재난지원금 1차 (2020.5) — `wallet` (가구단위·소멸 3개월) · 증가

### ④ 사회적 거리두기 2단계 이상 (2020) — `hours_limit` · **감소와 증가가 함께**

서울연구원 정책리포트 「코로나19 확산이 서울 지역에 미친 경제적 손실」(주재욱·노승철·윤종진, 2021.4).
**신한카드 2019~2020 서울 데이터 · 패널분석** — 지역도 데이터 종류도 우리와 같다.

| 지표 | 실측 | 부호 |
|---|---|---|
| 음식점 매출 (전년비) | **−14.1%** (약 1.5조) | − |
| 음식점 — 거리두기 2단계 이상 추가효과 | **−14%** | − |
| **소매업 매출** | **+4.2%** | **+** |
| 관광특구 매출 | −8.7% | − |
| 발달상권 매출 | −4.4% | − |
| 관광특구 유동인구 | −25.5% | − |
| 발달상권 유동인구 | −13% | − |
| 유동인구 탄력성 (유동 1% → 음식점 매출) | 0.34% | + |
| 점포 매출 총 감소 | 약 4.8조원 | − |

> **한 정책 안에서 음식점(−14.1%)과 소매업(+4.2%)의 부호가 반대다.** 이것이 이 정책을
> 훈련에 넣는 가장 큰 이유다. "정책이면 늘어난다" 로도 "제약이면 줄어든다" 로도 수렴할 수 없다.

보조: 정보통신정책연구 30(3) 「사회적 거리두기 정책의 효과 분석: 영업시간 제한 vs 사적 모임 인원 제한」
(김다미·김용규, 2023) — 구글 이동성 기준, **영업시간 제한은 소매·여가 이동 유의하게 감소**.

### ⑤ 사적모임 인원 제한 (2020 가을) — `gathering_limit` · **무효**

같은 논문. 인원 제한 더미는 **유의하지 않음**. 거주지 이동만 증가.

> 카드매출 기준 분석은 찾지 못했다. 이동성 기준 무효를 정답으로 쓴다.
> 2020.12 5인 금지는 2.5단계와 동시 시행이라 기전 분리가 불가능해 제외했다.

### ⑥ 지역사랑상품권 (2018~) — `price_discount` + 지역 사용처 제한 · **총액 무효 + 장소 이동**

조세재정연구원 「지역화폐 도입이 지역경제에 미친 영향」(송경호·이환웅, 2020) 외.

| 지표 | 실측 | 부호 |
|---|---|---|
| 소비지출 **규모** | 영향 미미 | **0** |
| 구매처 — 동네상권 비중 | 증가 | + |
| 역외 소비 | 단기 차단 | − |
| 전 지자체 동시 발행 시 지역경제 활성화 | 효과 소멸 | 0 |

> **"총액은 안 변하고 장소만 옮긴다"** 는 이 조합이, 총액 앵커에 묶여 있는 우리 구조와
> 오히려 잘 맞는다(§3 참조). 그리고 "정책 = 소비 증가" 로 수렴한 프롬프트를 정확히 잡아낸다.

## 2. 정답 방향의 분포

| 방향 | 정책 |
|---|---|
| 증가 | P010 · P012 · 긴급재난지원금 |
| 감소 | 거리두기 (음식점·대면업종) |
| 증가 (같은 정책 안에서) | 거리두기 (소매업) |
| **무효** | 사적모임 인원 제한 · 지역사랑상품권(총액) · P012 제외업종 |

**무효가 정답인 지표를 반드시 섞는다.** 우리 프롬프트가 무슨 정책이든 효과를 만들어내면
증가·감소는 다 맞춰도 무효에서 걸린다. 이것이 이 채점표의 핵심 방어선이다.

---

## 3. 우리 구조가 낼 수 있는 지표 / 없는 지표

피팅 **전에** 갈라 두어야 한다. 구조가 못 내는 값을 목표로 주면 프롬프트가 그걸 억지로
짜내고, 홀드아웃에서 무너진다.

| 낼 수 있다 | 근거 |
|---|---|
| 업종 구성 변화 · 업종 간 상대 순위 | POI 선택이 자유롭다 |
| 상권유형별 차이 (관광특구/발달/골목) | `hub_catalog.json` 보유 |
| 유동인구·이동거리 변화 | 이동을 산출한다 |
| 적립/제외 업종 대조 | `sangsaeng_eligible` 백필 |
| 개인 내 쌍체차 (off vs on) | 같은 에이전트를 연속으로 돌린다 |

| 낼 수 없다 | 이유 |
|---|---|
| **배달·온라인 대체** | 배달은 페르소나 통계(`delivery_days`)일 뿐 거래 채널이 아니다 |
| **총소비의 큰 폭 감소** | 하루 총액이 페르소나 앵커에 묶이고 소비성향 밴드가 ±0.12 |
| 가구 단위 지표 (가구원수별) | 우리는 개인 단위다 |
| 온라인 쇼핑 전환 | POI 기반이라 온라인이 없다 |

→ **감소 정책의 채점은 총액이 아니라 업종 구성·상권유형·이동으로만 한다.**

## 4. 기전 모듈 (정책은 파라미터만 준다)

정책마다 코드를 새로 쓰면 프롬프트를 일반화해도 배관에서 1:1 결합이 되살아난다.
현재 P012 는 캐시백이 코드에 박혀 있다(`dawn_context._format_cashback_status`,
`sangsaeng_eligibility.py`). 이것을 아래로 분해한다.

| 기전 | 파라미터 | 쓰는 정책 |
|---|---|---|
| `wallet` | 금액 · 지급단위 · 사용처 · 소멸일 | ① ③ |
| `cashback` | 환급률 · 문턱 · 한도 · 정산지연 | ② |
| `hours_limit` | 대상업종 · 차단시각 · 포장배달 허용 | ④ |
| `gathering_limit` | 인원상한 · 시간대 · 예외 | ⑤ |
| `price_discount` | 할인율 · 사용처 · 구매한도 | ⑥ |

적격 POI 판정도 정책 전용 코드가 아니라 **정책 JSON 의 룰 명세**(업종코드 포함·제외,
규모 기준, 브랜드 목록)를 평가기 하나가 읽는 방식으로 바꾼다. 그래야 홀드아웃 정책을
코드 수정 없이 붙일 수 있고, 그게 일반화 주장의 실체가 된다.

## 5. 홀드아웃 후보 (효과분석 미열람)

훈련이 `wallet` · `cashback` · `hours_limit` · `gathering_limit` · `price_discount` 를
쓰므로, 홀드아웃은 이 다섯에 없는 기전이어야 진짜 시험이 된다.

| 후보 | 시기 | 기전 | 비고 |
|---|---|---|---|
| 8대 소비쿠폰 (숙박·관광·공연·영화·전시·체육·외식·농수산물) | 2020.8 / 2021.10 | `sector_voucher` — 업종 한정 할인 + 선착순 수량 | 업종이 우리 POI 에 다 있다 |
| 외식할인쿠폰 | 2020~2021 | `usage_count_rebate` — **횟수** 문턱 (금액 아님) | 요식이 우리 최대 업종 |
| 유류세 인하 | 2018.11 / 2021.11 | `tax_cut` — 재화 가격 인하 | 주유소가 우리 Category 어휘에 없다 — 구현 필요 |

**권장 프로토콜**: 홀드아웃은 사용자가 고르고 **효과분석은 사용자가 봉인**한다.
나는 시행방안만 보고 배관을 만들고, 채점은 봉인 파일을 여는 마지막 1회에만 한다.

## 6. 남은 확인 사항

- 거리두기 ⑤(인원 제한)의 **카드매출 기준** 정답지 — 현재 이동성 기준뿐
- 지역사랑상품권의 **업종별** 이동 방향 — 현재 "동네상권으로 이동" 수준
- 2021 국민지원금은 P012 관측창(2021.10)과 시기가 겹친다. 우리 P012 시뮬에는
  국민지원금이 들어 있지 않다 — 교란 요인으로 보고서에 명시할 것
