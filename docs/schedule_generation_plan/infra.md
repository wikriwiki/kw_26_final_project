## 1. 두 가지 실행 모드

### Mode A — vLLM 자체 호스팅 (권장)

- 실행 스크립트: `run_vllm.sh`
- 기본 모델: **Gemma-4-26B-A4B-it** (현 설정, MoE, bf16, ctx 8192)
- 대안:
  - **Qwen2.5-7B-Instruct** — 빠름, 한국어 안정
  - **EXAONE-3.5-7.8B** (LG) — 한국어 특화, 서사성 우수
- 구조화 출력: vLLM `guided_json` (outlines/xgrammar 자동)
- Prefix caching 자동 활성 → per-agent 고정 블록(1,150 토큰) 재사용
- **Graphiti NL 추출용 LLM 호출도 동일 vLLM**에서 처리(에이전트간 대화·정책 뉴스만 대상, 전체의 소수 비중)

### Mode B — Qwen Turbo API (fallback)

- A100 미가용 시에만 선택
- 에이전트별 context cache + CSV 압축 필수
- JSON mode로 구조화 출력 강제 후 Pydantic 재검증

## 2. 토큰 예산 (호출당)

에이전트 1명 × 하루 = **2회 호출** (Stage 1 → Stage 2).

**Stage 1 — "무엇을 할까"**

| 블록 | 토큰 | 캐시? |
|---|---|---|
| System 지시 | 300 | ✅ 전역 |
| 페르소나 + 고정 장소 + 참조통계 + 카테고리 어휘 | 700 | ✅ per-agent |
| 날짜·요일 | 100 | ❌ |
| memory_context (30일 Top-5~7) | ≤500 | ❌ |
| policy_context (awareness≥0.3) | ≤200 | ❌ |
| social_context (14일 pending 포함) | ≤400 | ❌ |
| Intent zone 힌트 | ≤150 | ❌ |
| running_state (정책 수혜 시 쿠폰 포함) | ≤100 | ❌ |
| **Stage 1 입력** | **~1,950** | - |
| Stage 1 출력 (category 시퀀스) | ~300 | - |

**Stage 2 — "어디로 갈까"** (미결 event만 처리, pinned_poi는 Stage 2 우회)

| 블록 | 토큰 | 캐시? |
|---|---|---|
| 페르소나 + 고정 장소 | 450 | ✅ per-agent |
| 미결 이벤트 목록 (Stage 1 출력 중 pinned 제외) | ~200 | ❌ |

| **Stage 2 입력** | **~1,850** | - |
| Stage 2 출력 (미결 event POI 확정) | ~250 | - |

**합계: 입력 ~3,800 / 출력 ~550** (2회 호출 합산, 하루 1~2 event 평균 pin 가정)

### Mode B 비용 산출 상세 (2-Stage 기준)

Qwen Turbo 단가 (2026 초 근사):
- 입력 $0.05 / 1M 토큰
- 출력 $0.20 / 1M 토큰
- 캐시 입력 $0.025 / 1M 토큰 (캐싱 시 50% 할인 가정)

agent-day당 2회 호출. 캐시 블록: Stage 1 고정 700 + Stage 2 고정 450 = **1,150 토큰**.

| 구분 | 계산 | 비용/agent-day |

| Day 1 (캐시 miss) | 3,800×$0.05/M + 550×$0.20/M | $0.000300 |
| Day 2+ | 2,650×$0.05/M + 1,150×$0.025/M + 550×$0.20/M | $0.000271 |

**60일 합계**: 60K × ($0.000300 + 59×$0.000271) ≈ **$977**

## 4. A100 처리량 추정

단일 A100 80GB + vLLM 기준:

| 모델 | VRAM | Aggr 처리량 | 60K/일 소요 |
|---|---|---|---|
| Gemma-4-26B-A4B | ~52GB | 10~15k tok/s | ~7~8 hr |
| Qwen2.5-7B | ~16GB | 20~30k tok/s | ~3~4 hr |
| EXAONE-3.5-7.8B | ~18GB | 20~30k tok/s | ~3~4 hr |

**Day 2 이후**: Prefix cache가 1,150 토큰 고정 블록을 재사용 → 실효 처리량 1.3~1.5배 개선.

**60일 Full 총 소요**: ~150~250 GPU-hr ≈ **6~10일 ** (단일 A100 연속 가동).

**7일 POC**: 4~8시간.

> 60K×60일이 10일 내에 처리 불가능하면 7B급 모델로 다운사이즈하거나 동시성을 조정.
