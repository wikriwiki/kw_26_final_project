## 1. 어떤 정책으로 실험하나

한 칸은 **한 사람의 하루**다. 같은 사람·같은 날짜에 정책 문구만 넣고 뺀 두 팔을 만들고,
그 차이를 지표로 환산해 실측과 견준다.

| 기전 | 칸의 날짜 | 현실 대응 | 정답지 출처 |
|---|---|---|---|
| P012 캐시백 | 2021-10-25 | 2021 상생소비지원금 | 기획재정부·KDI (2022.9) |
| P013 정책지갑 | 2020-05-14 | 2020 1차 긴급재난지원금 | KDI FOCUS |
| P014 할인 상품권 | 2020-09-23 | 지역사랑상품권 할인발행 | 조세재정연구원 (2020) |
| 거리두기 2단계 | 2020-11-24 | 수도권 2단계 (정책 아님·사회 배경) | 서울연구원 (2021.4) |

정책 정의·정답지·라운드별 결과는 [`data/POLICIES.md`](../data/POLICIES.md) 에 폴더별로 묶여 있다.

**프롬프트에는 정책 이름도, 원하는 방향도, 실측 수치도 한 글자 없다.**
금지어 목록을 둔 단위 테스트가 그것을 고정한다(현재 473개 통과).

## 2. 검증은 어떻게 하나

```
같은 사람 · 같은 날짜 · 같은 프롬프트
  ├─ off 팔   정책 문구 없음
  └─ on  팔   정책 문구 있음
       차이를 지표로 환산 → 실측 부호·크기와 대조

계획 → 자원 게이트 → 수정 3바퀴 → 조립 → 결제 → 채점
```

- **사전등록**: 판정선·취소선을 **결과보다 먼저** 커밋한다. 커밋 시각이 증거다
- **순환 금지**: 실측 부호·크기·공식을 프롬프트에 넣지 않는다
- **구간**: 95% 붓스트랩. 0을 지나면 **부호조차 말하지 않는다**

## 4. 오늘 알아낸 것 — 왜 안 맞는지

### (1) 표본을 키우자 틀린 답이 확신을 얻었다

```
열두 명    DS-1 구간이 0을 지남              "모른다"
예순 명    DS-1 구간이 0을 지남              "모른다"
백스무 명  DS-1 +169.2 [+40.0, +533.3]      "확신을 갖고 틀렸다"
```

세어 보면 한 줄이다.

```
거리두기 칸 · 무정책 62 · 정책 67
  매장·포장   0 →  0        한 건도 없다
  배달       13 → 35
정책 팔 식사 35건 중 배달 35건 (100%)
```

**+169.2% 는 배달 35건 위에서 계산된 값이다.** 실측 −14.1% 는 **매장 취식 붕괴**가
배달 증가를 압도한 값인데, 우리에게는 붕괴할 매장이 0건이다.

모델은 정책에 **올바른 종류로** 반응한다 — 거리두기가 걸리자 배달로 간다.
다만 그 반응을 재는 자가 매장 취식을 재도록 만들어져 있다.

> **검정력은 정렬을 고쳐 주지 않는다.**
> 자세히: [`POWER_WITHOUT_ALIGNMENT.md`](../experiments/POWER_WITHOUT_ALIGNMENT.md)

### (2) 계획이 집 밖 활동을 거의 안 고른다

```
구매 가능 활동 17개 중 11개가 480개 계획에 단 한 번도 안 나옴
빠진 11개는 전부 집 밖에서 해야 하는 것

쇼핑   home_online_goods  95회  ·  shopping (매장)   0회
식사   home_delivery     115회  ·  meal_takeaway     0회
```

**세 가지 설명이 배제됐다.**

| 설명 | 배제 근거 |
|---|---|
| 카탈로그에 없다 | 열넷 전부 60명 **모두의** 활동 사전에 있다 |
| 문법이 막는다 | 열넷 전부 60/60 문법에 있고 **자리도 더 많다**(2,642 대 2,360) |
| 자원이 모자란다 | 게이트는 계획 **뒤**에 돈다 |

남는 것은 모델의 선택뿐이다.

### (3) 모델은 구매를 위해 나가지 않는다 — 이미 하던 이동에 붙인다

서로 다른 프롬프트로 돌린 두 런이 독립적으로 같은 것을 가리킨다.

```
v25   재직자 나간 적 있음 11/34(32%) · 통근 56.6분 대 30.4분 · p=0.0001
      비재직자 나간 적 있음  1/26(4%)
v36   재직자 나간 적 있음 10/34(29%) · 통근 54.7분 대 32.3분 · p=0.0002
      비재직자 나간 적 있음  0/26(0%)
```

집 체류·소비액·이동성은 갈리지 않는다. **통근만 두 배 넘게 다르다.**

이 하나로 전부 설명된다 — 왜 96.7%의 계획에 집 밖 구매가 없나(붙일 이동이 없다),
왜 집 변형이 이기나(이동이 필요 없다), 왜 DS-1이 안 움직이나(매장 취식이 요구하는
이동이 안 생긴다).

> 자세히: [`THE_HOME_VARIANT_MONOPOLY.md`](../experiments/THE_HOME_VARIANT_MONOPOLY.md)

## 5. 프롬프트 후보 — 무엇을 시험했고 무엇이 남았나

| 라운드 | 후보 | 무엇을 | 결과 |
|---|---|---|---|
| v21 | **v36** | 3행 "평균 지출과 과거 비중은…" 삭제 | 기각 · +0.0000 [−0.0229, +0.0229] |
| v21 | **v37** | 9행 `대체·` 삭제 | 기각 · −0.0083 [−0.0292, +0.0125] |
| v21 | **v38** | 위 둘 + 18행, **셋 합침** | 기각 · +0.0042 [−0.0187, +0.0271] |
| v22 | **v39** | 6행 "먼저 확정된 일정을 배치하고…" 삭제 | **주 지표 기각**, 그러나 ↓ |

**v39 가 예측한 자리에서 갈렸다.**

```
              칸       집 밖 칸        차이
비통근 26명   208       1 → 7      +0.0288  [+0.0096, +0.0529]   갈림
통근  34명   272      15 → 14      +0.0000  [-0.0368, +0.0404]   0을 지남
```

**비통근자만 움직이고 통근자는 건드리지 않았다.** 기전이 예측한 그대로다 —
6행이 하루를 **확정된 의무의 뼈대**로 세우므로 의무 없는 사람에게는 이동의 틀이
없었고, 그 문장을 빼자 그들에게만 틀이 생겼다.

그 부분군은 **돌리기 전에** "이 라운드의 진짜 물음"으로 사전등록문에 적혀 있었다.
그래도 **판정은 기각**이다 — 부 지표를 사후에 주 지표로 바꾸지 않는다.
[v24](../experiments/v24/prompt_v24.md) 가 새 씨앗에서 확증한다.

### 한 가지 규칙이 드러났다

```
v30  금지 대상에서 낱말을 지움        움직였다
v39  순서를 정하는 문장을 지움        움직였다 (부분군)
v31  부정문을 서술로 바꿈             안 움직였다
v35  부정문을 서술로 바꿈             안 움직였다
```

**금지를 지우면 움직이고, 서술을 더하면 안 움직인다.**

## 7. 이 검증이 유효하다고 말할 수 있는가 — 부분적으로만

**말할 수 있는 것**

- **대조가 성립한다** — on/off 가 같은 사람·같은 날짜다
- **사전등록이 결과보다 앞선다** — 커밋 시각으로 증명된다
- **순환이 없다** — 금지어 단위 테스트로 고정돼 있다
- **오염이 들어오지 않았다** — 오늘 서버가 다섯 번 죽었는데, 회로 차단기가
  기반 고장을 값으로 기록하기 전에 멈췄다

**말할 수 없는 것**

- **부호를 맞히지 못했다** — 9개 중 맞힌 것 0개, 틀린 것 1개
- **여덟 지표는 구조적으로 못 낸다** — 월 단위 회계, 업종 계층 부재
- **크기를 맞댈 수 없다** — 카탈로그는 낱개 단가, 실측은 카드매출
- **행렬이 불완전하고, 팔에 따라 불균등하다** — 960칸 중 487칸이 남았고 그중
  on/off 짝이 온전한 것은 197쌍뿐이다. 지역화폐에서는 정책 팔이 체계적으로 더 많이
  탈락한다(McNemar p=0.003). 지표는 이제 짝만 써서 낸다

> **요약: 설계와 실행은 유효하나, 상류가 막혀 있어 정답지 지표가 아직 의미를
> 갖지 못한다.** 그 상류를 여는 것이 지금 하는 일이다.

## 부록 — 오늘 고친 기반

| 무엇 | 왜 |
|---|---|
