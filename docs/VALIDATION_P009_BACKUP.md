# P009 시뮬레이션 타당성 검증 — 13일 전체 데이터 (쉬운 설명판)

## 이 문서가 답하는 질문
> **"우리가 만든 가상 시민 시뮬레이션이 진짜 서울 사람들처럼 행동하는가?"**

확인 방법: 시뮬레이션이 만든 행동 기록을 **실제 데이터**와 비교합니다. 단, **시뮬을 만들 때 쓰지 않은 데이터**(held-out)로 비교해야 공정합니다.

## 검사한 데이터
- 기간: 2026-05-25 ~ 06-06 (**13일**, 주말 포함) · 가상 시민 **7,500명** · 행동 기록 **83.7만 건**
- 정책: **P009 — 소득이 낮을수록 더 많은 현금 지급**(하 60만 / 중하 45만 / 중 25만 / 중상 10만, 상층 제외)

> 📌 "기준값"은 **합격선이 아니라 참고선**입니다. 교통모형 검증 매뉴얼(Cambridge Systematics, 2010)도 단일 합격/불합격 판정을 권장하지 않습니다. "이 정도면 현실적"이라는 참고 범위로만 씁니다.

## ② 항목별 자세한 설명

### 1. 시간대 — "하루 중 언제 소비하나?"
**무엇을 보나**: 24시간을 시간별로 나눠 "그 시간에 활동한 비율" 그래프(시뮬 vs 실제)를 겹쳐봅니다.
**닮음을 재는 법**: **코사인 유사도**(두 그래프 *모양*이 같으면 1, 다르면 0; 0.8↑이면 상당히 닮음), **JSD**(두 그래프가 *다른 정도*; 0이면 동일).
**정답 데이터**: 통신 기반 성·연령별 시간대 활동량(BDC). 시뮬에 안 쓴 held-out.
**기준이 왜 그 값인가**: 유사 연구가 같은 방식을 씀 — Liao et al.(2025)은 OD 코사인 0.97·JSD 0.006을 "강한 일치"로 보고. 그 척도에서 0.8/0.1을 보수적 참고선으로 채택.
**우리 결과**: 코사인 **0.83**, JSD **0.069**, 점심 피크 **시뮬·실제 모두 12시 일치**.
**무슨 뜻**: ✅ 하루 리듬 *모양*은 현실적. 단 시간대별 *양*의 오차(MAPE 45%)는 큼(점심에 너무 몰림).

### 2. 외출 횟수 — "하루에 몇 번 나가나?"
**무엇을 보나**: 한 명이 하루에 몇 곳을 다니는지. 정의가 두 가지 — ① 외출 **목적지 수**(집·직장 제외 방문 장소), ② **통행(이동) 수**(장소가 바뀐 횟수, 귀가 포함).
**정답 데이터(한국)**: 서울 **목적통행 원단위 2.59 통행/인·일**(2010; 1996년 2.34) — 서울연구원 「통계로 본 서울 교통」(수도권 가구통행실태조사). 전체 통행 기준으로는 약 **3.7 통행/인·일**(2022, 서울연구원 도시모니터링). ※ 이전 보고서의 미국 NHTS(2~6번) 기준은 폐기.
**우리 결과**: 외출 목적지 **3.65개**, 이동(통행) **6.26회**(평일 6.34/주말 6.06), 분포는 6회 중심 단봉형.
**무슨 뜻**: △ 분포 *모양*은 단봉형으로 자연스러우나, **이동 횟수(6.26)가 서울 목적통행(2.59)·전체통행(3.7)보다 많음** — 에이전트가 행동 사이 귀가를 자주 해 통행이 과다. (미국 NHTS 기준일 땐 ✅처럼 보였으나, 한국 정답으로 바꾸니 과다가 드러남.)

### 3. 단골 — "같은 가게에 다시 가나?"
**무엇을 보나**: 한 가게를 몇 번 재방문하는지의 분포. 현실은 "대부분 1회, 소수만 단골".
**정답 데이터**: 소비자 반복구매 실증 — 한 번 방문이 가장 많고 점점 줄어드는 긴 꼬리(Ehrenberg, 1988).
**우리 결과**: 1회 38.6% → 2회 21% → 3회 16% … 계속 줄어드는 꼬리.
**무슨 뜻**: ✅ 현실의 단골 형성 패턴과 같은 모양.

### 4. 빈부 격차 — "소비 격차가 현실적인가?"
**무엇을 보나**: 소비 격차를 **지니계수**로 측정(0=모두 같음, 1=한 명 독식).
**정답 데이터**: 통계청 — 한국 **소득** 지니 약 0.39. 단 **소비** 격차는 소득보다 항상 작음(소비평탄화, Friedman, 1957).
**우리 결과**: 소비 지니 **0.26** (소득 0.39보다 낮음).
**무슨 뜻**: ✅ "소비 불평등 < 소득 불평등" 법칙과 방향·크기 일치.

### 5. ⚠️ 지원금 효과 — "현금 받으면 더 쓰나?" (가장 중요)
**무엇을 보나**: 현금을 받은 사람이 그 돈을 실제로 얼마나 쓰는지 = **MPC(한계소비성향)**. 예: 60만 받아 6만 쓰면 10%.
**정답(현실 법칙)**: **가난한 사람일수록 받은 돈을 더 많이 쓴다**(돈이 급하니까). 근거: Jappelli & Pistaferri(2014) — "여유 현금이 적은 가구가 부유층보다 MPC가 훨씬 높다"; Johnson, Parker & Souleles(2006) — 2001년 세금환급에서 저소득·저자산 가구의 소비반응이 더 큼.
**우리 결과 (정반대!)**:

| 소득 | 받은 돈 | 쓴 비율(MPC) | 실제 쓴 총액 |
|---|---|---|---|
| 하 (제일 가난) | 60만 | **4%만 씀** | 44.9만 (제일 적음) |
| 중하 | 45만 | 6.7% | 61.5만 |
| 중 | 25만 | 12.8% | 63.8만 |
| 중상 | 10만 | **34% 씀** | 64.1만 (제일 많음) |

**무슨 뜻**: ❌ **현실과 거꾸로.** 제일 많이 받은 저소득층이 4%만 쓰고(96% 미사용), 총소비도 최저. **원인**: 시뮬에서 소비 금액이 '평소 일일 예산(daily_wd)'에 묶여, 저소득층은 예산이 작아 큰 지원금을 평소만큼만 쓰고 끝남. **구조적 결함이며 수정 가능**(예산을 소득·지원금에 연동).

### 6. 지역 분포 — "소비가 서울 어디에 몰리나?"
**무엇을 보나**: 소비가 25개 자치구 어디에 몰리는지가 실제 매출 분포와 닮았는지.
**정답 데이터**: 동별 실제 매출 지수(BDC, held-out) + 가게 위치는 시각화 데이터로 연결(커버리지 55%).
**기준 근거**: 분포 모양은 코사인/JSD(Liao et al., 2025); 오차·상관은 교통모형 매뉴얼(Cambridge Systematics, 2010, ※합격/불합격 비권장); 공간 밀도 검증은 소매 ABM(Horikomi & Mizuno, 2025).
**우리 결과**: 코사인 **0.95**, JSD 0.024 → 분포 모양 잘 맞음. 단 소비 집중도 시뮬 0.15 < 실제 0.22.
**무슨 뜻**: ✅ 전체 모양은 현실적. △ 강남·종로 같은 번화가로 덜 몰리고 자기 동네에서 소비하는 경향(home-bias).

## ④ 결론
- **잘 맞음(✅)**: 시간·단골·지역 분포 *모양* — 현실 데이터·정설과 부합.
- **애매(△)**: 시간대별 소비량 크기; 도심 쏠림(약함); **외출 횟수(한국 기준으로 재검증 시 이동 과다)**; **소비 불평등(시뮬 0.25 < BDC 실측 0.42, 너무 평등)**.
- **틀림(❌, 중요)**: **현금 지원금이 저소득 소비를 늘리지 못함**(오히려 거꾸로). `daily_wd` 고정이 원인, 수정 가능.

> **한 문장**: 평소 일상 소비는 실제 서울과 꽤 닮게 재현하나, 지원금을 받았을 때 더 쓰는 효과는 (특히 저소득층에서) 작동하지 않습니다.

## ⑤ 부록: 지표 수학 정의 (Formulas)

> 공통 표기: 분포는 구간(bin)별 벡터로 만든 뒤 비교한다. 시간 = 하루 7~21시(구간 n=15), 공간 = 서울 자치구(n=25).
> Sᵢ, Rᵢ = i번째 구간의 **시뮬·실제** 값 / Pᵢ, Qᵢ = 합이 1이 되도록 정규화한 비율 / Σ = 모든 구간 합 / √ = 제곱근.

**(1) 코사인 유사도 (Cosine similarity)** — 두 분포의 *모양* 일치도

```
                 Σ (Sᵢ · Rᵢ)
cosine(S, R) = ─────────────────────────
               √(Σ Sᵢ²) · √(Σ Rᵢ²)
```
- 범위 0~1. **1이면 완전히 같은 모양**, 0이면 무관. 크기(총량)는 무시하고 방향(비율 패턴)만 본다.

**(2) Jensen–Shannon Divergence (JSD)** — 두 분포가 *다른 정도*

```
D_KL(P ‖ Q) = Σ Pᵢ · log₂(Pᵢ / Qᵢ)          (상대 엔트로피)
M = ½ (P + Q)                                 (두 분포의 평균)
JSD(P ‖ Q) = ½ · D_KL(P ‖ M) + ½ · D_KL(Q ‖ M)
```
- D_KL은 한 분포가 다른 분포와 얼마나 다른지(상대 엔트로피), M은 둘의 평균. JSD는 D_KL을 **대칭·유계(0~1)** 로 만든 것.
- 범위 0~1(log₂ 기준). **0이면 동일**, 작을수록 닮음.

**(3) MAPE (평균 절대 백분율 오차)** — 구간별 *크기* 오차

```
          100      | Sᵢ − Rᵢ |
MAPE =  ─────── · Σ |─────────|   (%)     (Rᵢ > 0 인 m개 구간만)
            m       |   Rᵢ    |
```
- 각 구간이 평균 몇 % 어긋났나. 작을수록 좋음.

**(4) 지니계수 (Gini coefficient)** — 불평등 / 집중도

```
        2 · Σ (i · x₍ᵢ₎)       n + 1
G  =  ────────────────────  −  ──────       (x₍ᵢ₎ = 오름차순 정렬값)
         n · Σ x₍ᵢ₎              n
```
- x₍ᵢ₎ = 작은 값부터 정렬한 i번째 값(예: 한 사람의 소비액, 또는 한 자치구의 소비액), n = 대상 수.
- 범위 0~1. **0 = 완전 평등, 1 = 완전 독점**. 소비 불평등(사람별)·공간 집중도(자치구별)에 사용.

**(5) 피어슨 상관계수 (Pearson r)** — *값*의 직선 상관

```
            Σ (xᵢ − x̄)(yᵢ − ȳ)
r  =  ──────────────────────────────────
       √(Σ (xᵢ − x̄)²) · √(Σ (yᵢ − ȳ)²)
```
- x̄, ȳ = 각 변수의 평균. 범위 −1~1. **1 = 완전한 양의 직선관계.** 소득–소비, 시뮬–실제 자치구 소비에 사용.

**(6) 스피어만 상관계수 (Spearman ρ)** — *순위*의 상관

```
              6 · Σ dᵢ²
ρ  =  1  −  ──────────────       dᵢ = rank(xᵢ) − rank(yᵢ)
             n · (n² − 1)
```
- dᵢ = 두 값의 **순위 차이**. 값 대신 순위를 보므로 이상치·비선형에 강함. "어느 구가 더 큰가"의 순서 일치를 잰다.

**(7) 한계소비성향 (MPC, Marginal Propensity to Consume)** — 지원금 소비율

```
            Σ policy_spend  (그룹 g가 정책으로 쓴 금액)
MPC_g  =  ─────────────────────────────────────────
            Σ grant_received (그룹 g가 받은 지원금)
```
- g = 소득 그룹(하 / 중하 / 중 / 중상). 받은 지원금 중 **실제로 정책소비에 쓴 비율**.
- 현실 정설: **저소득 그룹의 MPC가 더 높다**(본 시뮬은 반대 → 결함).
