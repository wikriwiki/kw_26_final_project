## 0. 핵심 아이디어

시뮬레이션은 **페르소나 + LLM 추론**으로 각 에이전트의 행동을 생성한다. 검증은 그렇게
**창발(emergent)된 집단 분포**가, 시뮬 생성에 **직접 쓰지 않은 독립 실측 통계**와 일치하는지를 본다.
일치하면 "현실의 소비 패턴을 재현했다"(= **외부 타당성**)는 근거가 된다.

> 핵심 개념: **held-out** — 검증의 정답으로 쓰는 통계는 행동을 스크립팅하는 데 쓰지 않고 떼어 둔다.

## 1. 정답(ground truth)으로 쓴 데이터

정답은 시뮬이 만든 값이 아니라 **실제 서울 통계**다. 원천은 모두 **서울시 빅데이터 원본 데이터**
(원본 CSV: 통신사 29종 지표 · 신용카드 소비 데이터 · KT 유동인구 · 집계구 결제 데이터)이며,
아래는 그 원천을 검증용으로 집계한 것이다.

| 평가 항목 | 정답으로 쓴 실제 데이터 |
|---|---|
| 시간대 활동분포 | **통신사(텔레콤)·유동인구 기반 성·연령대별 시간대 활동 분포** |
| 공간 소비분포 | **상권발달지수 — 행정동별 매출지수** (매출·점포·유동인구·집객·금융 개별지수 중 *매출지수*) |
| 통행/외출 횟수 | **서울연구원 「2022 수도권 가구통행실태조사」 (KOTI 제공)** — 서울 통행원단위 ≈ **3.7 통행/인·일**, 목적통행 2.59 |
| 소비 불평등 | **신용카드 소비 데이터 기반 평일/주말 소비수준 10분위(decile)** |
| 재방문·단골 | 소비자 충성도 **Zipf 정형사실**(소비자행동 문헌) |

> 위 통계는 시뮬레이션의 행동 생성에 **직접 쓰지 않고 검증용으로 떼어 둔(held-out)** 값이다.
> ⚠️ 통행 정답으로 처음 쓰던 **NHTS(미국 가구통행조사)는 한국에 부적절**하여 전면 폐기하고
> 위 서울연구원/KOTI 자료로 교체했다.
> (집계 산출 파일 — 시간대: `global_distributions.json` · 상권: `dong_context.json` · 소비분위: `decile_boundaries.json`)

## 2. 평가 방식 (지표 정의)

분포 비교를 위한 정보이론·통계 지표 (검증 코드에 순수함수로 구현).

| 지표 | 의미 | 좋은 값 |
|---|---|---|
| 코사인 유사도 | 두 분포 벡터의 *방향(모양)* 일치도 | **1**에 가까울수록 동일 |
| JSD (Jensen-Shannon Divergence) | 두 확률분포의 정보이론적 *거리* (KL 대칭화) | **0**에 가까울수록 동일 |
| MAPE | 평균 절대 백분율 오차 | 낮을수록 |
| Pearson / Spearman | 선형 / 순위 상관 | 1에 가까울수록 |
| Gini 계수 | 불평등·집중도 (0=완전균등, 1=독점) | 실측과 비슷할수록 |

코사인은 "모양이 닮았나", JSD는 "구간별 차이가 작나"를 본다 — 둘이 함께여야 세부까지 일치 보장.

### 수식 (참고)

```
코사인 유사도
  cos(x, y) = Σᵢ xᵢyᵢ / ( √(Σᵢ xᵢ²) · √(Σᵢ yᵢ²) )

Jensen-Shannon Divergence  (M = (P+Q)/2)
  JSD(P‖Q) = ½·KL(P‖M) + ½·KL(Q‖M)
  KL(A‖B)  = Σᵢ A(i)·log₂( A(i) / B(i) )

Gini 계수  (v 오름차순 정렬, n개)
  G = ( 2·Σᵢ (i+1)·vᵢ ) / ( n·Σ v ) − (n+1)/n
```

## 4. 무엇을 평가했나 (6지표 + 결과)

| # | 평가 대상 (질문) | 방법 | 결과 |
|---|---|---|---|
| 1 | **언제** 소비하나 (시간대 분포) | cosine·JSD·MAPE vs 통신·유동인구 활동분포 | **cosine 0.857 · JSD 0.061**, 정오 피크 일치 |
| 2 | 하루 **얼마나** 다니나 (통행수) | KOTI 통행원단위와 대조 | 통행수를 KOTI 정의로 재계산해 비교 |
| 3 | **재방문·단골** 형성되나 | Gini·Zipf | 방문횟수 Gini, 충성도 분포 |
| 4 | **소비 불평등** | 1인당 소비 Gini | **시뮬 0.250** vs 카드소비 분위 실측 **0.424** |
| 5 | **정책 반응** (소득별 MPC) | 소득별 grant 소비율 | 저소득일수록 MPC↑ (정책 효과 확인) |
| 6 | **어디서** 소비하나 (공간 분포) | cosine·JSD vs 상권발달지수(매출) | **cosine 0.944 · JSD 0.026**, 공간집중 Gini 시뮬 0.162 / 실측 0.215 |

> 한 줄 요약: **시민들이 언제·어디서·얼마나·어떻게 소비하는지의 시공간·불평등 패턴이
> 실제 서울 통계와 객관적 지표로 거의 일치**함을 입증.

## 5. 한계 (정직한 짚음)

1. **공간 검증의 부분 순환성** — 광역이동 재설계에서 **상권발달지수(매출)**를 Huff *매력도 prior*로 쓰므로,
   공간 cosine은 일부 prior가 심어준 결과일 수 있음. **단 시간대 cosine/JSD·소비 Gini·MPC는
   매력도와 독립**이라 방어 가능.
2. **소득 라벨이 grant 역산** — 진짜 소득이 아니라 P009 지급액에서 역산한 근사값.
3. **표본 불균형** — 자치구별 에이전트 수 차이를 인구가중으로 보정(완전하지는 않음).
