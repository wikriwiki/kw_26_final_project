## 그런데 이 라운드의 더 큰 소득은 이것이다

**같은 프롬프트 v45 를 384칸으로 두 번 쟀다.**

```
v47 런의 v45   356/384   92.7%
v48 런의 v45   326/384   84.9%

짝지어 보면   개선 23 · 악화 53 · 순증 −30 · 뒤집힌 칸 76 · p=0.0008
```

**같은 프롬프트가 76칸을 뒤집고 순증 −30 이다.** 그리고 그 −30 이 McNemar 로
유의하다. 즉 **런 자체가 하나의 요인이다.**

v45 를 네 번 잰 기록을 모아 보면 이렇다.

```
v41 런 (192칸)   171/192   89.1%
v46 런 (192칸)   165/192   85.9%
v47 런 (384칸)   356/384   92.7%
v48 런 (384칸)   326/384   84.9%
```

**런 간 이동이 후보 간 효과보다 크다.**

```
런 이동 (같은 프롬프트)   −30칸
v49 − v45                +20칸
v48 − v45                 +9칸
v47 − v45                −17칸
```

## 그래서 무엇을 말할 수 있고 무엇을 말할 수 없는가

**말할 수 있는 것.** 같은 런 안에서 짝지은 비교는 칸의 난이도를 통제하므로
유효하다. 그리고 **v5 대 v45 계열은 그 잡음의 몇 배다.**

```
v5 → v45   +95칸   p<0.0001   (v47 런)
v5 → v47   +78칸   p<0.0001   (v47 런)
```

**말할 수 없는 것.** ±20칸 규모의 차이를 한 런으로 판정하는 것. 런이 혼자서
30칸을 움직인다. v49 의 +20 도, v47 의 −17 도, **한 런의 관측이다.**

> 내가 계산한 최소검출차(384칸에서 21칸)는 **런 안의 불일치**에서 나온 값이다.
> **런 사이의 이동은 거기에 안 들어 있었다.** 설계를 그만큼 낙관적으로 잡았다.
