## 이번에는 왜 졌는지가 보인다

앞의 두 라운드는 "v45 가 낫다는 증거가 없다" 였다 — 차이가 런 이동 안에
들어가 판정이 증거에 거의 기대지 못했다. 이번은 다르다.

```
지표      v5        v51        실측
DS-1     -7.7%     -7.4%     -14.1%     음식점 — 둘 다 덜 줄었다
DS-2     +3.1%    -15.1%      +4.2%     소매  — v5 는 늘었고 v51 은 크게 줄었다
DS-4    -11.7%    -25.6%     수치 없음    카페  — v51 이 두 배 이상 줄었다
```

**v51 은 전부 아래로 밀었다.** 소매가 −15.1%, 카페가 −25.6% 다. 실측에서
소매는 **늘었다**(+4.2%). 거리두기 2단계는 음식점 영업을 제한하지 소매를
제한하지 않으므로, 제약 업종에서 빠진 소비가 소매로 옮겨 가는 것이 실제 모습이다.

`DS-3` 은 바로 그것을 잡으려고 등록한 지표다. 채점표에 이렇게 적혀 있다.

> 소매 > 음식점 — **'제약이면 다 줄어든다'로 수렴한 프롬프트를 잡는다**

```
v5    쇼핑+마트  +3.1%  >  식사 -7.7%     적중
v51   쇼핑+마트 -15.1%  <  식사 -7.4%     빗나감
```

**v51 은 그 실패 모양 그 자체다.** 관문에서 v45 를 +15칸 이긴 후보가,
정답지에서는 "제약이 있으면 전부 줄인다" 로 수렴했다.

## 관문과 정답지가 세 번째로 갈렸다

```
              관문                     정답지
v5 → v45     +20.6%p (p<0.000001)     v50 갈림·라운드2 패 → v5 유지
v45 → v51    +15칸  (p=0.0059)        라운드3 패        → v5 유지
```

**관문 성적이 정답지 성적으로 옮겨지지 않는다**는 것을 이제 두 후보·세 라운드가
말한다. 관문은 형식(JSON 문법·필드 규칙)을 재고 정답지는 행동을 잰다. 형식을
조이는 문구가 행동을 실측 쪽으로 옮기지 않으며, 이번에는 **반대쪽으로 옮겼다.**

## 이 라운드가 말하지 못하는 것

**DS-2 의 −15.1% 를 v51 의 성질로 단정하지 않는다.** 같은 프롬프트의 런 이동이
13.1%p·2.7%p 로 재였고 한 수로 적을 수 없다(`run_shift_second_estimate.md`).
다만 **DS-3 은 순위 지표라 두 업종의 대소만 본다** — 금액 잡음이 약분되고,
그래서 판정을 거기에 걸어 두었다. 순위가 뒤집힌 것은 읽는다.

**한 정책 한 런이다.** v51 이 다른 정책에서도 같은 모양으로 지는지는 재지 않았다.
