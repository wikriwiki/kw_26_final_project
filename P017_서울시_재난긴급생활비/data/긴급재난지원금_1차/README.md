# 긴급재난지원금 1차

**정책** · `P013` · 기전 `grant` · 2020-05-13 ~ 2020-08-31

2020년 1차 긴급재난지원금. 정책지갑 지급 기전.

---

## 정책이 무엇을 하는가

정부가 코로나19로 위축된 소비를 살리고 생계를 돕기 위해 전 국민에게 지원금을 지급합니다. 가구원 수에 따라 1인 40만원, 2인 60만원, 3인 80만원, 4인 이상 100만원이며 신용·체크카드에 충전해 받습니다. 서울 시뮬레이션은 개인 단위이므로 서울 가구구성으로 환산한 1인당 28만원을 일괄 적용합니다. 대형마트·백화점·면세점·온라인몰·유흥업소에서는 쓸 수 없고, 거주 지역 안의 일반 가맹점에서만 쓸 수 있습니다. 8월 31일까지 쓰지 않은 금액은 소멸합니다.
