# S3 정책 설정 화면 계약

선행 계약: `s1.0.0`, `S2`
상태: 구현 완료, Critic 통과

정책 목록·상세·검증은 `/api/policies`와 `/api/policies/{id}/validate`만 사용한다.
편집 초안은 API가 반환한 원본 정책에서 복제하고, 화면에 숫자 KPI를 만들지
않는다.

- `grant_key_effective === "spend_decile"`이면 실제 `decile_grants`를 1~10분위 입력으로 표시한다.
- 그 외에는 실제 `income_grants` tier를 표시한다. 지급 필드가 없는 facility 정책은 빈 입력을 지어내지 않는다.
- 날짜·양의 정수·모순을 즉시 로컬 표시하고, 500ms debounce 후 실제 preflight subprocess 결과를 요청한다.
- JSON 미리보기는 현재 draft 전체를 `JSON.stringify`로 표시한다.
- 저장은 서버 PUT 이후 다시 GET preflight를 실행한다.
- `unknown[]`의 `db_wiring`은 성공 배지가 아니라 별도 미확인 경고로 표시한다.
