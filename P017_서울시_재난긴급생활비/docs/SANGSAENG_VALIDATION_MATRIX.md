## D. 대조 불가 — 명시할 것

- **수급 vs 미수급 구조** — 전 국민 대상 신청제라 우리 설계엔 대조군이 없다.
  KDI의 삼중차분 계수를 우리 쌍체차와 직접 비교하지 않는다.
- **가구 단위** — KCB 자료는 가구 합산이고 우리는 개인이다. 가구원 수 효과
  (4인 +26.41%)는 재현 대상이 아니다.
- **신청 5부제·실적확인 2일 지연** — 미구현. 전원이 발효일부터 문턱을 안다고 단순화.
- **11월 효과** — 관측창이 10월이라 11월 계수(+9.01%)는 대조하지 않는다.
