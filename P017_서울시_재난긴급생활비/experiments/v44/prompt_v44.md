# v44 사전등록 — 모델이 문턱을 쫓기는 하는가

**작성 2026-09-22 13:00 · 실행 전 커밋** · 12명 × 격자 5 × 씨앗 2 = 120 호출 · 프롬프트 v5 그대로

---

## 왜 이것을 먼저 물어야 하는가

P012 는 실측과 가장 먼 지표다. 원인 후보로 둘을 시험 중이다.

```
v30  관측 창이 짧아서 (2일 대 한 달)
v43  정책 본문이 잘려서 (280자)
```

**둘 다 "모델이 문턱을 쫓기는 한다"를 전제한다.** 그 전제를 확인한 적이 없다.

런타임은 사람마다 이렇게 계산해 준다.

```
X  2분기 월평균 앵커       Z = X × 1.03   실적 문턱
Y  적립업종 이번달 누적     W = max(0, Z − Y)   문턱까지 남은 거리
```

W 가 작으면 조금만 더 쓰면 자격이 생기고, 크면 이번 달엔 글렀다. **W 를 움직여도
계획이 그대로라면, 창을 늘리든 문장을 돌려주든 P012 의 크기는 안 움직인다.**

## 설계 — 숫자 하나만 바꾼다

동결된 파일럿 맥락(`validation_v3/pilot_registered/frozen_inputs.json`)의 캐시백 on
셀 12개를 쓴다. 각 셀에서 **Y 하나만 옮겨** W 격자를 만든다.

```
격자 (문턱 대비)   0.02 · 0.10 · 0.30 · 0.60 · 1.00
                  거의 다 왔다 ────────────────── 한 푼도 안 썼다

고정   문턱 Z · 앵커 X · 남은 일수 · 페르소나 · 날짜 · 그 밖 모든 글자
함께   페이스(W ÷ 남은 일수)를 바뀐 W 로 다시 계산한다
```

**페이스를 안 고치면 앞뒤가 어긋난 맥락이 되고, 그러면 W 가 아니라 그 불일치를
재게 된다.** 60칸 전부에서 `누적 + 남은 거리 = 문턱` 을 확인했다(모순 0칸).

> 처음엔 절대 금액 격자(1만~90만원)로 만들었다가 W=90만에서 **누적 0 · 남음 90만 ·
> 문턱 52.9만** 이라는 모순을 냈다. 사람마다 문턱이 다르므로 비율이어야 한다.

## 합격선 — 결과를 보기 전에 정한다

```
반응한다   W 가 커질수록 두 지표가 줄어들고(단조), 양 끝의 차이가 0 이 아니다
반응 안 한다  양 끝의 차이가 0 이거나 부호가 오락가락한다
```

**사전등록한 예측.** 반응은 있으나 **약할 것이다.** 근거: `P010 역진의 벽` 에서
같은 계열 모델이 서술에는 안 움직이고 계산된 사실에만 움직였고, W 는 계산된
사실이다. 다만 `_format_cashback_status` 주석이 남긴 3차 실측 기록 — 한도 환산을
넣었더니 오히려 후퇴했다 — 은 이 모델이 큰 숫자를 "불가능하네"로 읽는다는 뜻이고,
그러면 W 가 클 때 오히려 포기 쪽으로 갈 수 있다. **비단조도 가능하다고 미리 적는다.**

## 결과가 무엇을 바꾸는가

| 결과 | 그다음 |
|---|---|
| 뚜렷이 반응 | 전제가 성립한다. v30·v43 의 결과를 액면대로 읽는다 |
| 거의 반응 없음 | **P012 의 크기는 프롬프트로 못 맞춘다.** 창도 절단도 원인이 아니고, 엔진이 문턱을 예산에 반영해야 한다 |
| 비단조 | 큰 W 를 포기 신호로 읽는다는 뜻. 고칠 것은 W 의 제시 방식이지 문장이 아니다 |

## 유도가 아닌 이유

| 물음 | 답 |
|---|---|
| 새 문장을 더하는가 | **아니다. 바뀌는 것은 숫자뿐이다.** 단위테스트가 '더 쓰라·서둘러·기회' 같은 말이 안 들어갔는지 검사한다 |
| 순환 검증인가 | 아니다. W 는 이미 모델의 입력이다. 여기서는 **그 입력을 모델이 쓰는지**를 잰다 |
| 정답지를 보는가 | 아니다. 실측 +20.82% 는 이 라운드의 어떤 판정에도 안 들어간다 |

> 아키텍처 문서가 요구한 "엔진 파라미터 민감도 실험"이 이것이다.

## 이 라운드가 답하지 못하는 것

Stage1 파일럿이므로 **POI 선택·결제·기억 전이가 없다.** 계획의 반응을 보는 것이지
지출의 반응을 보는 것이 아니다. `daily_propensity` 는 실제 지출이 아니다 —
`VALIDATION_V3_RESULTS.md` 가 그것을 정책 효과로 읽지 말라고 적었고, 여기서도
읽지 않는다. **읽는 것은 "W 에 반응하는가" 한 가지뿐이다.**
