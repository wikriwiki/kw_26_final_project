사전등록한 합격선(v46 ≥ v45)은 넘었다. **그러나 짝지어 재면 구별되지 않는다.**

## 예측이 틀렸다

> 등록한 예측: **5~8%p 오른다.** 안 오르면 두 모순이 원인이 아니었던 것이다.

**+2.1%p 였다.** 예측 구간 밖이고, 짝지은 검정으로는 0 과 구별되지 않는다.
두 자기모순(체류 대 간격, 되감기는 예시)을 고친 것이 시간 위반을 눈에 띄게
줄이지 못했다. 그대로 적는다.

## 이 라운드의 진짜 소득 — 잡음의 크기를 쟀다

v45 를 **같은 시민·날짜·seed 로 두 번** 돌린 셈이 됐다.

```
v41 런의 v45   171/192  (89.1%)
v46 런의 v45   165/192  (85.9%)

같은 칸 192개 중 판정이 뒤집힌 칸   38개 (19.8%)
  통과 → 실패  22
  실패 → 통과  16
```

**같은 프롬프트가 한 번에 38칸을 뒤집는다.** 순증으로는 −6칸이다.

원인은 결정성이다. seed 를 고정해도 배치 구성이 런마다 달라 샘플러의 실제 흐름이
달라진다. 아키텍처 문서가 미리 적어 둔 그대로다 —
*"seed 지원도 비트 단위 결정성을 보장한다고 주장하지 않는다."*

## 그래서 v41 사다리를 다시 읽었다

```
v5 → v40    개선 38 · 악화 28 · 순증 +10   p=0.268    유의하지 않다
v40 → v42   개선 43 · 악화 19 · 순증 +24   p=0.0032   유의
v42 → v45   개선 23 · 악화 17 · 순증  +6   p=0.430    유의하지 않다
v5 → v45    개선 52 · 악화 12 · 순증 +40   p<0.0001   유의

v45 → v46   개선 23 · 악화 19 · 순증  +4   p=0.644    유의하지 않다
v45 ↔ v45   개선 16 · 악화 22 · 순증  −6              (잡음)
```

**확실한 것은 둘뿐이다.**

```
형식 고침(v40 → v42)   +24칸   p=0.0032
누적(v5 → v45)         +40칸   p<0.0001
```

나머지 — 캐시백 오염 제거(+10), 지갑형 어휘(+6), 시간 규칙과 예시 정렬(+4) —
은 전부 잡음 폭 안이다. **하나씩 떼어 공을 돌릴 수 없다.**

## 무엇을 배웠는가

**① 이 파일럿은 n=192 에서 ±10칸을 못 가른다.** 앞으로 이만한 차이를 주장하려면
표본이나 복제를 늘려야 한다. 한 런의 %p 차이를 그대로 읽으면 안 된다.

**② 내가 그것을 모르고 읽었다.** v41 결과에 "세 단계가 전부 올랐다"고 적었고,
그중 둘은 잡음이었다. 정정했다.

**③ 합쳐 놓은 것은 확실히 낫다.** v5 → v45 가 +40칸에 p < 0.0001 이다.
**프롬프트는 분명히 좋아졌고, 좋아진 이유를 셋으로 나눈 것이 섣불렀다.**
