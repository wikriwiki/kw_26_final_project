# 사전등록 수정 1 — 질문의 범위를 넓힌다 (본런 **전**)

**2026-09-24 04:45** · 본런은 아직 안 돌았다. 교정 탐침(단계 가)만 끝났다.
원본: `prereg.md`

---

## 무엇이 바뀌나

```
전   v5online    "배송으로 받는 몫"
후   v5offsite   "동네의 작은 가게가 아닌 곳에서 나가는 몫"
```

회계·눈금·관문·판정 기준은 **그대로**다. 바뀌는 것은 묻는 범위 하나다.

## 왜 — 교정 탐침이 범위 불일치를 드러냈다

단계 가는 응답률만 보려던 것인데, 그 값이 설계 결함을 짚었다.

```
응답률      100.0% (80/80 파싱)        ← 관문 (a) 통과
online_share 평균 0.1400 · 중앙 0.1500 · sd 0.0831 · 고유값 6
예시값 0.25  응답에 **한 건도 없다**    ← daily_propensity 의 쏠림과 대조적
```

**그런데 회계가 걷어내는 몫은 0.7465 다.** 0.14 와 0.7465 는 같은 양이 아니다.

`ELIGIBLE_SHARE_SEOUL = 0.2535` 는 서울시 상권분석의 '생활밀착 63업종' 매출
비율이고 그 목록에 **백화점·대형마트·할인점·면세점이 없다**. 그러니 여집합
0.7465 는 배송만이 아니라 **동네 가게가 아닌 모든 곳**이다. 코드 주석도 처음부터
그렇게 적혀 있었다 — "하루 지출이 전부 동네 가게 계산대에서 나가지는 않는다".
블록을 "배송" 으로 좁게 쓴 것은 내 잘못이다.

## 좁은 답으로는 천장이 간격보다 낮다 — 그래서 돌리면 안 된다

회계는 `share_i = share0 x (1 - online_i) / KEEP_MEAN` 이므로 배수의 최댓값이
`1 / KEEP_MEAN` 이다. 탐침값 KEEP_MEAN = 0.86 으로 계산하면:

```
모두가 배송 0 으로 가도     오프라인 **+16.3%** 가 한계
평균 0.10 만큼 내려가면     +10.8%
평균 0.05 만큼 내려가면     +5.4%

메워야 할 간격              18.92%p   (P012-1 실측 +20.82 대 현행 +1.90)
P012-1 의 런 간 이동        8.2%p     (이보다 작으면 읽을 수 없다)
```

**천장(+16.3%)이 간격(18.92%p)보다 작다.** 그리고 현실적인 이동폭(+5~11%)은
런 간 이동 8.2%p 와 겹친다 — 즉 **돌려도 읽히지 않을 공산이 크다.**
12시간을 쓰기 전에 알아낸 것이 이 탐침의 값어치다.

## 넓힌 판의 천장 — 이 값은 v2 교정에서 확정한다

범위를 회계와 맞추면 기준값이 0.42 근처여야 한다(서울시 자료로 잡은 참 앵커
52,462원 대비 사용처 30,255원 → 사용처 몫 0.577, 여집합 0.423). 그렇다면
`KEEP_MEAN ~ 0.58`, 천장 `1/0.58 ~ 1.72` → **+72%** 의 여유가 생긴다.

**다만 이것은 아직 추정이다.** v5offsite 로 96호출을 다시 돌려 실제 KEEP_MEAN 을
재고, 그 값으로 천장을 다시 계산한 뒤에 본런 여부를 정한다.

```
새 중단 조건   넓힌 판의 천장이 여전히 18.92%p 보다 작으면 본런을 돌리지 않는다.
               그때는 "2층을 다 열어도 P012-1 을 못 메운다"가 결론이고,
               남는 것은 1층(총액)인데 그쪽은 수준이 +40.7% 틀어진다 —
               즉 **이 모델의 구조적 한계**로 보고한다
```

## 예측은 그대로 둔다

P012-1 은 커진다 · P012-2 는 부호가 안 고쳐진다 · **총 오차가 줄어야 성공**.
범위를 넓혔다고 예측을 느슨하게 하지 않는다.

## v5online 을 지우지 않는 이유

좁은 판의 교정값(0.14)이 **왜 범위를 넓혔는지의 증거**다. 지우면 "처음부터
넓게 물었다" 처럼 보이는데, 사실은 한 번 틀리고 탐침에 걸린 것이다.
