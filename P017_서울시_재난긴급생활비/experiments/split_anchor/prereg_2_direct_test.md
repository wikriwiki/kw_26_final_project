# 사전등록 2 — **필드가 정책에 반응하는가**를 직접 본다 (사후 등록임을 밝힌다)

앞선 등록: `prereg.md` · `amend_01_scope.md` · 판정 `calib_02.md`

---

## 먼저: 앞의 중단은 유효하다. 되돌리지 않는다

`amend_01_scope.md` 의 조건이 걸렸고 그대로 멈췄다. **그 판정을 고쳐 쓰지
않는다.** 이 문서는 **다른 질문을 묻는 새 실험**이고, 결과를 본 뒤에 쓰는
것이므로 **사후 등록**임을 앞에 적는다. 증거의 무게가 다르다.

## 앞의 조건이 무엇을 잘못 봤나

```
등록했던 조건   천장(+17.0%) < 간격(18.92%p)  →  중단
```

이 조건은 **"간격을 다 메울 수 있는가"** 를 물었다. 그런데 실험을 돌릴 가치는
**"읽히는가"** 에 달렸고, 읽히는 기준은 런 간 이동이다.

```
천장          +17.0%
런 간 이동     8.2%p      ← 읽히는 기준
간격          18.92%p     ← 다 메우는 기준
```

**+17.0% 는 잡음의 두 배가 넘는다.** 즉 다 메우지는 못해도 **읽히는 크기는
충분히 낼 수 있다.** 조건을 잘못 세웠다. 이것은 결과가 마음에 안 들어 기준을
무르는 것이 아니라, 기준이 측정한 적 없는 것을 물었다는 뜻이다.

## 그러나 calib_02 의 반증도 그대로 유효하다

범위를 3배 넓혀도 답이 안 바뀌었고(0.1448 → 0.1427, p=0.711) 27%는 집합
논리에 어긋났다. **문구에 반응하지 않는다**는 것은 확실하다.

확실하지 **않은** 것은 이것이다 — **정책 맥락에도 반응하지 않는가.**
문구는 지시문 안의 낱말이고 정책은 맥락 안의 사실이다. 둘은 다르다.
P010 에서 본 것도 "서술은 무효, **계산된 사실에는 반응**" 이었다.

**이것은 탐침으로 못 본다.** 정책이 켜진 맥락은 그래프에서만 만들어진다.

## 그래서 이 실험의 1차 질문을 바꾼다

```
1차 질문   online_share 가 **정책 시작 전 날짜와 후 날짜 사이에 달라지는가**
           같은 에이전트 안에서 쌍을 맞춘다 (런 하나 안에 두 창이 다 있다)
2차 질문   P012-1 이 현행 +1.90% 에서 얼마나 움직이는가
```

**1차가 이 런의 존재 이유다.** 2차가 안 좋아도 1차는 답이 남는다 —
"모델이 정책 맥락에 반응하는 스칼라를 내는가" 는 이 프로젝트 전체에 걸린
질문이고, 지금까지 한 번도 직접 잰 적이 없다.

## 판정

```
1차   쌍별 부호검정(양측). 정책 후 online_share 가 내려간 사람이 유의하게 많은가.
      **방향을 미리 안 고정한다** — 정책이 배송을 늘릴 수도 있다(외출 기피).
      동점 수를 함께 적는다.
      움직이면    2층 레버가 살아 있다. 회계 분리가 값을 갖는다
      안 움직이면 **스칼라 경로는 죽었다** 가 확정된다. 더 이상 안 건드린다
2차   |시뮬 − 실측| 이 P012-1 에서 줄어야 한다. 움직임이 8.2%p 를 못 넘으면
      "읽을 수 없다" 고 적고 판정을 보류한다
관문   나-1 배선(전부 split_behavioral) · 나-2 수준(±1%) — 깨지면 본런 안 돌린다
```

## 무엇이 이 실험을 죽이나

```
· 관문이 깨지면 → 안 돌린다
· 1차에서 동점이 압도적이면(예: 80% 이상) → 필드가 상수라는 뜻. 2차를 읽지 않는다
· 2차만 좋아지고 1차가 안 움직이면 → 개선이 레버가 아닌 다른 데서 왔다는 뜻이므로
  **2층 가르기의 공으로 적지 않는다.** 무엇 때문인지 따로 찾는다
```

## 비용과 대안

```
이 런        관문 0.5h + 본런 7.5h = 8h
안 돌리면    같은 GPU 로 P016(농할) 또는 사적모임 — 지표가 통째로 비어 있는 정책
```

P012-1 은 잰 지표 오차 29.52%p 중 **18.92%p(64%)** 다. 그리고 1차 질문은
이 프로젝트에서 가장 오래 미뤄 둔 질문이다. 그래서 이쪽을 고른다.

## 고백

**이 등록은 결과를 보고 쓴 것이다.** 앞의 조건이 걸린 뒤에 "그 조건이 물어야
할 것을 안 물었다" 고 판단해 새로 세웠다. 그러므로 여기서 나오는 2차 결과는
**앞선 등록만큼의 무게를 갖지 않는다.** 1차 결과는 한 번도 잰 적 없는
질문이므로 그 자체로 읽는다.
