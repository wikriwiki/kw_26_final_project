설계: 2,000명(정책 시점 서울 주민등록 분포) · 정책 전 1주 공통 → 같은 사람을 정책 있음/없음으로 1주씩.
엔진: doinggyu + 우리 엔진 병합판(`docs/KW26_MERGE_20261005.md`). 프롬프트 v53.

## 모든 정책에 걸린 것 — 고쳤다

1. **두 갈래로 나눌 때 실행 ID**: 엔진은 전날 상태·기억이 다른 실행 ID 에서 오면 멈춘다(`run_simulation` "previous State belongs to a different experience run", `experience` "cannot mix runs"). 실행기는 정책 전 주와 두 갈래에 같은 실행 ID 를 쓴다. 두 갈래는 다른 그래프·다른 출력 폴더다.
2. **원장의 월 누적 시작값**: 내보내기가 첫 날 전 지출을 0 으로 가정해, 정책 전 주가 같은 달이면 멈췄다. 전날 State 에서 연다.
3. **사용처·할인 판정 업종**: 계획한 업종이 아니라 고른 가게 자신의 업종으로 판정한다(P010·P013·P016).
4. **계획 통로가 켜졌는지**: 행마다 기준선·배수를 기록하고, 실행기가 두 갈래에서 90% 이상 쓰였는지 확인한다(아니면 멈춘다).
5. **기준선 빈 칸**: 정책 전 주말에 계획이 없던 사람은 주말마다 옛 공식으로 돌았다. 사람 하나의 값을 함께 쓴다.

## 정책별

### P012 상생소비지원금
- 정책 전 주(9월) 지출은 10월 누적에 섞이지 않는다 — 엔진이 매달 1일 월 누적을 0 으로 돌린다.
- 발표일(2021-09-27)~시행 전 선반영은 두 갈래 모두 없다(정책을 갈라진 뒤에 넣는다).

### P013 긴급재난지원금
- 받는 날 = 실제 신청·충전 일정(05-12~06-03), 받은 날부터 정책이 보인다. 카드 충전형이라 사용처 결제에서 자동 차감.
- 지원금 카드로 낸 몫 0.5617(전국 5/24 누적 소진율에 맞춘 보정값) — U1 2주차는 독립 검증에서 뺀다.
- 1주 창(05-11~05-17)에 받는 사람 약 52%. 계약서의 2주·4주 지표는 이 창으로 못 잰다.

### P010 민생회복 소비쿠폰
- 결제 규칙을 자동 차감으로 바꿨다(신용·체크카드 충전분이 수령자의 69.2%, 집행결과 p2; 사용처 결제 시 자동 차감, 정책원문 p3). 예전 기본값(건별 선택)은 P013 에서 사용 0.1% 였다. 개인 단위 쿠폰이라 P013 의 가구 보정(0.5617)은 쓰지 않는다.
- 하루 인출 상한 없음(`EXP_SPREAD_DAYS=1`). 이 값이 없으면 자동 차감 모드에서 잔액의 25%/일 상한이 걸리는데, 그 상수는 한국은행 수치에서 왔다(쓰면 안 되는 값).
- **바꾸지 않은 것(정책 파일)**: 금액을 소비분위로 정한다(1분위 40만·2분위 30만). 실제는 수급 자격이고, 그래서 평균이 실제보다 높다(2,000명 기준 재계산 필요). 지급 일정(첫 주 출생연도 끝자리 요일제, 신청 다음 날 충전)도 없다. 둘 다 정책 파일을 고쳐야 해서 사용자 결정이 필요하다.
- 기존 채점기(`paired_coupon_effect.py`)는 옛 설계(7/12~23 한 달력)에 묶여 있다 — 새 설계는 `score_ab3w.py`.

### P016 농축산물 할인쿠폰
- 할인 계산은 맞다(20%, 1인 누적 1만원, 매장 매출은 할인 전 금액).
- 실제 쿠폰 사용은 대형마트 58.7%·온라인몰 21.8%, 전통시장·중소마트 0.03%였다. 그래프에는 대형마트 업종이 없고, 온라인은 정책이 닿지 않는 고정 몫이다. 시뮬의 할인은 동네 청과·정육·슈퍼·식료품 가게에서만 일어난다 → C1(대형 유통 5사 신선식품 매출)은 간접 대리 지표, C2·C3 는 셀 수 없다.
- 원칙 문장 "그 업종의 일을 앞당길지, 평소대로 할지는 본인이 정한다"는 늘리거나 그대로인 쪽만 준다(줄이는 선택이 없다). 지원금·캐시백에서 뺀 문장과 같은 종류라 뺐다. 사실 문장 "혜택은 정해진 업종에서 정해진 조건을 채웠을 때 적용된다"만 남는다.
- 표시 "[농할]"은 실제 캠페인 이름이라 익명 설정에서도 정책을 알아볼 수 있다(정책 파일 값).

### 거리두기 2단계 (2020-11-24)
- 날짜는 맞다(11-19~23 1.5단계, 11-24~12-07 2단계). `covid_2021` 환경은 날짜로 규칙을 고르므로 2020년 11월 규칙이 들어간다.
- 고친 것(2026-10-06):
  - 정책 없음 쪽 = 11-23 의 1.5단계를 이어 가는 환경 `covid_2020_hold_1123`(확진 소식은 그날 것). '비교 조건' 문구가 없다. 단계표에 1.5단계 세부 규칙이 없어 단계 이름만 보인다 — 없는 규칙을 지어 넣지 않았다.
  - 카페가 종일 포장·배달만인 날 '식당·카페 매장 취식 21:00까지'라고 적던 줄을 '식당 매장 취식 21:00까지'로 고쳤다.
  - 원장·채점: 대조 갈래 이름 `control_hold`, 첫 날 월 누적을 전날 값에서 연다, 두 갈래 실행 ID 가 같아도 된다(실행 지문이 다르면).
- 고치지 않은 것(처음 검수 목록):
  1. 정책 없음 쪽 = '거리두기 전혀 없음'(`covid_no_distancing`)이라 11-24 에 오히려 완화 충격을 받는다. 정답지(서울연구원)는 2단계 이상 vs 그 아래 단계라, 11-23 의 1.5단계를 이어 가는 쪽이 맞는 대조다.
  2. 정책 없음 쪽 머리말에 "비교 조건"이라고 적혀 모델이 실험 중임을 안다.
  3. 규칙은 Stage1 프롬프트에만 있고 Stage2(가게 고르기)는 모른다. 문 닫은 업종(유흥 5종)·21시 이후 매장 취식이 후보에서 걸러지지 않는다. 위반도 기록되지 않는다.
  4. 카페 규칙을 한 줄에서 "매장 취식 21:00까지"로 잘못 적는다(실제 카페는 종일 포장·배달만). 100명 이상 행사 금지가 빠졌다.
  5. 규칙 자료 파일(단계표 json)이 실행 지문에 들어가지 않는다.
- 공통 프롬프트(v53 이 물려받은 p012)의 "외출을 너무 보수적으로 줄이면 부자연스럽다"는 두 갈래 모두에 들어가지만 제한 효과를 줄이는 쪽으로 민다.

### P014 지역사랑상품권 — 2026-10-06 고쳐서 돌린다
규칙(원문 대조, 정책 사본 `data/experiments/P014_ab3w_policy_20261006.json`):
- 할인율: 서울시 2020-07-08 "기본할인율은 7%". 같은 글의 자치구별 발행표에서 2020-09-21 이전 마지막 발행이 10% 인 구 = 관악·강북·도봉·노원·은평·서대문·강남·중랑(9/1). 본문은 "7개 구 10%"(동작 포함, 강북·중랑 없음)라 표와 다르다 — 표를 따랐다.
- 할인 구매한도: 월 70만원(8/1~), 구별(서울시 2019-12-19 "1인당 자치구별"). 보유한도 200만원은 1주 창에서 모형화하지 않는다.
- 사용 범위: 발행 구 안에서만, 구매는 누구나 어느 구든(서울시 2019-12-19) → 사는 구·직장 구 상품권 모두 쓸 수 있게 했다.
- 회계: 상품권 결제 = 결제 즉시 할인(그 구 할인율), 그 구 그 달 상한 = 70만원 x 할인율. 매장 매출은 할인 전 금액.
- "새로 생기는 돈이 아니다"를 정책 설명·상태·원칙에서 모두 뺐다(줄이는 쪽 방향 문장).
- 가정: 모든 사람이 상품권을 쓰는 세상 vs 없는 세상. 실제 서울 사용액은 2020년 1~8월 2,479억원(이데일리 2020-10-15) — 1인 1일 100원 안팎이라, 결과는 '모두가 쓸 때'의 반응이다.

실측 지표(조세재정연구원 2020, 송경호·이환웅 — 서울은 분석 대상이 아니다, 부록 PDF 98쪽):
| 지표 | 원문 | 시뮬(정책 있음 - 없음, `score_ab3w.py`) |
|---|---|---|
| P014-K1 총매출 | 삼중차분 -0.019(0.024), 유의하지 않음 — 표 VI-4 (4)열, PDF 75쪽 | `offline_spent` 95% 구간이 0 을 포함하는가 |
| P014-K2 슈퍼마켓(47121) | +0.153** — 표 VI-6 (1)열, PDF 79쪽 | `--subs 슈퍼마켓` 증가 |
| P014-K3 음식료품 위주 종합소매(47129) | +0.110*** — 같은 표 | `--subs 종합소매` 증가 (대응 불확실: 우리 '종합소매'는 '그 외 기타 종합 소매업') |
| P014-K4 음식료품·담배 소매(472) | +0.165, 유의하지 않음 | `--subs 식품전문=식료품+정육+청과+수산+음료소매` |
| P014-K5 음식점(561) | -0.033, 유의하지 않음 | `by_l1` 식사 |
원문 해석은 "대형마트에서 동네 슈퍼마켓으로의 매출 이전"(PDF 81~82쪽)인데 그래프에 대형마트가 없어 빠져나간 쪽은 잴 수 없다. 크기는 '발행액 1%당 탄력성'이라 견줄 수 없고 방향·유의만 맞댄다.

옛 기록(2026-10-05 검수 시점):
- 10% 할인이 결제에 적용되지 않는다(즉시 할인 회계가 `price_discount` 를 받지 않는다). 두 갈래 모두 정가를 낸다.
- "새로 생기는 돈이 아니다"가 하루에 여섯 번 나온다(정책 설명·상태·원칙) — 줄이는 쪽 방향 문장이고 정답지(조세재정연구원)의 소득 효과 설명과도 반대다. 설명은 정책 파일 값이라 고치려면 사용자 승인 필요.
- 정답지는 2011~2018 시군구 x 업종 연간 매출(서울은 처치 지역이 아니다). 서울 주민 1주로는 같은 양을 잴 수 없다.

### P015 8대 소비쿠폰 — 2026-10-06 돌릴 수 있게 했다(맞댈 실측 효과는 없다)
규칙(정책 사본 `data/experiments/P015_ab3w_policy_20261006.json`, 업종별 시작일을 엔진이 날짜별로 켠다):
- 외식(10/30~11/22): 금 16시~일 24시 2만원 이상 3회 결제 → 4번째 외식에서 1만원 환급, 카드사별 1일 2회, 같은 업소 1일 1회, 구내식당 제외(농식품부 정책브리핑 2020-10-28; 중단 이데일리 2020-11-23).
- 숙박(11/4~11/22): 7만원 이하 3만원, 초과 4만원 할인(정책브리핑 2020-11-09; 11/23 발급 중단 서울신문).
- 체육(11/2~11/30): 기간 중 8만원 이상 쓰면 3만원 환급, 응모·당첨(이데일리 2020-10-18).
- 넣지 않은 것: 여행(온라인 투어비스 상품만), 공연·영화·전시(그래프에 가게 없음), 농수산물(이 기간 1만원 상한 쿠폰이 이어졌는지 출처 없음 — P016 이 따로 다룬다). "선착순 소진" 문구는 모형화하지 않아 뺐다.
- 가정: 모두 응모·당첨된 세상 vs 쿠폰 없는 세상. 실제 외식 응모 324만 명(전국).
- 실측: 이 창(10/30~11/5)의 소비 효과를 잰 자료를 찾지 못했다. 참여 실적(전국)만 있다 — 외식 324만 명 응모·347만 건 결제·목표 달성 29만 건·29억원 환급(농식품부 2020-12-28), 체육 32만 명 환급(MK스포츠 2021-06-16), 숙박 56만 건 발급(서울신문 2020-11-23). 그래서 시뮬 결과(업종별 변화·환급액·외식 목표 달성 비율)는 보고하되 실측과의 일치 판정은 내지 않는다.
