# 서울사랑상품권

**정책** · `P014` · 기전 `price_discount` · 2020-09-21 ~ 2020-10-11

지역사랑상품권 할인 발행. 자치구 안에서만 쓸 수 있다.

---

## 정책이 무엇을 하는가

자치구가 발행하는 지역 상품권을 액면가보다 10% 싸게 살 수 있습니다. 45만원을 내면 50만원어치를 받는 식이며 1인당 월 구매한도가 있습니다. 새로 생기는 돈이 아니라 본인 돈으로 미리 싸게 사 두는 것입니다. 사는 곳 자치구 안의 동네 가맹점에서만 쓸 수 있고 대형마트·백화점·온라인몰에서는 쓸 수 없습니다.

## 정답지

출처 — 조세재정연구원 「지역화폐 도입이 지역경제에 미친 영향」(송경호·이환웅, 2020)

| 지표 | 기대 | 무엇을 재는가 |
|---|---|---|
| `LV-1` | 0 | 소비지출 규모 무반응 (실측 영향 미미) — 방어선 지표 |
| `LV-2` | + | 거주 행정동 소비 비중 증가 — 구매처가 동네상권으로 이동 |
| `LV-3` | - | 타 자치구 소비 비중 감소 — 역외 소비 단기 차단 |
