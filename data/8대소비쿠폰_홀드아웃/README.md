# 8대 소비쿠폰

**홀드아웃 (봉인)** · `P015` · 기전 `sector_voucher` · 2020-10-30 ~ 2020-11-22

홀드아웃. 채점을 한 번만 했고 다시 부르지 않는다. 지표는 돌리기 전에 정책 설계만 보고 적었다.

---

## 정책이 무엇을 하는가

정부가 코로나19로 피해가 큰 분야의 소비를 살리기 위해 할인·환급 쿠폰을 나눠 줍니다. 외식은 주말(금요일 오후 4시~일요일 밤 12시)에 2만원 이상 세 번 결제하면 네 번째 외식에서 1만원을 돌려받습니다. 여행상품은 30%, 농수산물은 20%(최대 1만원) 할인되고, 숙박은 온라인 예약 시 3만원, 체육시설은 이용료 3만원을 돌려받습니다. 수량이 정해져 있어 선착순으로 소진되면 받을 수 없습니다.

## 정답지

출처 — 봉인 — 채점 1회에만 개봉. 지표는 **돌리기 전에** 정책 설계만 보고 적었다.

| 지표 | 기대 | 무엇을 재는가 |
|---|---|---|
| `HO-1` | + | 농수산물(마트) 지출 몫 증가 — 20% 할인(최대 1만원) 대상 |
| `HO-2` | + | 관광·숙박·체육 몫 증가 — 여행 30%·숙박 3만원·체육 3만원. 세 업종을 묶은 것은 각각의 관측 수가 적어서다(POI 는 각 4천~6천개로 충분하다) |
| `HO-3` | + | 쿠폰 대상 업종 전체가 총지출에서 차지하는 몫 증가 — 기전의 핵심 예측 |
| `HO-4` | + | 마트 지출 금액 증가 — 금액 수준. 하루 총액이 앵커에 묶여 있어 몫보다 보수적으로 움직인다 |
| `HO-5` | 0 | 거주 행정동 소비 비중 무변 — 서울 전역 정책이라 동네로 몰릴 유인이 없다. 지역화폐(P014)와 가르는 지점이다 — 그쪽은 가맹점이 거주 자치구로 제한된다 |
| `HO-6` | 0 | 총소비 무반응 — 새 돈을 주는 지갑이 아니라 할인·환급이다. 지갑(긴급재난지원금 +12.6%)과 가르는지 보는 방어선 |
