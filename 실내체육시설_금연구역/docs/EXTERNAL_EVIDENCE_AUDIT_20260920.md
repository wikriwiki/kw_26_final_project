# 외부 실측값의 비교 가능성

이 문서는 **평가 전용**이다. 시민 프롬프트·정책 사실·소비 생성기로 전달하지 않는다.
기존 기록을 삭제하거나 결과가 좋아 보이는 다른 정답으로 교체하지 않는다.

## 상생소비지원금

[KDI 원문](https://www.kdi.re.kr/research/reportView?pub_no=17750)의 표 4-7을
PDF 59~61쪽(인쇄 49~51쪽)에서 렌더링하여 확인했다.

- 분석 단위는 가구이며 월별 카드소비를 사용한 삼중차분 회귀다. 모형의 종속변수는 로그 카드소비다.
- 적립업종 10월 계수는 0.2082, 표준오차 0.0188, 관측치 710,472이다.
  단순한 전체 시민 on/off 평균소비 증감률과 동일한 추정량으로 취급하지 않는다.
- 제외업종 10월 총결제 계수는 0.0285, 표준오차 0.0268, 관측치 652,762이다.
  유의성 별표가 없다는 것이 정확한 무효과의 증거는 아니다. 동등성은 별도 허용 대역이 필요하다.
- 같은 표의 11월에는 다른 계수와 유의성이 나타난다. 어떤 달을 비교하는지 반드시 고정한다.
- 원문은 수급가구/미수급가구 구분의 자기선택 문제도 설명한다. 시뮬레이션의 무작위 on/off
  개입과 곧바로 같은 처치 효과라고 부르지 않는다.

보고서의 수치 설명은 로그계수의 백분율 근사를 사용한다. 후속 분석에서는 로그계수와
수준 변화율의 변환을 명시하고, 가구·기간·비교집단을 일치시킨 경우에만 크기를 채점한다.

## 긴급재난지원금

[KDI 지급효과 분석](https://www.kdi.re.kr/share/pressView?bd_no=4018)은 전년동기 대비
카드매출 변화, 사용가능업종의 증감률 변화(%p), 다른 요인을 배제한 추정 증가분을 구별한다.
기존 EM-2의 `%p`를 시뮬레이션의 `%`로 나눠 배수 일치를 주장한 것은 유효하지 않다.
전년 대비 전체 매출 변화도 정책만 켠 on/off 차이와 다른 비교량이다.
개인에게 일괄 환산한 지원액과 실제 가구별 지원액의 차이도 비교 계약에 남겨야 한다.

## 감염병과 거리두기

[주재욱·노승철·윤종진(2021), 정책리포트 322호 원문 초록](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE10553987)은
2019~2020년 자료로 코로나19 확산에 따른 손실을 분석한다.
동일한 감염 배경에서 특정 날짜의 영업규제만 바꾸는 현재 개입은 감염병 전체 충격과 다르다.
이 자료를 특정 규제의 2일 효과에 대한 정답으로 사용하거나 크기 일치를 채점하지 않는다.

## 현재 판정과 다음 비교

현재의 네 기전 개발 사례는 미시 행동 및 제약 준수를 비교하는 데 사용할 수 있다.
위 불일치를 해소하지 않은 채 외부 크기 적중률을 계산하는 것은 중단한다.
외부 검증 전에 지역, 개인/가구, 기간, 전체/조건부 모집단, 업종, 지출 범위,
분모, 단위, 추정방법, 불확실성을 별도 계약으로 고정한다.
호환되지 않는 항목은 비교 불가로 남기고, 실패한 방향을 막는 지시문이나 수치 조정으로 해결하지 않는다.

## 참여 자격 자료의 빈칸

[2021년 정부 참여 신청 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148893643)는
만 19세 이상과 2분기 본인 명의 신용·체크카드 사용 실적을 참여 조건으로 설명한다.
현재 P012 설명에는 이 조건이 빠져 있고 시민 자료에는 정확한 나이와 해당 카드 이력이 없다.
`10대`에는 19세가 포함될 수 있으므로 해당 시민을 자동으로 부적격이라고 단정하지 않는다.
0.268로 만든 지출 기준은 실제 본인 카드 사용 이력을 관측한 값이 아니다.

따라서 v19는 공급된 입력에 따른 행동 실행 확인으로 한정한다. 후속 가상 구매 실험은
참여 자격을 충족한다고 가정했음을 입력과 결과에 표시한다. 이러한 가정을 실제 참여율이나
역사적 수급 집단의 관측으로 바꾸어 해석하지 않는다. 실제 효과 비교에는 개인 자격의
관측·미관측 상태, 가구 지원금 배분, 과거 가맹점 사용 조건을 별도 공급자 자료로 보완해야 한다.
