**최우선은 기존 데이터 보존이야.** 노원·서초·송파1,154명, 모델·기간·정책 조건과 완료 결과를 유지하고 절대 Day1부터 다시 돌리지 마. 인수인계의 과거 PID/수치를 현재로 단정하지 말고 SSH로 실제 진행과 백업을 먼저 확인해.

준비하는 동안 기존 Vast 실행은 계속 돌려. Vast가 DB·작업 원장·검증·결과 저장·백업을 맡고 Colab이 동일 모델 추론을 분담하는 구조를 우선 검토해. 앞/뒤 순서를 사용할 수 있지만 중앙에서 중복 배정·중복 저장·늦은 응답·연결 종료를 처리해야 해. Colab이 끊기면 미완료 작업을 Vast가 이어받아야 해. 최초 시도 뒤 최대5회 재시도 후 해당 agent-day/야간 pair만 skipped로 남기는 규칙과 기존 시도 횟수를 보존하고, 개별 실패 때문에 전체를 중지하지 마.

Colab GPU 확인, 같은 모델 적재·소량 성능 시험, 분산 처리와 장애 복구 검증까지 진행해줘. GPU를 기다리는 동안 가능한 로컬 구현·검증은 계속해. 로그인이나 GPU 선택처럼 내가 해야 하는 일만 구체적으로 요청해. 실제 확인하지 않은 가속 효과나 복구를 성공했다고 말하지 마.

검증과 최신 그래프+run 백업을 확보한 뒤 **다음 안전한 날짜 경계에 최대한 빨리 적용**해줘. 다음14일 프로세스까지 미루지 마. 현재 프로세스에 hot reload가 있다고 가정하지 말고 필요한 계산 프로세스 인계만 통제해서 수행해. Vast 인스턴스/기존 모델을 불필요하게 재시작하거나 결과를 초기화하지 마. 서버15초 자동 복구기와 Codex6시간 감시가 있으니 실제 교체 전 작업 소유권·잠금을 조율해 이중 실행을 막아줘. 중단을 발견하면 보고만 하고 GPU를 방치하지 말고 원인을 진단해 기존 결과에서 재개해.

활성 frozen v22와 runtime 패치는 로컬 최신 메인 코드와 다르므로 실제 로드 경로·해시부터 확인해. 과거 Day2/Day5 일회성 복구 스크립트를 다시 실행하지 말고 source/execution fingerprint나 무결성 검사를 무력화하지 마. 기존 미커밋 변경도 보존해줘.

마지막에는 실제 구현·검증·배포 범위, 두 GPU의 실측 처리량/오류율, 기존 데이터 보존, Colab 종료 시 Vast 복귀, Drive 백업, 남은 문제를 보고해. 완료/미완료와 새 경로·해시·다음 순서를 인수인계 문서 및 ACTIVE_DEPLOYMENT에 기록해줘. 계획 설명에서 끝내지 말고 가능한 구현과 검증을 이어서 수행해줘.
