**W 를 50배 움직였는데 성향이 0.019 안에서 논다.**

## 그런데 모델은 그 숫자를 읽고 있다

```
reasoning 이 '문턱' 을 언급한 응답    79 / 120  (66%)
'캐시백' 을 언급                    67 / 120
'적립'                             26
'남은'                             21
```

**읽고, 그것에 대해 쓴다.** 무시하는 것이 아니다.

## 그리고 개인별로는 움직인다 — 방향만 없다

```
시민 12명, W 격자 다섯

단조 감소        0명
단조 증가        0명
사실상 평평       1명 (범위 < 0.02)
비단조           11명

시민별 propensity 범위   중앙 0.090 · 최소 0.015 · 최대 0.165
```

**성향이 9%p 씩 움직인다. 그 움직임이 W 와 무관하다.** 집계가 평평한 것은
개인별 움직임이 서로 상쇄되기 때문이고, 반응이 없기 때문이 아니다.

```
무시한다        아니다 — 66% 가 문턱을 인용한다
반응한다        아니다 — 방향이 없다
읽고 흔들린다    이것이다
```

## 예측 대조

|---|---|

| **비단조도 가능하다**고 미리 적는다 | 12명 중 11명이 비단조. 이 갈래가 맞았다 |

## 이 결과가 두 라운드를 무효로 만든다

```
v30  관측 창을 31일로 늘려 누적을 쌓으면 캐시백 효과가 커지는가
v43  잘린 "문턱 못 넘기면 혜택 사라짐" 을 돌려주면 커지는가
```

**둘 다 "모델이 문턱을 쫓는다"를 전제한다.** 쫓지 않는다. 누적을 더 쌓아도,
잃는다고 더 분명히 말해 줘도, 문턱까지의 거리가 행동을 정하지 않는다.

사전등록에 이 갈래의 귀결을 미리 적어 두었다.

> 거의 반응 없음 → **P012 의 크기는 프롬프트로 못 맞춘다.** 창도 절단도 원인이
> 아니고, **엔진이 문턱을 예산에 반영해야 한다.**

## 그러므로

```
v30   18/31 일차에서 세운다. 정책런 채점까지도 가지 않는다 — 전제가 죽었다
v43   돌리지 않는다
다음   P012 의 크기는 프롬프트 라인의 과제가 아니다. 엔진 쪽 과제다
```

**GPU 는 v50(정답지 평가)으로 간다.** 그것이 프롬프트 라인의 목표 그 자체다.

## 이 문서가 말하지 않는 것

**"모델이 캐시백을 이해하지 못한다"가 아니다.** 66% 가 문턱을 인용하고,
`P012-1` 은 거시 런에서 +11.5%p 로 유의했다. 정책에 **반응은 한다.**

말하는 것은 하나다 — **그 반응의 크기가 문턱까지의 거리에 의존하지 않는다.**
그러므로 거리를 더 잘 보여 주는 개입(창 연장·절단 복구)으로는 크기를 못 움직인다.
