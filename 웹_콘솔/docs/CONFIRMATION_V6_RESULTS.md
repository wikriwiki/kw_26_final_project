# 새 시민 확인과 구매 정보 전달 시험

활동 v24의 선언된 실행 프로토콜은 새24명 × 알려진4기전 ×on/off ×2seed =384조건을
원문384/384, 독립 실행·사실 검사384/384로 통과했다. 요청 오류와 사후 시각 조정은0개,
평균 생성량은730.54토큰이었다. 등록한 실행 기준을 모두 통과했다.
이는 새로운 정책 홀드아웃이나 현실 소비·효과 크기의 검증 완료를 뜻하지 않는다.
18시 이후 마무리는 구조적으로 보장하는 표현 범위다. 이24명은 이제 사용한 표본이다.

## 반복 생성 변동

전체384원문을 독립 재검증하고, 개인별1개씩24개 행동열을 수동 검토했다.
반복 감사는 실행 중 추가한 보조 기술 분석이며 새로운 사후 합격선을 붙이지 않는다.
아래는 시각을 제외한 활동ID·장소역할의 정규화 편집거리(0~1)다. 지역 코드 자체는
서로 다른 행동으로 세지 않는다. 각 열은 기전당48쌍의 평균이다.

| 기전 | 같은 사람·같은 조건, 난수만 변경 | 같은 사람·같은 난수, on/off 변경 |
|---|---:|---:|
| 캐시백 | 0.383 | 0.442 |
| 지원금 | 0.417 | 0.462 |
| 지역상품권 | 0.402 | 0.457 |
| 거리두기 | 0.458 | 0.458 |

이는 소비의 방향·크기·유의성 지표가 아니다. 그럼에도 단일 경로에서의 행동 차이를
안정된 정책 반응으로 읽기 어렵다는 점을 보여 준다. 실제 소비 효과 평가에는 반복 경로의
효과 분포와 동일 시민의 공통 초기 조건이 필요하며, 동일 LLM seed만으로 같은 하루의
숨은 필요·근무 방식이 완전히 고정됐다고 볼 수 없다.

수동 표본에는 오후 늦은 출근, 학생의 미관측 학교 일정, 경비원 직업이 있으나 근무 POI는
없는 입력이 보였다. 현재 사전의 근무 활동 가용성은 근무 POI 존재와 연결되어 있다.
근무 위치가 미관측인 것을 무직이라고 읽거나, 고정 장소가 없는 직업의 활동을 누락하는
문제가 없도록 입력의 미관측 상태와 활동 사전의 표현 범위를 추가 보완해야 한다.

## 구매 정보를 먼저 제시한 개발 시험

원래12명·96조건의 market_v1도 원문/실행96/96, 시각 조정0개, 평균725.99토큰이었다.
96개 행동열과96개 최초 전송 입력을 검토했다. 원래 시민·정책·환경 정보를 보존했고,
계획 전에 전달한 품목·수량·가격·제안을 사용해96개 실제 결제 입력도 생성·검증했다.
추가 결제 LLM 호출은 하지 않았다.

구매 검토 활동은 기존의 오프라인2·온라인86개에서 새 입력의 오프라인7·온라인103개로
변했다. 많아졌다는 이유로 행동이 더 맞았다고 판정하지 않는다. 상품 정보 전달의 일관성은
확인했지만, 여전히 좁은 상품 목록·불완전한 생활 조건이 남는다. 외부 효과 목표에 맞춰
가격이나 사용 자격을 조정하지 않았다.
