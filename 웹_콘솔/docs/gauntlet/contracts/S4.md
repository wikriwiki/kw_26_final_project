# S4 실행 모니터 계약

선행 계약: `s1.0.0`, S2 API
상태: 구현 완료, Critic 통과

- 첫 화면은 `/api/runs`, `/api/runs/{id}/days`, `/api/runner/lock`만으로 일자 상태를 그린다.
- `/days/{day}`, `bottlenecks`, `failed`는 선택 일자를 열 때만 요청한다.
- SSE snapshot은 2초 이상 간격으로 서버가 제공하며, 프런트가 추가 polling loop를 만들지 않는다.
- `progress_ratio === null`, `checkpoint_failed_count === null`, `failed.total === null`은 `UnknownTag`로 표시하고 0으로 치환하지 않는다.
- `available:false` 병목은 `fallback_rank` 4개 phase를 보여주고 완전 리포트와 구분한다.
- 실행 시작은 서버 lock이 이미 있으면 버튼 상태와 무관하게 409로 거부된다. 화면은 lock 보유자·시작 시각·PID를 표시한다.
- ETA는 서버 로그의 `last_progress_line` 원문만 표시하며 클라이언트가 새 ETA를 계산하지 않는다.
