# 병합이 고침 하나를 조용히 되돌렸다 — 여드레 동안 저장소가 틀려 있었다

**2026-09-23** · 되돌아간 고침 `fc91872` (09-15) · 되돌린 병합 `c47a904` · 복구 이 커밋

---

## 무엇이 없어졌는가

`fc91872` 가 고친 것은 이것이다.

```
restricted_pids = {
    p["id"] for p in policies
    if p.get("poi_restricted") and 지갑잔액[p["id"]] > 0      ← 이 조건
}
```

`sector_voucher`·`price_discount` 는 **지갑을 만들지 않는다.** 결제하는 자리에서
값이 깎이는 방식이라 지갑 잔액이 영원히 0 이다. 그래서 이 정책들은 사용처 표시가
**한 번도 켜지지 않았다.**

에이전트가 읽는 글에는 "표시된 가게에서만" 이라고 적혀 있는데 후보 목록에는
표시가 하나도 없다. 자격 있는 가게가 **하나도 없는 셈**이고, 그러면 그 업종을
피할 이유가 된다. 위약 런에서 대상 업종이 기대와 반대로 −10.5%
(CI[−1,906, −291]) 줄었던 것이 그 자국이다.

## 어떻게 되돌아갔는가

```
fc91872  09-15  고침이 들어간다
   …
92f3815         고침을 가진 쪽
0430c83         고침이 없는 쪽 (경험 기억 층)
c47a904         두 쪽을 병합 — 이 파일에서 고침 없는 쪽이 이겼다
```

충돌 표시도, 되돌림 커밋도 없다. `git log -S'_WALLET_T'` 로는 **추가한 커밋
하나만 보이고 지운 커밋은 안 보인다** — 병합이 지운 것은 그렇게 나온다.

## 얼마나 오래, 어디까지 틀려 있었는가

```
09-15 ~ 09-23    저장소(G:)의 코드가 틀려 있었다       여드레
서버 /data/repo   작업 사본에 고침이 남아 있었다         런은 무사하다
```

**이미 채점한 런들은 서버 작업 사본으로 돌았으므로 결과가 오염되지 않았다.**
확인했다 — 서버의 `run_simulation.py` 에 `_WALLET_T` 가 그대로 있다.

그러나 **저장소에서 받아 돌리면 틀린다.** 그리고 나는 곧 채점기 고침을
저장소에서 서버로 올릴 참이었다. 그때 이 파일이 같이 갔으면 **돌고 있는 설정을
깨뜨리면서, 깨진 줄도 몰랐을 것이다.**

## 어떻게 찾았는가

P016 런너를 짜려고 배관을 따라가다 "이러면 [농할] 표시가 안 붙는데" 에서 멈췄다.
고침을 새로 쓰고 나서야 `git log -S` 로 **여드레 전에 이미 고쳐져 있었다**는 것을
알았다. 순서가 반대였으면 같은 코드를 두 번 쓰고 끝났을 것이다.

## 무엇을 바꿨는가

판정을 `run_simulation` 인라인에서 **기전 레지스트리**로 옮겼다
(`mechanisms.poi_restriction`). 이유는 두 가지다.

```
① 시험을 붙일 수 있다   인라인은 Neo4j 세션이 있어야 돌릴 수 있었다
② 병합이 또 지우면 시험이 빨간불이 된다
```

`tests/unit/sim/test_poi_restriction_wiring.py` 12개. 그중 하나는 **되돌아간
그 인라인 구현과 결과가 같은지**를 직접 맞대 본다 — 서버가 지금 그 코드로 돌고
있으므로, 옮기면서 동작이 달라지면 이미 채점한 런과 다음 런이 서로 다른 코드가 된다.

옮기면서 하나 더 고쳤다. 그래프에서 읽은 정책 행은 판정 룰이
`mech_params`(JSON 문자열) 안에 실려 온다. 파일에서 읽을 때만 되고 **DB 경로에서만
조용히 None** 이 되는 모양이라, 양쪽을 다 보게 했다.

## 배운 것

**`git log -S` 로 "언제 들어갔나" 만 보면 안 된다.** 지금 파일에 그 코드가
있는지도 봐야 한다. 병합은 커밋을 남기지 않고 코드를 지운다.

그리고 **작업 사본이 저장소보다 옳은 상태가 계속되면 안 된다.** 서버
`/data/repo` 는 09-13 기준 커밋 위에 미커밋 수정 12파일을 얹고 돌고 있다.
그 장비는 11-05 에 회수된다.

> 이 문서가 적는 것은 여기까지다. **고침이 병합에 지워져 여드레 동안 저장소가
> 틀려 있었고, 런은 서버 작업 사본 덕에 무사했으며, 되돌아간 구현과 결과가 같은지
> 맞대 보는 시험을 붙여 복구했다.**
