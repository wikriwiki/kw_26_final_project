## 왜 6행인가

지금까지의 후보는 전부 **무엇을 고를지**를 건드렸다. 6행은 **하루를 어떤 순서로
세울지**를 정하고, 아직 아무도 건드리지 않았다.

그리고 두 런이 독립적으로 같은 것을 가리킨다.

```
v25   재직자 34명 중 나간 적 있음 11명(32%)
      통근 56.6분(나감) 대 30.4분(안 나감)   차이 +26.2분   뒤섞기 p=0.0001
      비재직자 26명 중 나간 적 있음 1명(4%)

v36   재직자 34명 중 나간 적 있음 10명(29%)
      통근 54.7분(나감) 대 32.3분(안 나감)   차이 +22.4분   뒤섞기 p=0.0002
      비재직자 26명 중 나간 적 있음 0명(0%)
```

다른 특징은 갈리지 않는다 — 집 체류 11.7 대 12.3, 소비액 124k 대 113k,
이동성 분위 5.5 대 5.6. **통근만 두 배 넘게 다르다.**

> **모델은 구매를 위해 나가지 않는다. 이미 하던 이동에 구매를 붙일 뿐이다.**

6행이 그 순서를 쓴다.

```
먼저 확정된 일정과 이동 시간을 배치하고, 그 전후에 필요한 일상과 저녁 마무리를 정한다.
```

하루가 확정된 의무를 뼈대로 세워지므로, **이동을 요구하는 필요는 붙을 의무가
없으면 자리를 못 얻는다.** 통근이 없는 사람에게는 붙을 다리가 아예 없다.

## 사전등록

| | 내용 |
|---|---|
| 설계 | 60명 × 4기전 × on/off = 480칸, **seed 70001** |
| 원본 | `/data/cohort60/source_meal.json` — v18·v21 과 같은 파일 |
| 대조 | **v18 의 v25 팔**. 같은 코호트·같은 seed·같은 파이프라인 |
| 실행 | 문법 사전검사 → 계획 (주 지표는 계획에서 끝난다) |

### 주 지표 — 계획에 들어간 집 밖 구매 활동의 종류 (v21 과 같음)

```
기준선 v25   종류 3/14 · 칸당 0.033 · 집 밖 있는 칸 16/480
잡음 폭      짝지은 구간 ±0.023  →  칸 수로 ±11칸
```

**성공선: 칸당 종류가 늘고, 칸을 짝지은 95% 구간이 0을 제외한다.**
칸 수로 말하면 **27칸을 넘어야** 상수가 움직였다고 말할 수 있다.

### 부 지표 — 통근 없는 사람이 나가는가

이 라운드의 진짜 물음은 이쪽이다.

```
기준선   비재직자 26명 중 나간 적 있는 사람   v25 1명 · v36 0명
```

**비재직자에게서 늘어나는지 따로 적는다.** 전체 비율이 같아도 그 안에서
통근자 → 비통근자로 옮겨 갔다면 그것은 다른 사실이다.

### 취소 조건

| 조건 | 선 | 무엇을 막나 |
|---|---|---|
| 계약 깨짐 | 유효·적격 < 95% (v25·v36 은 480/480) | 순서를 빼면 형식이 무너질 수 있다 |
| 채우기 | 계획당 사건 수 ≥ v25 + 1.0 (v25 = 9.01) | 빗장이 아니라 항목 수를 늘린 것 |
| 의무 누락 | 직업 있는 칸에서 근무가 빠진 비율이 v25(8%)의 두 배 초과 | 순서를 빼자 근무를 빠뜨린 것 |

세 번째가 이 후보의 고유 위험이다. 6행은 의무를 **먼저** 놓으라고 말하는 줄이다.

### 이 실험이 답하지 않는 것

- **정답지 지표** — 60명으로는 아홉 지표 전부 0을 지난다
- **6행의 어느 부분인가** — 통째로 지우므로 "먼저 배치"와 "그 전후에 끼움"을
  가르지 못한다. 움직이면 그다음에 가른다

### 주 지표 — 기각

```
              칸당     집 밖 칸     차이
v25 (대조)    0.0333      16

```

**사전등록 판정: 기각.** 구간이 0을 지난다.
다만 **여태 나온 후보 중 점추정이 가장 크다**(v36 +0.0000 · v37 −0.0083 ·
v38 +0.0042 · v39 +0.0125).

### 취소 조건 — 하나도 안 걸렸다

```
계약     480/480 유효·적격
채우기   계획당 사건 수 9.01 → 8.82  (선 +1.00)
근무누락 24/296 (8%) → 24/296 (8%)   ← 이 후보의 고유 위험, 전혀 안 늘었다
```

**6행을 통째로 빼도 근무가 하나도 더 빠지지 않았다.** 의무를 먼저 놓으라는 문장이
없어도 모델은 근무를 제자리에 놓는다.

### 부 지표 — 이 라운드의 진짜 물음이 갈렸다

위에서 "전체 비율이 같아도 통근자 → 비통근자로 옮겨 갔다면 다른 사실"이라고
적었다. **옮겨 갔다.**

```
              칸       집 밖 칸        차이
비통근 26명   208       1 → 7      +0.0288  [+0.0096, +0.0529]   갈림
통근  34명   272      15 → 14      +0.0000  [-0.0368, +0.0404]   0을 지난다
```

**v39 는 비통근자만 움직이고 통근자는 건드리지 않았다.**

기전이 예측한 그대로다. 6행이 하루를 **확정된 의무의 뼈대**로 세우므로,
의무가 없는 사람에게는 이동을 걸 틀이 아예 없었다. 그 문장을 빼자
그 사람들에게만 틀이 생겼다.

전체 지표가 못 넘은 이유도 이것으로 설명된다 — 비통근자는 칸의 43%뿐이고,
합쳐서 재면 효과가 희석된다.

## 이 라운드가 남긴 것

1. **22라운드 만에 처음으로, 예측한 자리에서 구간이 0을 제외했다.**
   부분군은 결과를 보기 전에 "진짜 물음"으로 적어 둔 것이다
2. **그래도 사전등록 판정은 기각이다.** 부 지표는 성공선이 아니었고,
   그것을 사후에 주 지표로 바꾸지 않는다
3. **확증이 필요하다.** 한 라운드의 부분군 해결은 v18 의 v34 처럼 복제에
   실패할 수 있다. 검정력을 갖춘 확증 라운드를 따로 사전등록한다
4. **v23(볼일) 조건이 충족됐다.** 주 지표가 기각됐으므로 사전등록대로 돈다.
   v23 은 같은 집단(비통근자 26명 중 21명)을 시나리오로 겨냥하므로,
   프롬프트 쪽(v39)과 시나리오 쪽(v23)을 **따로** 재 두는 것이 낫다.
   섞으면 어느 쪽이 움직였는지 못 가린다
