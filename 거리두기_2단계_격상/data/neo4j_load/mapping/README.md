# mapping/ — 외부 코드 → 카테고리 매핑

## `mapping_upjong_to_sub.json` ✅ 자동 생성됨

소상공인공단 상가정보의 **소분류 코드 247개**를 우리 **소비자 관점 12대분류**로 매핑.

### 자동 매핑 전략
1. **L3 명 키워드 매칭** (시뮬 핵심) — 약국·헬스장·치킨·꽃집 등 명확 키워드 우선
2. **industry_l2 그룹 매핑** — 산업분류 중분류명을 우리 cat·sub에 일괄 매핑
3. fallback 없음 (247개 모두 매칭됨)

### 스키마

```json
{
  "<L3 코드>": {
    "cat": "<우리 L1>",          // 식사·카페·디저트·주점·편의점·마트·미용·쇼핑·여가·건강·교육·기타
    "sub": "<우리 L2>",
    "_l3_name": "...",            // 원본 L3 명 (참고)
    "_count": 1234,               // 데이터 건수 (참고)
    "_status": "name_kw" | "industry_l2",  // 매칭 방식
    "_industry_l1": "...",        // 원본 산업 L1
    "_industry_l2": "..."         // 원본 산업 L2
  },
  ...
}
```

### 통계 — `_remap_stats.json`

```json
{
  "total_l3_codes": 247,
  "matched_by_name": 47,       // L3 명 키워드 매칭
  "matched_by_industry_l2": 200, // 그룹 매핑
  "fallback": 0
}
```

### 검토 권장 — 다음 케이스

자동 매핑이 완벽하지 않을 수 있으니 필요 시 수동 수정:
- **"의약·화장품 소매"**: 일괄 "쇼핑·화장품"으로 묶음. 약국은 L3 명 키워드로 별도 분리됨 (정확)
- **"비알코올 음료"**: "카페" L1로 묶음. 디저트성 음료(스무디 등)는 L3 명 키워드 ↔ 디저트/카페 분류 가능
- **"기타" L1 sub 29개**: 시뮬 핵심 아님 (부동산·법무·광고 등). 그대로 두거나 빼도 무방

수정 시 직접 JSON 편집 후 `03_pois.py` 재실행.
