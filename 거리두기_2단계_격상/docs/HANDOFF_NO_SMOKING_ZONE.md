읽기 전용 반복 호출 검사 `/workspace/probe_determinism.py`에서 같은 시민·날짜·Stage 1 프롬프트·seed를 두 번씩 보냈다. 샘플링 온도 0.2의 응답 원문 해시는 달랐고, `POLICY_BACKTEST_DETERMINISTIC=1`로 강제한 온도 0의 응답 원문 해시는 같았다. 이 설정만으로 전체 시뮬레이션 재현성이 증명되지는 않는다. ### 온도 0 재검사, 공통 선행 기간 전환, GPU 처리량

위 온도 0 재검사는 OFF·ON 모두 실행 완료·근거 감사 통과, 30/30 `ok`와 정책 비활성이 확인됐다. 하지만 시행 전 Day 1의 방문 사건 수 일치는 **17/30명**, 잔액 16/30명, 만족도 12/30명, 모형 결제액 26/30명이다.
