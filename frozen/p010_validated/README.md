# P010 민생회복 소비쿠폰 — 검증 완료본 동결 스냅샷

**동결일** 2026-09-11 · **기준 커밋** `e38f72b` · **태그** `p010-validated`

이 디렉토리는 한국은행 이슈노트 2026-13 대조 검증을 통과한 결과를 만들어낸
**프롬프트와 로직의 사본**이다. 이후 다른 정책(일반화 실험) 작업에서
`scripts/sim/` 아래 파일이 수정되더라도, 여기 사본은 건드리지 않는다.

> **수정 금지.** P010 재현이 필요하면 이 디렉토리를 `scripts/sim/`으로 되돌린다.

---

## 1. 왜 동결하는가

Stage1 프롬프트의 **예시 이벤트 구성**이 업종 분포를 직접 좌우하고,
`consumption.py`의 **정산·MPC 측정 로직**이 지표 값을 결정한다.
새 정책에 맞춰 이 둘을 손대는 순간 P010 수치는 재현되지 않는다.
검증 결과를 논문·제안서 근거로 쓰는 이상, 그 결과를 만든 코드가 고정되어 있어야 한다.

## 2. 동결 대상

| 경로 | 역할 |
|---|---|
| `sim/stage1_intent.py` | 하루 의도 생성 프롬프트 — **예시 이벤트가 업종 분포를 결정** |
| `sim/stage2_poi.py` | 장소·금액 선택 프롬프트 — `extra_spent`(신규 유발액) 수집 블록 포함 |
| `sim/consumption.py` | 결제 확정·잔액 제약·정책지갑 분리·MPC 측정(금액 기반, 상한·안분) |
| `sim/plan_writer.py` | 결제 원장 및 기억 적재 (`why`/`pick_why`/`trigger`/`extra_spent`) |
| `sim/run_simulation.py` | 하루 사이클 오케스트레이션 |
| `sim/mobility.py` | Huff 광역상권 허브 선정 |
| `sim/night_intent_llm.py` | 야간 대화 의도 분류 |
| `sim/interview_agent.py` | 1:1 인터뷰 프롬프트 |
| `policy/P010.json` | 정책 명세 (분위별 차등 지급·사용처 제한) |
| `stats/hub_catalog.json` 외 2 | 광역상권 입력. **없으면 허브 0개로 조용히 실패** |

무결성은 `SHA256SUMS`로 확인한다.

```bash
cd frozen/p010_validated && sha256sum -c SHA256SUMS
```
