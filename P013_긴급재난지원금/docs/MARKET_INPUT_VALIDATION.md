# 상품 입력과 미시 행동 검증

현재 공통 프롬프트의 실행 검사는 통과하더라도, 상품·가격을 계획 뒤에야 보여 주고
실제 선택지는 활동당 하나인 구조에서는 사람의 수요를 충분히 검증하기 어렵다.
이를 정책 소비 증가나 특정 사용처 방문을 지시하는 문구로 해결하지 않는다.

## 정보 전달 순서 시험

`validation_market_v1_development.json`은 기존96조건에 결제 후보 개요를 미리 제공한다.
공통 v24, 사고예산512, 온도0.2, 시간 문법, 시민, seed44001은 기존 temporal_v5와 같다.
가격·수량·제안·잔액·합성 사용 자격의 정보 묶음만 추가하므로 가격 하나의 인과효과라고
부르지 않는다. 기존 사실을 제거하거나 정책 결과의 기대 방향을 넣지 않았다.

`base_quote`를 계획 미리보기와 결제가 공유한다. 이전 결제96조건이 그대로 재현됐고,
새96입력에서도 원래 문구는 보존됐다. 결제 시 미리보기와 다른 가격·조건을 주거나
미리보기를 실제 요청에서 숨기면 실패한다. 상품 종류를 늘리는 효과는 이번 실험과 분리했다.

## 보존한 실제 메뉴 게시자료

로컬 `naver_crawl/sqlite/kakao_enrich.db`를 SQLite 읽기 전용 트랜잭션으로 조회했다.
295,707개 장소 원문 중76,660개에 유효한 양의 정수 가격의 구조화 메뉴가 있었다.
메뉴명·개별 게시가격·원문 항목·수집시점·수정시점·품절·할인 및 AI 표시를 보존했다.
아파트 매매가격, 리뷰, 사진 수, 가격대 기호를 메뉴가격으로 취급하지 않는다.

| 항목 | 기록 수 |
|---|---:|
| 보존한 메뉴 게시항목 | 1,569,592 |
| 매장 메뉴 경로 | 954,699 |
| 배달 플랫폼 메뉴 경로 | 614,893 |
| 가격 누락·0 이하·모호한 가격으로 미채택 | 743,839 |
| 이름 누락으로 미채택 | 1 |
| 보존 항목 중 품절 표시 | 3,709 |
| 보존 항목 중 AI 표시 | 64,962 |

품절·AI 표시는 삭제하거나 정상 견적으로 바꾸지 않았다. 모든 보존 항목은
`purchase_ready=false`이며, 정책 참여 자격이나 배송비·최소 주문·할인 조건을 추측하지 않는다.
메뉴 제목의 시간당/6인 등 단위도 원문 그대로 남긴다. 특정 할인 금액으로 자동 바꾸지 않는다.
한 매장의 중앙값을 모든 상품의 가격으로 쓰지 않는다.

수집은2026-06-15~16이다. 항목에 과거 수정일이 있어도 그 가격이2020·2021년에 유효했다는
증거는 아니다. 현대 상권 조건에 대한 별도 가상실험에는 검토 후 쓸 수 있으나, 역사적
정책 효과와 직접 맞추기 위해 미래의 가격을 과거 관측값으로 넣어서는 안 된다.
이 자료는 전 업종 소비·실제 재고·현금흐름·인구 대표성을 모두 제공하는 데이터도 아니다.

추출물은 `output/validation_reference/menu_listings_2026/listings.jsonl`에 있으며
개별원문 해시, 원본 패널 해시, 후보 POI 매핑을 보존한다. 파일 SHA256:

`579608f83aef3c21933adc1cba665743f5bea0ff08759c6da64ba4b1d8798418`

원본 DB는 읽기 전용으로 열었으며 전후 크기7,715,360,768바이트와 수정시각이 같았다.
[전체 감사](experiment_evidence/menu_listings_2026_audit.json)에 집계와 소스 스트림 해시를 남겼다.
현재 진행 실험에 이 자료를 자동 편입하지 않았다.

## 다음 판단

새 시민 확인과 정보 가시성 시험은 등록대로 마친다. 행동에 생긴 차이는 전부 기록한다.
그 뒤 실제 선택지 확장에는 날짜·장소 매핑·메뉴 단위·결제 범위·품절·자격 상태를 갖춘
별도 고정 상품집합이 필요하다. 좋은 정책 부호가 나오는 상품이나 가격만 고르지 않는다.
범용 문구의 미시 선택 유효성과 외부 정책 효과의 방향·크기 타당성은 계속 구별해 평가한다.
