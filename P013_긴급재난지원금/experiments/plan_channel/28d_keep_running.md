"문턱 도달률이 0% 이거나 100% 면 이 창도 죽은 것이다. 갈리는 구간이 있어야 산다."

문턱 = `(wd×5 + we×2)/7 × 30 × 0.268 × 1.03`  — `dawn_context._sangsaeng_monthly_anchor`
와 `score_policy.fetch_cashback` 이 쓰는 그 식 그대로. 이틀 누적을 28일로 곧게 늘려 나눴다.

## 9일 창과 나란히

```
             문턱 근접도(중앙)   넘는 비율   갈리는 구간
9일 창              0.64            ~0%        0%      <- 죽어 있었다
28일 창             0.975          48.0%      넓다     <- 산다
```

**중앙이 0.975다.** 절반이 조금 못 미치고 절반이 넘는다 — 정책이 움직일 수 있는
자리에 사람들이 서 있다는 뜻이다. 9일 창에서는 91%가 닿을 수조차 없었다.

그러므로 **P012-3(문턱 도달)·P012-4(캐시백)·P012-6(한도)** 이 이 런에서 처음으로
값을 갖는다. 지금까지 이 셋은 '못 잰 지표' 였고, 그건 우리 문제였다.

## 그래서 멈추지 않는다

앞선 메모에서 "3일차에 멈추고 회계 고침을 켜 다시 건다" 고 적었다. **철회한다.**

```
멈춘다  -> 3일 + 28일 = 16.5시간, 그리고 고침 켠 값 하나
둔다    -> 19시간, 고침 끈 28일 원장 하나 + 평일 기준선 7일치
```

고침(`EXP_PLAN_DRIVES_TOTAL`)은 `personal_total` 을 바꾸는 **산술**이다. 적립업종
몫이 상수(아래)이므로 `sangsaeng_new = sangsaeng_old × personal_new/personal_old`
로 원장 위에서 곧장 다시 셀 수 있다 — P012 +2.37→+5.41%, P013 +0.32→+9.03% 을
그렇게 냈다. **GPU 를 한 시간도 더 쓰지 않는다.**

되레 두는 쪽이 낫다. 기준선을 쓸 **평일**이 생긴다:

```
10-04~10-08 (월~금) · 10-11~10-12 (월·화)   = 정책 전(15일부터) · OFF창(13~14) 밖
```

멈췄다면 10-01(금)·10-02(토)·10-03(일) 뿐이었다. 그건 못 쓴다 — 아래를 보라.

## 멈췄으면 틀릴 뻔했다 — 요일이 앵커와 계획을 반대로 민다

```
                10-01(금)    10-02(토)    개인 쌍 부호
  소비성향 p       0.680       0.680       동점 238 (평평하다)
  앵커            94,425      62,249      토<금 439/500
  계획            49,116      99,594      토>금 439/500
  계획/앵커 중앙    0.500       1.568
```

**같은 439명이 양쪽으로 갈린다.** 성향은 안 움직이는데 앵커는 내리고 계획은
두 배가 된다. 그래서 `max(앵커, 계획)` 이 금요일엔 앵커가, 토요일엔 계획이 이긴다 —
**요일마다 다른 기계가 총액을 정한다.**

개인 안에서 계획/앵커 비의 이틀 간 상대차가 중앙 113.8%다. 이 섞인 이틀로 개인
기준선을 세웠다면 비교 창(10-13·14 수목, 10-27·28 수목)에서 `plan/base` 가 죄다
클램프 `[0.5, 2.0]` 에 걸려 **신호가 눌렸을 것이다.**

기준선은 **비교 창과 같은 요일종류(평일)** 에서 와야 한다. 그 평일은 런을 둬야 생긴다.

## 덤으로 확인된 것 — 가맹몫은 상수다

```
적립업종 몫 = sangsaeng_month_spent / month_spent
  10%  0.241     중앙 0.253     90%  0.254
```

`ELIGIBLE_SHARE_SEOUL = 0.2535` 그 자체다. POI 의 `sangsaeng_eligible` 플래그가
'온라인' 으로 갈라낸 몫과 사실상 같은 선을 긋고 있다 — 두 번 깎이지는 않는다(다행).

그러나 **이 몫은 정책에 반응할 수 없다.** 실제 제도의 핵심 통로는 대형마트·온라인에서
골목상권으로 **옮겨 가는 것**인데, 우리 모형에서 그 몫은 0.2535 에 못 박혀 있다.
`experiments/error_budget` 의 "오차는 구조다" 가 여기서 다시 확인된다 —
**P012-2(제외업종)는 프롬프트로 못 고친다. 2층이 측정 전에 지워 버린다.**
